## 独立入口与保留项

- 新入口：`versions/v2/games/court/`，保留并链接 `preview/court/` 的 v1。

## 这一轮实际改变

- 保留原海滨插画，用 1200×680 近构图裁去装饰天空和底部铺地，完整球场和极端远投弧线保持在画面内。
- 原创矢量球员约 1.62 倍放大，重画轮廓、球衣号码、头部、四肢、跑动与举手。青绿己方和紫色对手提高区分。
- 白环及“你”标记控制对象；金环标记持球者；球有明亮描边。运球、蓄力、传球、起跳、抢断、防守和庆祝姿势分开。
- 出手窗口贴近当前球员。小屏文字/窗口按画布实际 CSS 宽度调整。接球落点、传球/投篮尾迹、碰撞/落地圈、得分及篮板/抢断文字反馈跟随实际事件。
- 完成传球后，原传球者获得 1.8 秒切入。空位时 AI 可通过正常可拦截传球回传；20 秒临界抢投仍优先。
- 防守每个固定 tick 唯一分配一人压迫持球者、另一人盯无球者，避免两人错误重复追球。
- 原创合成运球、传球、接球、出手、弹框、得分、抢断、篮板和终场音色。默认静音，保存偏好；用户操作后解锁音频，最多12个短音源。
- 精简场内外重复蓄力条；窄屏方向键44px，绘制CSS方向符号避免依赖箭头字形。

## 尚未通过的放行门槛

1. 公网真实浏览器宽屏及 390/360 CSS 布局，完整比赛空间/比分/时间/操作同屏，无字体方框。
2. 至少3场正常速度连续实玩覆盖胜、负、加时；一场完整无剪辑录像。需真正看到传切、抢断、篮板和受干扰投篮。
3. 真实触屏双指移动+蓄力，pointercancel、切后台、旋转、音频恢复；桌面低延迟输入测量和帧时稳定性。
4. 至少两种有效得分思路，新玩家能迅速看懂己方、球权和方向。模型中有效的单一通关策略不构成玩法深度证明。
5. 动作逐帧审查、耳机/外放声音听测与静音检查。
6. 原作具体版本尚未确认，不能称为 NBA Jam 等价复刻；未使用原作角色、球队或音乐素材。

进入v2，确认从全新第一场开始而v1记录未变。开始后确认场地自动定位；移动、K传球、队友接球自动切换、原传球者切入、J蓄力松开；P暂停/继续、玩法开关、R重开；浏览器切走回来不误投。分别检查桌面1366×768、390×844和360×640的布局。最后按上面的实玩/设备门槛继续验收，不以这些冒烟步骤替代完整验收。
