本轮基于统一候选8cb045c08910d37a862e98277affb85cc6a2824f；只改本地，未上传、未改main或部署。入口仍是 experiments/windowlife-request-preview/index.html，未新增游戏或入口。可复核结果见report.json，原Inlet和Quiet保持原字节。

## 实际体验闭环

在放大的纸上按下、拖动、松开：落点、叶尖朝向与大小决定实际叶形。最多两笔，一笔后即可主动收笔；撤回一组会一并移除依赖它的枝线。草稿只在控制器内，松手后才成为保存指令。无输入等待不会新增玩家笔迹或替玩家收笔。

- 现在一起：人物实际走到长座；玩家画叶影，阿沐从纸上花盆向玩家叶柄补枝线，0.8s逐步落下。两种摆放产生不同叶形与枝线坐标。玩家收笔、枝线画完才回桌续写，之后收好两份作品。
- 稍后：玩家在手记里完成自己的叶影，阿沐画自己的窗景；收笔后才带着两份各自完成的作品去分享。
- 独处/不回应：同样的个人纸面能力，完整的手记与速写，无强制分享、情绪扣分或劣等结局。

完成页以相同尺寸并排展示两份实际作品，不靠文字回执取代作品。个人手记和共同窗景都读取同一份保存几何。小屋里的小纸、放大编辑纸和收尾纸一致。

## 操作与保存边界

鼠标/单指在白纸绘图区拖动；第二个指针不抢笔，越界松手、pointercancel、失焦会丢弃未落墨草稿。白纸绘图区外保留页面纵向滚动；暂停后绘图区也恢复pan-y。键盘聚焦纸面Enter起笔，箭头移动叶尖，Tab选择叶柄/叶尖握柄，Shift加大步幅，Enter落墨，Esc放下草稿。两个握柄均44px，位置以百分比提供可访问名称。

390px视口下，按当前CSS约束估算实际白纸约316×248 CSS px；这是源代码算术，不是浏览器DOM测量。暂停保留纸面和控制区域，避免因隐藏按钮造成布局跳动；输入禁用而不是让纸消失。

v2保存有界整型端点与落墨/撤回/收笔指令，不存pointermove轨迹。取消保留已落墨部分，不把未完成共创标成完成；暂停、刷新恢复先暂停。坏档保全和写失败重试维持原语义。4096指令边界仍保留安全暂停/关闭槽位，并明确说明需要重新安排。

旧v1档通过legacy-scene原行为续读，既有动作/纸面/终局不转换成新创作。界面明确“旧版自动片段”，选择文案也恢复旧语义，只有原“重新安排”确认后才进入手动片段。legacy-scene保留上轮scene完整代码，只追加共享基础函数导出；原有29项旧场景/控制器/画面测试保留并明确针对v1，新版另有独立测试。

## 质量复核时的真实操作

1. 正常重新安排进入新片段，选现在一起，画左/右不同叶影，看枝线是否实际接到各自叶柄；连续画、撤回、收笔与立即取消各试一次。
2. 稍后和独处均用键盘完成一笔，检查两者同样完整；稍后确实把两份作品带到长座，独处能直接收好。
3. 390×844与桌面分别测纸内画、纸外滚动、抬手越界、触控取消、暂停/返回、刷新；确认没有滚动劫持、焦点丢失或控件遮住作品。
4. 有旧档时应明确恢复旧片段，未确认重新安排前不抹除进度；坏档与满存储必须继续明确提示临时进度。

当前交付是待质量复核的本地完整原型，不替换稳定站点。
