# 晶簇花园 · 第十款阶段验收

范围见 [GARDEN_SPEC.md](GARDEN_SPEC.md)。二十关原创三消已实现，图鉴保留 72 条、10 组，原创实验区为 10 款、118 关。前九款运行目录保持原样。本阶段验收后回到主对话安排下一款，项目继续扩展。

## 实现与规则

关卡/种子/目标位于 `games/garden/levels.mjs`，生产规则位于 `engine.mjs`，原创 SVG 晶簇与动画渲染位于 `renderer.mjs`，输入、界面和本地存档位于 `game.mjs`。图块、封面、花园界面和合成音效原创，不复制 Bejeweled 品牌资产。

- 8×8 邻格交换，横纵三连、下落补充和级联。无效交换回弹且不扣步；一个有效交换只扣一步。动画阶段锁棋盘，重开直接替换实例，无异步旧动画回调改写新局。
- 横四连清行，竖四连清列；五连或同色 T/L 连通块生成 3×3 花蕊。每个连通块只留一枚，优先交换目标格、再源格，级联优先左上普通格；生成格本轮不计收集或土层，若被旧特殊效果命中则仍被移除。
- 特殊晶簇通过同色匹配或与任意邻格直接交换触发。两枚特殊分别作用于交换后的格位，没有隐含额外组合。效果可引爆其他特殊，每格每轮去重计数；土层固定格位，每次去一层。
- 全部级联后先判目标达成，再判零步失败。无动作自动洗牌，保留图块多重集、特殊、固定土层、步数与目标计数，不奖励分数。初盘无现成匹配且有合法交换。
- 稳态存档保留棋盘、RNG、步数、分数、目标与统计。动画中刷新回到交换前完整稳态；恢复后先暂停。通关/失败不保留半局，刷新重新整备。存储异常时仍可游玩。

## 逻辑与正常策略

`node scripts/test_garden.mjs` 通过 12 组边界测试，见 [logic-report.json](garden-qa/logic-report.json)：横纵交叉去重，特殊种类/生成格位/直接触发/同色触发/连锁，旧效果清除新生成位置，土层和颜色计数，级联稳定，无效交换与输入锁，最后一步目标优先，保留多重集洗牌、受约束重排后备及自动无动作流程，暂停、重开、只读快照和存档校验。

这些边界测试在隔离实例内构造棋盘与最后一步场景，不作为通关证据。独立的二十关正常策略模拟只通过生产规则的相邻交换接口推进，未改写棋盘、目标、步数或胜利状态，见 [simulations.json](garden-qa/simulations.json)。策略只看当前可见棋盘与目标，不读取 RNG，不预测尚未落下的新晶簇。

每关使用下表固定种子，重试相同种子可复验。本报告证明这些默认关卡种子可由该策略完成，不代表所有任意随机种子必胜，也不宣称最优策略或人工全通。

## 部署与复现

公开部署状态将在 Pages 成功及实际 URL 核验后追加，不能将本地预览当作上线。

```powershell
node scripts/test_garden.mjs
python scripts/test_garden_browser.py --stages 1,10,20
python scripts/test_garden_ui.py
python scripts/test_browser.py --url http://127.0.0.1:4174/
python scripts/verify_deployment.py --commit HEAD
```

使用环境中已有 Node、Python、Playwright/Chromium；运行时无第三方依赖、后端、模型调用、登录或付费服务。未覆盖真实手机硬件、Safari/Firefox、手柄或完整屏幕阅读器体验。声音仅验证偏好与触发路径，未作主观听感评价。
