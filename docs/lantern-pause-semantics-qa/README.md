公开旧版窄屏普通点按复现：待命时顶部暂停已禁用，底部触屏“暂停”却仍可按且无效果。处理器的状态保护本来正确；问题是同一动作两处按钮呈现可用性不一致。

最小修复只同步触屏暂停按钮的disabled状态，并在入口给两个暂停按钮安全的待命禁用初值。进行、暂停态仍分别显示暂停、继续，原有启航、方向、巡灯和记录规则不变。

测试执行真实控制器的按钮呈现语句，覆盖ready/playing/paused/won/lost；旧源码负对照保留顶部禁用但触屏可用的差异。终态呈现fixture与真实UI分列，不冒充自然胜利。

桌面与390CSS普通UI验证待命按钮、正式启航、暂停冻结、同一按钮继续。桌面另按原规则自然行进至终态，确认暂停入口不可恢复或重开；窄屏终态未另行追胜。
