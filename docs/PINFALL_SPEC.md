# 落星弹庭 · 第十四款固定范围

12 关原创瞄准弹珠消钉战役。重力弹道、圆形钉反弹，命中全部目标星钉后在本球回收时胜利；普通钉提供得分与路线变化。逐关引入一次性涟漪钉和不可消除的回弹石，地图、美术、名称与合成声音原创，不复制 Peggle 关卡或资产。

- 每关有限球数。一次只飞行一球，不能连按抢发；本球命中的钉保留碰撞到回收，统一移除，每枚仅首次命中计分。连续多钉有小额递增加分。
- 自动接球槽只在飞行时沿底部往返，瞄准时静止。完整接住且本球至少命中过一钉时返还一发；空球不返还，避免无限刷球。最后一发先结算命中和接球，再判胜败。
- 物理采用固定 1/180 秒步长和连续扫掠圆碰撞，接触分离、有限碰撞迭代及球速上限。低速持续 1.2 秒时轻推、每球最多两次；12 秒仍未回收就回收本球，只移除已命中的钉，不替玩家点亮目标。统计保护次数，手册公开规则。
- 涟漪钉命中后点亮半径 110 内的钉，范围内其他涟漪只点亮、不再扩散。回弹石无分、不可消除。全目标清空优先于球数耗尽。
- 鼠标移动瞄准、点击球场或发射按钮；键盘左右/A D 微调，Enter/空格发射。触屏横拖或滑杆瞄准，显式按钮发射；松手、竖向滚动与触摸取消均不自动发射。
- 教学、胜败/重试、暂停、12 关解锁、本地最佳得分/用时、声音偏好。完整一球结算后保存合法角度日志；飞行中刷新回到本球出手前，恢复先暂停，避免部分结算。版本损坏拒绝，重试重新开始当前图。
