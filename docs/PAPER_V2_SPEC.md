## 固定范围

两关，每关 3 发同一种纸团。第一关为分段纸柱 / 木柱支撑的门架，第二关为上下两层门架与高低错开的两个木偶。每关初始 8 个动态刚体；即使三发都保留也只有 11 个，低于 24 个预算。没有第三关、能力、爆炸、付费或账户。

纸板与木封件两种结构材料，分别具有密度 0.65 / 1.3、摩擦 0.65 / 0.7、单次接触法向冲量破坏阈值 4.8 / 12。静态承重不累计伤害。破坏只在物理解算完成后删除对应结构；碎纸是无碰撞的限时视觉装饰。

## 物理

官方 Planck 1.5.1，原发行 ESM 文件本地托管。1/120 秒固定步，10 次速度 / 4 次位置迭代，重力 9.8 m/s²，米制；所有实体由真实刚体位置和角度绘制。不设置预定角度、倒塌时间或目标命中路线。

纸团直径 0.56 m，密度 4，bullet=true。速度为 8 + 力度×0.24 m/s，合法力度 15–100%，仰角 12–75°。最高速度 32 m/s。仅预览最初 0.46 秒以内的短轨迹点。指针从发射器向左下拉动；短拖、越界释放与取消不发射。

为避免纸团在地面无限微滚，仅当纸团真实接触静态地面时使用线性阻尼 0.8、角阻尼 1.2，离地恢复 0.045 / 0.08。不强制休眠，不将速度或位置归零。结构保持普通物理休眠 / 唤醒。

木偶倾角超过 0.85 rad，或比初始位置下降 0.8 m，或水平位移超过 1.1 m，持续 0.22 秒即登记击倒；目标仍保留真实物理实体，唯一登记，轻触不直接清除。

飞行、转动和倒塌期间锁定下一发。所有实体线速度低于 0.12 m/s，结构角速度低于 0.14 rad/s（纸团按圆周线速度 0.12 m/s），持续 0.85 秒且该发至少观察 1.2 秒才结算。最后一发不立刻判负，迟到倒塌也可获胜。单发超过 60 秒未停稳提示“观察超时”，不假报弹药耗尽或通关。

## 输入与进度

滑杆 / 大按钮 / Space 或 Enter 发射；方向键调角度和力度，滑杆保留原生键盘行为。P / Esc 暂停，R 重来。切走页面自动暂停，取消旧指针；恢复须重新输入。重试和切关回准备态。弹尽失败、胜利与超时分别说明。

只存解锁和最好成绩，优先发数少、同发数时间短。本机成绩不是防作弊榜。刷新回第一关准备态，不续接中途弹道；帮助、页内说明均明示。存储不可用时仍能游玩。
