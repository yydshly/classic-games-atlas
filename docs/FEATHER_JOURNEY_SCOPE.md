## 一段有结局的浅滩旅途

1. 在同一张17步点浅滩结识晶雾芽或露纹鳍中的任意一位，带回营地。羽结仍有失败概率，资源与随机结果按原v2规则记录。
2. 在营地把任意新伙伴换入两人队伍；不是要求某个指定种类。任意伙伴参与两次有结果的相遇后，仍只成长一次：体力上限+8、基础威力+2。
3. 回营后可任选两位伙伴迎接“浅滩回响”。先前换入的新朋友不必成为终挑战的指定钥匙。整备免费恢复体力与3能量，带2颗终挑战露莓。
4. 平息回响后显示实际旅途总结：出行次数、伙伴、成长、终挑战队伍/次数/拍数与行动统计。刷新保留结局；回营后仍可自由出行，不开启第二地区。

## 一次固定终挑战

浅滩回响是自然的合奏，以原创几何光环表示，沿用原浅滩绘画与五位伙伴素材；它不是新增物种。24拍内消去190余势：

- 属性按“苔、苔、泉、泉、风、风”循环；来招按“试探、蓄势、回涌”循环。界面同时预告本拍与下一拍，预计来招会随当前领队与状态改变。
- 试探基础20、蓄势不攻击、回涌基础64。原属性系数仍为顺向1.5、逆向0.75，向下取整。每次轻击、技能、守息、治疗或换位占一拍；消去最后余势后不再结算该拍来招。
- 五种技能沿用原效果：缠风10威力并弱化两次来招；苔息恢复28；澄心恢复18并安心+10；晶雾安心+22并弱化一次；潮护10威力并给18护盾。技能耗2能量。
- 守息回复1能量并给本次16护盾；露莓恢复26，只有2颗。安心≥30时来招乘0.65；弱化乘0.5，观察/蓄势不消耗弱化次数。护盾只承担本次来招，属性与技能的取舍可以配合换位。
- 体力尽或24拍未完成即安全回营。已结识伙伴、原有成长不丢失，不强制重刷捕获；完成一次胜/败挑战的参与者各得1经历，仍封顶2经历/一次成长。主动提前回营不给额外经历。可免费重新准备。

模型中两组不重叠队伍均可通过：岚翎＋晶雾芽利用弱化/安心与回能；苔灯＋露纹鳍利用恢复/潮护与属性换位。最终模型检查中，20种有序双伙伴队伍在满有限成长下仅轻击均失败。这个有限检查说明本挑战不能靠持续轻击完成，不证明所有策略的难度或玩家感受。
