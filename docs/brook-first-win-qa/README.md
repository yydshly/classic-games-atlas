## 输入排查与模型区分

首次脚本只部署一台凝露台后29.7秒失败。原因是数字字符串选择存在标签/值歧义：请求"1"实际返回值0（标签1）；后续仍在已占格，部署被正确禁用。保留[该次失败记录](selector-attempt-report.json)与[原生选择框/键盘排查](selector-check.json)。线上控制器字节与main相同，原生End/方向键选格有效。脚本改用明确选项索引并逐步核对DOM值，保留生产实现；这不是难度或产品控件缺陷修复，也不把未布防失败算策略评价。

离线参考模型为66.9167秒、1070分、9清除、零损失，[参考摘要](model-reference-summary.json)和[参考源](model_reference.mjs)明确为模型。公开UI有自己的操作时刻/收露记录与截图，不以模型结果替代。随后使用实际UI的32条合法指令做独立离线重放，逐字段比较预算、冷却、装置/敌人/弹体/露珠、编号、统计、日志等一致，终局仍4015 tick、290露、9击杀；这是审计回放，不是第二场浏览器通关。[回放脚本](replay_ui.mjs)
