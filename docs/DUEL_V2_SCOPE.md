# 风庭对决 v2 · 有限候选

这是原创单人攻防游戏的独立 v2，不是《街头霸王Ⅱ》复刻或完整格斗成品。原有 games/duel 与 versions/v1 完整保留。入口位于 versions/v2/games/duel/，本地存档使用独立 classic-atlas.duel.v2。

## 这次确实改变了什么

原版已有八场、两种地面攻击、方向格挡、耐力、退步无敌窗口、前后摇、胜负计分、解锁及输入重放恢复。这些不是本轮新增。

本轮增补两组完整选择：
- 腾空与对空：W/↑起跳，J在空中变为踏风踢；地面 I 迎风对空可打到空中对手。普通地面短拍/长挑打不到高于45的对手。对空有0.48秒收招，乱用可被地面反击；空踢需要高度25–125，顶点不能靠按住J重复攻击。
- 近投与防守：O近投只在中心距离66内命中，穿过格挡；跳起或退开会让投技落空。投技0.24秒前摇和0.55秒收招，失败有代价。K继续是有方向、有耐力代价的格挡，跳跃时不能格挡。

八场保留原来的三段庭院节奏，并给第二场跳攻、第三场守投、后半段混合跳攻/投技/对空。对手只依据当前位置、高度及自身节奏，不读未来输入。只有两套角色外观，八场不是八位拥有独特招式的可选格斗家。

新增原创角色八个关键姿态，以及庭院图。姿态按规则切换、镜像与位移，配合预兆条、出招轨迹、受击闪烁、火花和既有击退。它不是逐帧骨骼动画，也没有完整抓取摔倒动画或物理布料。运行包不使用原作人物、ROM、图像或音乐。

## 固定规则边界

每场60秒；八关HP/速度与原版一致。世界宽900，双方不可穿身/换边；角色视觉肢体可重叠，不代表碰撞中心穿透。每次攻击仅结算一次。跳跃消耗12耐力，持续0.72秒，高度155；起跳时保存移动方向，以165速度沿固定方向移动，落地有0.12秒最小恢复。不能空中再次起跳、地面格挡、地面攻击或退步。

|动作|前摇/有效/收招 秒|范围|伤害|耐力|
|---|---|---:|---:|---:|
|短拍|0.15/0.09/0.28|96|12|8|
|长挑|0.38/0.12/0.42|148|26|20|
|对空|0.18/0.16/0.48|108|22|22|
|空踢|0.10/0.20/0.18|120|20|16|
|近投|0.24/0.10/0.55|66|24|24|

对手前摇按关卡额外放慢，收招乘1.15。跳跃本身不具有无敌，投技仅能击中地面；空踢能被正面格挡。动作成功后需松开并重新按方向键。暂停、失焦、弹窗和恢复释放旧输入；恢复重放合法命令后先暂停，不采信外部HP快照，不计离线时间。
