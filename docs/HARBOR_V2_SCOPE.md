# 云港调度 v2：三段经营解谜候选

[独立 v2](../versions/v2/games/harbor/) · [原 v1 十二关](../games/harbor/) · [首页对比](../index.html#compare=harbor)

## 本轮改变

原 v1 已有固定候选航道、两类船、有限货物与预算、装卸交付、容量、航道占用、期限和输入重放；它是出航前规划、出航后冻结方案。本轮保留原十二关和存档，在独立目录做三关可营业中再投资的短程经营解谜。

- 先用短线交付回款，再继续建设航道、购买船只或升级港口。营业中及暂停时均可投资，须预览确认；不足预算、取消和过期确认不扣款。出航后不能出售、拆线退款或撤销投资。
- 只可给停港且空舱的船改线，新路线必须包含当前港口，船不传送。船自动装卸、沿已连通往返线运行，货物不换船。
- 轻舟1格舱位、驳艇2格；重箱占2格。每次实际出发才扣航费，等待不收费，货物到指定终点卸下才回款。有限出库批次与期限从开局可查。
- 港口一次4币升级双泊位，允许同回合沿不同航道放行两船；每条航道仍只容一船。这里的泊位限制是每回合放行数，不是可停靠船数上限。
- 独立存档 `classic-atlas.harbor.growth.v2` 重放已确认操作。未结算运行进度刷新后先暂停，开局规划刷新恢复准备态；未确认输入不保存。胜负会清除当前会话，刷新回所选关准备态，解锁和最佳保留。现金不跨关。

## 三关与模型结果

以下分列生产引擎中的合法操作序列模型结果；后续有限公开实玩另见下节。模型本身不等于真实浏览器或玩家体验验证。

1. 从一段短线开始：预算11币，完整主线加轻舟需15币，先交付三箱短途货，再用回款扩展。示例第16回合完成，余13币。
2. 交汇口的两种生意：共享C港升级双泊位，示例第11回合完成、余20币、泊位等待0；保持单泊位第12回合、余24币、等待1；B—E长线绕行第16回合、余26币、等待0。升级更快但留下的钱较少，升级并非唯一通关办法，也没有一项方案在所有指标上都更好。
3. 回程重箱与预告货潮：预算14币，先跑短线并接重箱返程，之后建长线承接第7/11回合出库批次。示例第16回合完成、余19币。三关不是开放世界，完成后没有第四关。

模型另覆盖只跑首关短线、遗漏后续批次会在第23回合自然逾期失败；资金与货物守恒、重复收费、同航道排队、暂停、非法改线与存档重放等检查共2784次断言。普通控制器处理器的DOM模拟覆盖确认、取消、营业中投资、改线、刷新、胜利解锁、重试与失焦暂停。五张实际renderer离屏图用于核对资产接入与状态差异，不能当作公开浏览器截图。

## 画面与参考边界

AI辅助原创生成的暮色海湾背景、透明港口、两种船舶WebP已接入运行场景；升级显示第二条码头，两船错开停靠，另有插值移动、尾流、装货/回款提示。它们不是原作画面或原作授权素材。[素材来源、尺寸及哈希](../versions/v2/games/harbor/ASSETS.md)。场景采用二维精灵和程序航线/UI，不是可自由转动的3D场景或完整角色/船舶动画。

参考口径沿原目录《运输大亨》/TTD；OpenTTD是受其启发的开源项目，不是原作。这里只学习“运输回款→追加投资→观察效率”机制，仍仅固定候选船运网络，没有铁路/公路协同、换乘、城镇产业增长、对手公司或长期自由经营，不能当完整运输大亨复刻。
