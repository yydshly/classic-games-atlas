# 钢岚突进 · 验收与证据

第十五款原创横版跑跳射击，固定范围见 [GALE_SPEC.md](GALE_SPEC.md)。8 个完整滚动关卡，锈港、霜库、暮炉三种原创环境；步兵巡逻瞄准、炮台预警扇射、飞行机下投。终关“穹炉核心”有入场屏障和三阶段攻击。角色、地图、场景、首领、SVG 与合成音效均原创，不复制 Contra 或 Metal Slug 资产。

与《风行小径》的平台跑跳不同，本款必须射击清除全部单位后进入出口，跳跃不踩死敌人；有限弹药武器、脉冲清弹与敌方预警构成主要节奏。本轮无移动平台，固定实心掩体挡弹，单向高台可穿行且不挡弹。

## 规则与生产模拟

[13 组规则检查](gale-qa/logic-report.json)覆盖：八图/三环境及安全检查点；长短跳与不自动连跳；离地宽限、落地缓冲、过期空中跳；单向高台/实心阻挡；玩家及相机边界；左右/上斜射方向与弹药耗尽回基础枪；扫掠弹体优先碰撞和掩体；寿命/出界清理；受击链无敌、致命/跌落单次复归；两次脉冲不回血；首领阶段转换/旧弹清除与同帧致命优先；检查点资源恢复与损坏拒绝；全战斗暂停和唯一胜利结算。

这些极端状态使用独立游戏实例的隔离夹具，不改发布地图。夹具中的生命、位置、阈值与弹体设置不是正常通关证据，脚本末尾检查原始地图未被修改。

[八关正常生产模拟](gale-qa/simulations.json)全部通过：只读快照策略输出左右、跳跃、射击、上斜射和有限脉冲，真实局只调用生产固定步长更新，不写玩家/敌人护甲、坐标或胜利。五格护甲、三次出击、原定敌方护甲与弹药规则保持。终关实际经过三阶段，并有真实预警攻击。所有关卡清除本图全部单位后到达归航信标。

物理固定 `1/120` 秒，弹体采用线段扫掠扩张矩形。死亡/跌落复归清弹，保护期阻止同帧连锁伤害；最后一次出击致命失败先处理，不能用随后击杀复活。首领屏障到末段检查点且其他单位清除后才解除，避免在进场前被远处弹体削弱；转阶段短暂护盾、清除自身旧弹并重新预警。

## 策略失败记录与修正

没有用测试捷径掩盖自动控制困难。保留 [最初停滞](gale-qa/initial-strategy-stalls.json)、[第二次尝试](gale-qa/second-strategy-attempt.json)、[第三次尝试](gale-qa/third-strategy-attempt.json)。初期策略在掩体前原地射击、跃过障碍时松开方向，或把可落脚的低处误当坑隙，导致停滞、跌落和失败。

改动是普通输入策略：射线受实心掩体挡住时继续接近/跃过，过障碍保持方向至落地，识别可落脚的低处，并在矮目标低于枪口时走下高台。首领体积较高，跳跃射击时保持正常射距。几处可选高台出口与下一坑隙之间也留出更宽落脚空间；没有加护甲、削敌方护甲或改变物理速度来过测试。

开发中补充了过期弹体先清理再碰撞，避免超寿命命中；首领阶段预告调整后同步修正旧测试对冷却时长的过强断言，仍检查护盾、清弹和重新预警。自然失败 UI 首版只向右走，被前段实心掩体挡住；现先用正常策略到检查点，再不跳跃地向右落坑耗尽出击，未注入检查点或生命。
