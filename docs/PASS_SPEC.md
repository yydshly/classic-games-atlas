# 山口守望 · 第六款范围与验收

八张本项目原创山谷地图，每图六波固定路径敌人，使用固定建造点。三类塔分别负责单体、范围与减速，各有基础 I 级和一次升级后的 II 级。四类敌人为步兵、快骑、重卫、群行，各有可辨认形状、生命、移速与漏过伤害。所有地图、美术、音效与代码原创，不复制 Kingdom Rush 或植物大战僵尸素材。

- 正常金币预算，建造、升级、出售；击杀收入与波间补给，基地生命。
- 波次预告和手动开始，每波清场后整备；六波全清且基地尚存才胜利，生命耗尽失败，支持重试。
- 暂停、1x/2x、教学、逐关解锁、个人最佳余命/用时、声音和本地进度。刷新重新整备当前关，不伪称恢复未完战斗。
- 鼠标/触控选点，明确塔的用途、等级、费用、射程、敌人属性；原生按钮和键盘焦点。
- 不做英雄、技能树、无尽、联网或后端。当前款验收后返回主对话安排第七款，保留图鉴72条和前五款。

验收：目标选择、射程、伤害、减速取强不相乘及到期、范围伤害、击杀只发一次钱、漏怪扣命、出售/升级守恒、暂停与速度、末波/基地耗尽竞态、存档/重试；全部八图用生产规则及正常购买策略模拟通关并保留策略；至少1/4/8关真实浏览器正常建造/升级/开波通关，不注入金币/敌人/基地/时钟/胜利。另测失败重试、触屏、尺寸、存储失效和图鉴/前五款回归。独立代码提交、对应 Pages 成功、线上通关与文件 SHA 核对后交付。
