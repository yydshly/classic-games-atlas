## 自然失败、重试与取消

- 首关未购船时尝试开始被正确阻止，提示先建线购船；这是输入校验，不是失败终点。
- 正常建AB并购轻舟后只跑短线，不扩建后续航路。第23回合，B→D货物自然逾期，显示“还有货物等在岸边”，交付3/6、余14币。
- 重试实际恢复第0回合、11币、0/6、空船队和空账本。随后再开AB短线至第1回合，暂停后取得主页展示截图。
- AB投资预览选择“再想想”，11币和未建设状态不变，账本没有扣款。没有据此推断全部取消、失效确认或非法改线分支都已浏览器验证。
