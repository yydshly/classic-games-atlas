障碍相距26米，最快仍有1.042秒恢复间隔；82米可见距离，最短预警3.286秒。每关首障碍44米后出现。每条路线包含绕行、跳、滑与岔路，后段更快且交错更多；模型用相同普通动作可全程不碰撞，无需减血、加距离或修改结果。
