## 实际观察

1. 开始、进入教学并确认准备后，第一关为 20 砖、3 命。完整砖区、球、挡板、顶部即时 HUD、暂停和底部发球按钮在同一视口内可见。
2. 视口为 1181×757，页面内容宽 1166（滚动条占宽）、整页高 961。教学关闭后页面滚动位置为 108。画布实际为 458.25×549.906，视口内顶部 92.375、底部 642.281；暂停按钮顶部 12.281、底部 48.281，发球按钮顶部 656.281、底部 700.281。完整场地没有裁切，但标题和页脚不同时可见，整页仍可滚动。
3. 按当前屏幕位置正常点击发球，滚动位置仍为 108，以上矩形不变，场地、HUD 和控制仍同屏。画布与文字较紧凑，不能把这一结果称为审美或全面品质通过。
4. 正常发球、不主动接球，生命自然从 3→2→1→0。最终 33 秒、清除 5/20 砖、250 分，出现失败提示和重新挑战。点击重试后恢复 3 命、20 砖、0 分、0 秒。
5. 暂停显示“光轨暂停”，继续后可正常再次发球。
6. 重试后刷新回到第一关开始界面，再次开始没有重复教学，教学偏好保留。未取得通关解锁或最佳分，因此这些保存分支未验。原实现保存的是关卡进度与偏好，本轮不是活动局球位或生命恢复测试。

## 滚动疑点与正常点击复核

某自动化点击路径曾让页面额外下滚约 96 像素，导致顶部 HUD 出视口。这一观察保留，但不能据此认定普通发球必定触发下滚。

随后刷新、重新开始，并按当前屏幕位置点击发球，滚动位置和场地矩形没有变化，也没有先手工滚回或改样式遮盖。自动化路径出现下移的原因未确定，本轮未据此追加代码修改。此版本也没有承诺锁定整个页面或禁用滚动。
