# 回声走廊 v2 · 实现与验证边界

## 运行

静态站点下打开 `versions/v2/games/echo/index.html`。没有构建依赖。所有本地ES模块和CSS携带明确的 `echo2r1` 版本查询；图集只初始化一次。

## 模块

- `levels.mjs`：3张显式地图、出生点、补给、守卫与出口。
- `engine.mjs`：沿用本项目v1的60Hz固定步长、碰撞、射线、日志、资源账目；增加视线追击、两武器开火成本与独立存档版本，出口改为钥匙撤离。
- `renderer.mjs`：原有墙面射线与深度遮挡，增加原创工业分块、透明敌方billboard和武器外形。巡猎者与悬浮守卫使用不同垂直锚点。
- `game.mjs`：真实按钮/键盘/拖动控制、暂停/失焦、保存与恢复；最小DOM测试直接执行此文件，不另造控制器逻辑。

## 可重复检查

从仓库根执行：

- `node scripts/test-echo-independent.mjs`
- `node scripts/test-echo-controller.mjs`
- `node scripts/render_echo_v2.mjs`（离屏绘图需环境提供 `@napi-rs/canvas`）

检查报告见 `docs/echo-v2-qa/`。离屏图调用实际发行renderer，使用普通开始/等待状态；不是浏览器截图，不证明DOM尺寸、真实键鼠/触屏、字体加载或长时性能。源码和样式的尺寸预算也不能代替1181×757真实页面检查。
