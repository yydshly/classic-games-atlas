# 归火石室 v2 普通浏览器验收路线

此文是待执行路线，不是已通过报告。模型测试、离屏渲染不等于实际浏览器操作。不得用改状态、注入位置或胜利来代替通关。

## 基本操作

打开 `versions/v2/games/ruins/`，点击继续。WASD/方向键持续移动；J 横扫，K 闪避，L 回声灯，E 靠近交互。每次进房按入口记录检查点，重试恢复该点及生命。不同关可通过选择框独立开始，第二关需自行取得回声灯；第三关初始携带。

## 第一关：苔灯庭

1. 从入庭向右走，靠近右侧门按 E。
2. 进入守卫室，在中央石墙的上方绕行。向右上角石钥移动，靠近按 E。敌人靠近时会先显示金色区域；离开区域后可反击。闪避不会穿石墙。
3. 向右侧门移动，按 E 进入灯室。靠近右侧灯座按 E 点亮。
4. 沿左门返回守卫室，再从左门回入庭。走到左侧归途门按 E，出现本关完成。点击下一关。
5. 另开本关，在守卫附近站定，敌人应继续预警、攻击并自然造成死亡；重试恢复入口生命。此项与上述通关分开记录。

## 第二关：回声廊

1. 门厅可见右侧隔栏内的机关。先尝试 L 和右侧门，未取得回声灯不能开启。
2. 从下方门进入侧室，绕过中央石墙，靠近右下回声灯按 E 获得。
3. 从上门返回门厅。走到栅栏左侧，与机关处于同一水平线（画面约 y=220），面朝右按 L。蓝色回声穿过栅栏命中机关后显示已开启。
4. 另测试向石墙发射，回声应被阻挡。
5. 右侧门现可进入。靠近该房右侧归途门按 E，完成第二关。

## 第三关：归火殿

1. 中央守卫休眠。先从左门去西灯室，点亮左上灯座，再返回中央。
2. 从右门去东灯室，点亮右上灯座，再返回中央。守卫此时激活。
3. 靠近守卫引出金色前摇区域，向侧面移动或 K 闪避离开该区域。攻击朝向在前摇时锁定。
4. 红色攻击结束、守卫恢复时，面向守卫按 L 破防；靠近用 J 横扫。恢复期约1.6秒，破防约1.5秒，不在恢复期的回声不能破甲。反复完成该循环。
5. 守卫生命归零后，必须实际走到上方归途门按 E，才出现“三关完成”。单纯击败守卫不立即胜利。

## 恢复及布局

- 暂停/操作说明/离开标签页时观察时间、前摇不推进；返回先暂停，无后台补伤害。
- 战斗中刷新，状态恢复并暂停；继续后正常推进。重复点击结算不得跳过多关。
- 按住移动时失焦，回来点击继续应无粘键。
- 独立验证触屏按住方向与同时动作，松手和取消触摸。不得把鼠标点击模拟当成触屏证明。
- 320、390、768、1440像素检查布局、正常滚动、文本与按钮；390像素实际触屏完成首关。没有执行就标记未验。
