## 实际限制

本轮浏览器为当前Windows上的Chromium / Playwright（含原生Chromium touch）。iOS Safari、Firefox、多种实体设备和屏幕阅读器未全面验收；自动策略与几何预测不替代人工难度研究。80采样/曲线段的弧长为高精度近似，不是解析积分；瞄准虚线展示当前几何，运动中的最终接触以正式物理碰撞为准。

存档按普通操作重放，不是防本机恶意编辑成绩的安全系统。珠径、海珠、潮灯、礁屏、图形和合成声音原创，不使用Zuma原作素材、地图、ROM。没有外部模型/账户/付费/新凭据或运行依赖；本轮无部署权限阻塞。交付后由主对话安排后续，不自行开始第21款。
