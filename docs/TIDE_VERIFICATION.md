# 潮汐珠径 · 验收记录

十二条原创路径、三环境、322颗原珠（每关12–35颗），所有关基础推进同为12。正常策略在副本中按同一正式规则预测发射角，真实战局只接收fire/swap/slow/back普通操作，不改珠链位置、速度、颜色、分数或结果。有限能力使用记录独立列出，自动策略不等于人工难度体验。

## 本地规则与策略

26组逻辑验证覆盖弧长积分误差/端点/切线、路径范围与礁屏间距、恒定弧速、前后插入/必要推前、最小间距、真实跨断口闭合、不同色不消除、连锁与唯一ID得分、只取有用途颜色、相对扫掠碰撞、礁屏优先、末珠/触线同帧、有限能力/过期/回退夹限、连续输入/版本、暂停、帧分区、飞行/断口精确恢复、坏记录和自然失败。只有明确标注的接触/终点单元夹具设置测试世界；正常策略与真实恢复测试不使用这些修改。

初版纯双珠段会过度连锁，一些关两至四发便清空。最终改为单珠与双珠混合，第一关作为12颗原珠教学，后期四种颜色与礁屏要求不同观察角。正常推进速度不变。碰撞采用发射珠与运动珠的相对位移，避免回接段移动时漏碰。最早原型、混合版、最终预测策略的实际结果分别保留。

单元测试有一次在35个子步后立即发第二颗，仍处于正式装填期而被拒绝；测试改为等到正常冷却结束，不调整生产冷却。角度滑杆在获得焦点时保留用户正在编辑的端点值，重来显式同步滑杆与潮灯；原生Home/End/方向键已针对检查。

本地12关正式策略和额外每次延迟0.15秒的策略均通关，后者验证瞄准预测并非依赖即时执行。真实浏览器第1/6/12关合计75颗原珠、66次发射全部清空，93条普通操作逐tick重放的统计、得分、能力和结果精确一致。23组界面检查覆盖真实键盘发射通关、原生触屏通关、六种宽度、教学与菜单、焦点与连续输入、飞行中暂停/刷新、坏存储和自然触线失败。另补测角度滑杆获得焦点时按R后角度归零。

原72条图鉴的搜索、类别交集、空结果、全部详情、键盘、链接、深链与六宽度回归通过。前19个游戏目录相对上一发布提交逐文件未变。
