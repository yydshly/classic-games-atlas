# 夜航拾光验收记录

第八款原创迷宫收集追逐，范围见 [LANTERN_SPEC.md](LANTERN_SPEC.md)。十张夜港地图、原创风帆与三类几何巡灯、限时辉光、三条生命和完整关卡循环。保留72条图鉴与前七款运行文件。美术、封面和振荡器音效原创，不使用 PAC-MAN 角色、迷宫或音乐。本款交付后回主对话继续第九款。

## 地图和生产规则

[离线生成器](../scripts/generate_lantern.mjs)以固定种子雕刻原创迷宫，编织死路并增加环路，再导出 [静态关卡数据](../games/lantern/levels.mjs)。不在游玩时随机生成。十张布局唯一，光点全部可达；起点三格安全水域之外的敌人区域也连通，泊位位于安全区外。地图从 13×13 扩展到 15×15，敌人数从 3 增至 4，敌人相对速度提高，辉光时长从 7.4 秒递减到 6.32 秒，每关六处道具。

[8 组核心检查](lantern-qa/logic-report.json)通过：地图/光点/敌区连通及出生安全、下一可行路口的转弯缓冲和格点反向、循迹/三格预判/固定航标三类目标策略、强化到期与新拾取的同帧接触、反制只计一次/真实返回泊位/等候/出泊保护、最后普通光点与危险接触优先级、死亡保护及三次耗尽/重试、暂停冻结全部移动和计时、只读观察副本隔离。

角色以连续位置平稳移动，在格点选择下一方向；提前输入不因暂时遇墙丢失，普通回转在下一个格点执行。最大子步长 1/120 秒；碰撞距离小于每格间距，正常交错不会因整格跳步漏判。巡灯寻路遵守墙和安全水域，返回泊位后等待两秒，再以 1.1 秒无接触伤害窗口出泊。受伤回起点、清旧输入，并有 1.7 秒保护。

结算顺序：先递减旧辉光/保护时间；正常移动；拾取当前格新辉光；处理接触；仍存活才提交普通光点并判断全收齐。旧辉光本帧到期则不保护，新辉光本帧拾取即可反制。普通最后点与致命接触同帧时生命优先，该点保留，不能在重生后凭已清零光点自动获胜。返回/等待/出泊保护中的敌人不伤人。
