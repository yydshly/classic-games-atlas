## 覆盖缺口与方法

原记录只有首关自然失球、失败与重试，没有清砖胜利、最佳纪录或下一关证据。本轮只补这些。所有输入走生产页面的鼠标移动、发球、开始/暂停、关卡册和下一关按钮。只读复制诊断提供当前球/砖/挡板的可见几何，助手计算鼠标落点并发送真实pointermove；没有写状态、球位、分数、血量、存档或时间，没有直接调用引擎update、applyPower、胜利接口。正常生产RAF、碰撞与速度限制持续执行。

这是带自动跟球辅助的界面集成验证，证明输入→物理→清砖→结算→解锁/记录→下一关的链路；不能写作人手接球能力、难度、触屏手感或审美通过。策略参考的离线模型另外保存，不代替浏览器成绩。
