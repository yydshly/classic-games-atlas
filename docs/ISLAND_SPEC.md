# 云岛工坊 · 第28款固定范围

12关小型离散回合二维建设解谜。三套原创地形、四种朝向，9×7或7×9土地、递减预算及递增稳定/产出条件。芽风台、雾泉湾、星屿庭各4关。真实土地占格、地形约束、道路和覆盖影响结果；区别于既有运输调度、农场与棋盘资产交易，不作完整城市模拟。

驿站为固定起点，水/石不可覆盖。道路1币，四邻接洪泛必须回驿站；建筑不传路，任一占格四邻接连通道路/驿站就连通。小屋7币/1格，塔8币/1格且紧邻水，圃9币/1格且只能绿土，工坊11币/2×1可旋转1×2，花园6币/1格。所有占格做越界/地形/重叠/资金校验，不同建筑不能复用格子。

每回合固定顺序，各类按建造先后处理：连通塔产5水；连通圃用1水产4食物；连通工坊用1水与1食物产1匠作箱并提供4岗位；连通小屋用1水与1食物，再检查连通花园曼哈顿2格覆盖及2岗位，满足后入住2人、税收2币。食水必须同时足够才扣，缺一个就都不扣。已连通但缺花园/岗位的小屋仍吃食水，失联小屋不取资源；岗位来自本回合真正开工工坊。最后每座塔/圃/工坊维护1币，失联/停工也付。初始4水4食物，不凭空补给，无离线生产或墙钟增长。

各关要求4/6/8满足居民、连续稳定2或3回合、匠作箱2–8。稳定回合必须达到人口目标且全部已建小屋需求满足；有任一小屋未满足则稳定归0、累计失衡+1，3个失衡回合失败。人口不足但现有小屋均满足仅不累计稳定；无小屋可规划至期限。期限6/7/8回合，最后回合仍可成功；资金<0立即失败。终态只结算一次。中段可利用公开初始储备完成有限目标，并不宣称无限自给。

每次放置、拆除或结束回合都先给完整成本/资金/供给/需求预览，再携带状态版本确认；取消不变资源、土地、回合或日志。首次生产前拆除全退，之后按原价50%向下取整；同一ID只退一次，重建新ID，已产出资源保留。路断即时重算未来连通和花园覆盖。目标只检查真实规则，不读取或匹配测试策略布局；替代花园布局也能成功。
