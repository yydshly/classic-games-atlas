# 云港调度 · 验收记录

十二关正常预算模拟与本地真实界面全部通关，共59箱货、132回合、219条普通操作，操作重放的现金、账本、所有货物与船队状态精确一致。33组经营逻辑、24组本地界面检查通过（含完整原生触屏经营通关、真实破产、暂停/刷新和六宽度）。公开网址验证与最终部署证据将在实际取得后填写。

策略通过普通建设/购船/开始/逐回合操作，不写入库存、现金或交付状态。每个操作和回合都检查账本恒等式、非负资金、固定总箱数、唯一船舱归属、船舱容量、航道单船、节点放行与唯一交付。仅准确截止/最终回合的独立单元夹具调整时间边界。

首轮第5关双轻舟方案在第9回合耗尽周转费，只送达2/4箱。改为驳艇＋轻舟，预算仍37币、委托仍4箱，随后第11回合送齐、余5币；没有改变生产预算或库存。界面检查的一次停顿为测试API问题：Playwright对fieldset本身报告未禁用，但原生disabled属性与内部输入均已禁用，且重复空格只推进一回合；测试改为检查真正的输入控件，没有放宽生产保护。

本轮范围为Windows Chromium / Playwright及原生触屏事件。Safari、Firefox、多种实体设备、屏幕阅读器与人工经营难度尚未全面验收。玩法有意简化为固定候选网络、离散回合和整程承运，不作现实运输网络或经济系统仿真。
