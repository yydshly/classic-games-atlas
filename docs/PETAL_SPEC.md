# 花笺连线 · 第十二款固定范围与验收

20 关原创配对连线解谜。同图案之间用横竖线连接，最多两个拐点，可沿棋盘外侧一圈绕行。原创花笺图案、纸张主题、地图、界面和合成音效；不复制既有游戏素材。保留 72 条图鉴和前十一款，无付费服务、账号或凭据。

- 前期介绍相邻、直线、一折、两折及外圈；中期加入固定石障和异形留白。留白可走线但不放牌，石障不可穿过，其他花笺不可穿过。
- 第 9–14 关每次消对后向下归拢，第 15–20 关向左归拢；仅在连续纸格区段内移动，石障和留白隔开区段，顺序保留。移动后的无可连对状态立即处理。
- 每关两次洗牌，可主动使用；无可连对时自动使用一次。重排剩余花笺和空位，图案数量、固定障碍与留白保留；重排结果经生产移动规则验证可清空。次数耗尽且无可连对则明确失败。
- 每关四次同图案却无通路的容错，第 4 次错误后失败。选中同格取消，不同图案改选，均不扣次数。提示显示一对合法连线，不消耗容错或洗牌；提示/洗牌会影响个人分数。无强制倒计时，布局与路径是主要挑战。
- 连线、消除、归拢、洗牌动画期间锁定棋盘，重复点击不重复消对或计分。最后一对完成后直接胜利，不再误判无解。暂停冻结全部阶段计时，重开取消旧流程。
- 完整键盘选格/配对、鼠标、触屏点按，教学、胜败重试、选关解锁、存档、个人最佳和声音开关。稳态保存；动画中刷新回到此次操作前的完整状态，恢复先暂停。

测试路径转弯数、边缘绕行、遮挡、相邻、同格、重复输入锁、最后一对、移动与可解性、无解洗牌、暂停、重开和存档。20 关用生产规则正常配对求解，并在实际浏览器正常输入通关；不删除真实棋子或直接写胜利。固定默认布局与随机重排样本边界明确。回归导航及旧游戏，独立代码提交、Pages 成功、公开资源版本一致后交回主对话继续接续。
