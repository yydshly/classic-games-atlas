## 实际动作反馈

- 玩家圆圈和敌人菱形在人物、灯车重叠处仍可见，定位参考真实脚点；避让标签的位置可以偏离本体。朝向错误或未追近仍会空挥，脚点标记不会自动瞄准或命中。
- 实际出现纸鸢影锁定直冲、监守直冲锁线、横扫锁区及青色破绽。普通移动、转向、连击、纵深闪步、灯车停靠／恢复跟随均可操作。
- 第三关 27.4／27.9 秒，护势中回风 −5、归巷 −7；普通敌对应 −20、−28。35.9／36.4 秒，破绽中探灯 −24、回风 −30，相比普通 16／20 为 1.5 倍。这些有实际伤害日志，不只是标签出现。
- 34.2 秒 W+K 移出锁线，随后冲锋／收招期间自身 48、灯车 66 保持；回位、朝右追近后才反击命中。21.3 秒也移出直冲，之后曾因方向和距离不合空挥。移出攻击区域不等于触发闪步无敌接触计数：终局“避开”统计为 0。
- 第三关实际两次近车灯露分别使自身／车 103→120／66→86，以及 86→120／70→90，各消耗一份。终局累计自损 123、车损 74；治疗不能把这段记录算作无伤。
- 修补前首关也实际观察到灯车 66→86、灯露 2→1；E 停靠后车进度停止，恢复跟随后继续推进。护车和玩家生存不是同一个目标。
