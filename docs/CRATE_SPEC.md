# 仓格计划 · 第五款固定范围与验收

在同一仓库 main / Pages 持续扩展，保留 72 条图鉴与四款已发布游戏。本轮完成第五款后返回主对话接续下一款，不把阶段成果称为项目终点。

## 固定范围

原创推箱子式解谜《仓格计划 / Crate Plan》，20 个原创手工或验证生成的关卡。从单箱转向、双箱让行逐步进入三至五箱调度，地图规模和已验证解法复杂度逐步增加，不照搬著名题图。

- 四方向网格移动，只能推一箱、不能拉；箱子全部归位获胜。目标被箱子覆盖仍有边框与状态标记。
- 不限次数撤销，包括胜利后撤销；重开、选关、逐关解锁，完成后继续下一关。
- 保存个人最少步数、个人最少推箱次数，不显示无依据星级或“最优”承诺；两项个人最佳可来自不同完成局。
- 保存当前局合法动作记录，刷新可恢复棋盘和撤销历史；切关/重开开始所选关卡的新局。教学、音效开关与存储受限回退。
- 键盘与触屏方向盘，短按一步、长按受控重复，快速输入按顺序处理；关卡切换清空旧输入，避免误触。可点相邻格移动。
- 只提示“非目标静态墙角中的箱子”，不阻止继续操作，不把复杂局面武断判为死局。
- 原创布局、几何美术和 Web Audio 音效，无新服务、账号、付费依赖或原作素材。

## 验收清单

1. 边界、墙、双箱阻挡、正常推箱、目标归位与箱覆盖目标；非法移动不计步，不写撤销记录。
2. 多步撤销、推箱撤销、胜利后撤销、重开、快输入、切关残留按键，短/长触屏输入。
3. 静态非目标墙角提示准确；普通墙边、目标墙角与暂时被其他箱阻挡不错误报警。
4. 解算器找到全部 20 关的正常动作解，保存路线，并用生产规则逐步复核；不声称路线全局最优。
5. 优先通过真实浏览器键盘把全部 20 关走完，正常解锁下一关，不直接修改玩家/箱子/胜利状态；另测触屏。
6. 解锁、个人最佳、当前局与撤销历史重载；声音、教学与受限存储。
7. 图鉴 72 条、前四款入口、移动视口、控制台与资源回归；独立代码提交、Pages 成功、线上核心行为和文件版本核对。

可并行高效补验光轨剩余九关，每关有界运行，不因反复尝试拖住第五款；发现运行缺陷才独立修复提交。
