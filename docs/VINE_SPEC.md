# 青藤回廊 · 第十一款固定范围与验收

16 关原创生长藤蔓挑战，20×16 格。收集青芽逐格增长，达到本关目标后再抵达出口。闭合回廊、障碍、逐渐加快的节拍和定向传送门逐步引入；地图、叶片、植物主题、界面及合成音效原创，不复制诺基亚画面或原作关卡。保留 72 条图鉴和前十款；本关卡项目无无限模式、联机或新服务。

- 自动向当前方向前进；方向键 / WASD、触屏滑动和方向按钮。滑动位移超过阈值即提交，每个手势只提交一次，无需等到抬手。最多缓冲两次不同转向，按已排队的方向校验，拒绝瞬间反向和重复输入；每次移动只执行一项。暂停、失焦和传送后清空旧方向缓冲。
- 非增长步可以进入本步将离开的尾格；增长步尾格保留，因此会碰撞。墙、身体、传送入口或落点碰撞先于食物与出口计数，最后食物不能抵消同帧碰撞。
- 传送门是单向的：进入带编号的入口后，头部落在同编号出口格，并按出口箭头改变方向；落点仍参与身体碰撞。入口不保留为身体格，传送不消除身体；下一步从出口格前进。旧转向缓冲清空，避免坐标系变化后意外拐弯。
- 食物只在尊重当前方向、障碍、传送规则和身体占位的可达空格生成，不在蛇身、墙、传送门或关卡出口上。优先在前方若干格萌发；暂时没有合格空格时明确显示等待，继续正常移动释放空间后再尝试，绝不移动现有食物。闭合有效路线与最大蛇长逐关校验，避免制作永久封闭且无法完成的默认关卡。
- 达标后出口点亮；未达标时出口可穿过，进入已点亮出口才通关。食物目标、蛇长、步数、分数、传送次数和节拍清楚显示。
- 教学、失败重试、暂停、16 关解锁、本地最佳、声音开关及逐移动步存档。恢复棋盘、方向、食物、RNG、目标进度；恢复时暂停并清空方向缓冲，继续后等待完整一个节拍。胜败后刷新重新整备。

测试覆盖尾格、增长碰撞、快速转向、传送方向/落点、可达食物/暂缓生成、出口、最后食物与碰撞、暂停/重开、存档和触屏无滚动。16 关使用生产规则正常方向动作通关，至少首/中/末实际浏览器输入，尽量全关；不移动食物、删身体或减速证明通关。回归图鉴与前十款入口，独立代码提交、Pages 成功、公开地址和文件哈希核验后返回主对话接续。
