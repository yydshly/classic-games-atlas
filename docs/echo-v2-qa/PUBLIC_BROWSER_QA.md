## 首关普通撤离

1. 开始后按2切换破阵散射，W前进，巡猎者可见并追近，出现蓄光警告环。D侧移、S后退后显示“预警光束落空或被墙遮挡”，光息仍为100。
2. 在119秒、100光息、8光匣、散射状态暂停并刷新。这些数值及地图位置正确恢复，界面显示暂停中，没有离线推进。
3. 瞬时射击输入没有观察到开火。使用正常按住J约220毫秒后，散射命中巡猎者，记录伤害−36，光匣8→5；该敌随后从地图消失。这里没有把瞬时点击等同于持续按住，也没有修改攻击规则。
4. 沿左下通道移动取得琥珀钥匙，再沿下方通道绕墙拾取6光匣，5→11。另一浮空守卫接近，但没有被消灭。
5. 继续绕行，持钥匙按E开门，到出口再按E，正常显示“撤离成功”：剩109秒、光息100、消耗3匣、平息1个守卫。这条实玩路线验证无需全灭即可撤离，不代表所有路线或后两关通过。

## 活动局恢复与终点刷新是两种不同结果

中途暂停的119秒/100光息/8匣/散射和地图位置恢复通过。

撤离结算后刷新，页面回到第一关初始：120秒、100光息、8匣、精准脉冲。当前控制器在 won/lost 状态清除会话存档，这是当前持久化设计边界，不能写成“终点恢复通过”或“结算保留通过”。本轮实际观察的是 won 后刷新；自然失败及 lost 后刷新没有实测。最后停在刷新后的第一关初始界面，没有再跑。
