# 潮汐珠径 · 第二十款固定范围

十二条独立原创连续曲线，浅湾/礁池/月汐三环境。用弧长而非曲线参数推进珠链，各关基础速度同为12；变化来自两至四色、单珠/双珠配比、路径观察角、礁屏遮挡和少量能力，不按关数暗加速。每关固定一条已显示的有限珠链，无隐藏补珠；新发射珠也需要清掉。

- Catmull–Rom曲线每段80采样，累计弧长二分插值得位置与单位切线。珠半径12.5、中心弧距27，固定1/120秒。物理弧长不随弯道忽快忽慢，所有球保持顺序与最小间距。
- 旋转瞄准、直线发射；对运动珠用相对位移扫掠圆碰撞，礁屏用扩张矩形扫掠，最早碰撞生效，礁屏同距优先。按接触点相对路径切线判断前/后插入；只把必要的前段推开。礁屏仅挡发射珠，路径与礁屏不交叠。
- 连通的同色三颗以上消除；断口以220的速度拉近前段，保持每个相邻间距不小于27，闭合后再检查同色组。发射/衔接期间锁定下一发与换珠，防止连锁被新输入打断。每组只消除存活ID并计分一次，连锁深度延续到本发衔接结束。
- 弹仓只从场上仍存在的颜色里抽取，确定性洗牌袋；清空某色后剔除该色，当前/下一颗若失用立即改为仍有用途颜色。X换珠仅交换两颗，不额外生成颜色；换珠至少间隔.2秒。所有颜色都有独立形状，配色不是唯一识别方法。
- 第4关起缓潮两次，每次五秒降至40%推进；第7关起回汐一次，整链后退110弧距，靠入口时限制到不越过起点安全距离。只在发射准备状态接受能力，不叠加缓潮，不回补次数；无有效后退空间不消耗。
- 任一珠中心加半径到达终点即触线。同一步先触线又清掉末珠，触线失败优先；插入推前造成触线也计入。否则整条链清空才赢，结算一次。五分钟观察上限，正常不操作会自然触线失败。
- 鼠标移动/点画布瞄准发射；触屏点画布或拖瞄准后松手发射，近发射器和画布外松手可取消。大按钮发射、换珠、能力；左右键连续转向、Enter/空格发射、X换珠、1缓潮/2回汐、P/Esc暂停、R重来；角度滑杆与微调按钮。准备时全场可见且静止。暂停/菜单/失焦/取消指针清输入，旧手势不补发。
- 教学、十二关选关/解锁、重试、最好成绩、合成音效。保存正式tick和普通fire/swap/slow/back日志，恢复由同一引擎重放并暂停，飞行珠、弧距、断口、分数、弹仓、随机袋、冷却、能力次数均延续。不信任外来珠位/颜色/速度/分数；坏当前局拒绝，合法解锁与最好保留。只存本浏览器，不是防恶意本机编辑的安全系统。

正常策略允许在副本中用相同正式规则预测瞄准角，真实局只接收普通输入。验收要求十二关生产模拟与公开网址真实操作全部通关，不改珠位/速度/颜色、不直接删除珠子或写胜利。记录真实误发/遮挡、连锁、能力与资源，自动策略不冒充人工难度体验。另测弧长、插入、间距、跨断口、抽色、末珠/触线优先、唯一得分、连续输入、暂停/恢复/刷新、原生触屏、窄屏和公共入口。保留前19款及72图鉴，独立main提交、最终Pages及运行文件核对后交回主对话。
