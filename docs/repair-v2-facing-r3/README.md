# 修理所 v2 · r3 朝向与步态修复

用户2026-10-18反馈“人物好像倒着走”。实机QA进一步观察首日信使从左向右约220像素移动时，头/胸仍保持左前朝向。源码也证实 r2 只按时间选步态，从未使用 path 方向。

## 修复范围
1. 新增纯展示模块 facing.mjs，读取实体下一非零真实路径点，用屏幕投影后的 dx/dy 选右/左/前/后。机器人和调岗技师同时使用；规则和实体状态不写回。
2. 原创 Blender 模型真实旋转为4方向，4机器人×4方向×4步态 + 3技师×4方向×4步态，共112帧。向上看到背面、左右侧面不同，未用头部替换或帧序倒放。
3. 修复步态：本地前方为−Y，支撑脚相对身体向后(+Y)移动；回摆脚向前(−Y)时抬起。左右方向共用正序循环，通过模型真实旋转对齐，不反向播放。
4. 使用Blender相机投影的世界地面原点(128.00009,264.63269)，目标104×130贴图偏移−52/−107.507，使阴影与脚底采用同一锚点；删除额外整个人物上下浮动，腿部动画保留。
5. 图片未加载时也用低细节、有方向的行走回退图形；减弱动态模式保留正确朝向，只固定步态帧。
6. index入口/controller import/新图集显式新版本，避免旧renderer缓存。
