# 星泡航线 · 第三款固定范围与验收

本轮先补爆破迷宫第 2–9 关正常浏览器输入验证，发现规则阻塞则先独立修复发布；不把自动操作失利直接当作游戏不可解。然后完成第三款，在第三款上线后结束本轮，不开发第四款。

## 固定范围

原创单人泡泡解谜《星泡航线 / Starline Bubbles》，至少 12 张布局、颜色数量、悬挂结构和深度有差异的原创关卡。以瞄准发射、侧墙反弹、同色三连、顶端连接与掉落为通用机制，不复制原作关卡、美术或音效。

- 六邻接错位网格，连续飞行与侧墙反射，附着在碰撞点邻近的合法空格。
- 同色 3 个以上连通消除；失去顶端连接的泡泡整体掉落。
- 只从仍在场的颜色生成弹药，颜色袋限制长期缺色；显示当前与下一颗，可每发交换一次。
- 明确有限发射次数，清场获胜；弹药耗尽且未清场或接触底线失败，结算/重试/暂停/重开齐全。
- 瞄准轨迹与落点提示，鼠标瞄准点击、键盘方向与发射、触屏拖动瞄准及独立发射按钮；每种颜色同时使用独特图案辨识。
- 十二关逐关解锁、最佳纪录、教学记忆、音效偏好、本地保存与存储不可用提示。无账号、后端、联网对战、付费或新增运行依赖。

## 验收清单

1. 连通分组、六邻接边界、顶端孤岛判定、三连门槛、附着网格与满格碰撞。
2. 两侧墙面反弹、边界碰撞、轨迹预测与实际飞行一致，正在飞行时重复点击不消耗额外弹药。
3. 颜色耗尽后弹药更新，清场优先于弹药耗尽失败；底线、失败、暂停/重启、交换限制。
4. 所有 12 关用同一物理和规则解算并保存解法；这是模拟证据，不冒称浏览器实玩。
5. 首/中/末代表关卡通过正常鼠标、键盘或触屏输入实玩清场，不注入胜利或删泡泡。选关夹具只开放菜单，须注明；首关自然解锁与存档恢复。
6. 窄屏、键盘与触屏、教学/暂停/重试/声音、本地存储受限回退，图鉴 72 条与前两款入口回归。
7. 独立代码提交至 main，Pages 实际成功；线上核心流程实玩、控制台/网络与发布文件逐项版本核对。准确列出未覆盖项。
