# 新玩家旅程：选游戏到返回大厅

以堡垒防线 v2 为完整普通 UI 样本。基线 `67558a9d9548ad563cefe08d106276e2fdf7aa42`，桌面 1440×1050、390×844 CSS 窄屏模拟。只检查首页选款、理解来源/原创范围、进入推荐版待命、找到说明、退出回目录；未重复通关，也不代表40款出口均已验收。

[截图与逐步说明](index.html) · [普通 UI 报告](report.json) · [修复前观察](before.json) · [技术测试](navigation-tests.json) · [首页](../../index.html#play)

实际复现并修复：

1. 对照弹窗写“当前为 v1”，首页主按钮却进 v2。现顶部明确“首页入口为 v2”，保留旧版证据的版本标签。原作是 Battle City 的参考关系及本作原创两图、简化范围本来已有说明，未改写成复刻。
2. 堡垒 v2 唯一返回链接是“原版十关”。经旧版才能回首页。现增加直接“游戏大厅”入口，保留旧版入口。
3. 上述退出后筛选丢失，且落入很长的旧原型档案区。现从大厅普通同标签页试玩后返回，恢复搜索、版本、已展开数量、离开位置及主启动链接焦点。仅使用独立的临时目录返回记录，不读取或修改任何游戏存档。直接新开首页不沿用旧记录；记录一次消费，存储不可用时导航仍正常，不宣称已保存游戏进度。

普通 UI 全程只用键盘、点按、滚动与页面导航，没有注入状态、时间、胜负或存档。未开始战局。7组技术测试单列，包括40条当前版本提示分类、同域边界、错误/过期记录及模拟写入拒绝；这些夹具不是真实设备存储故障。原生导航和重新筛选取消的图片请求以 `navigationOrRerenderCancellations` 单列，不冒充资源404；通过报告没有控制台错误、HTTP错误或其它请求失败。

采集时保留了导航load等待超时、稀疏预览缺图及候选焦点误落缩略图的尝试记录。前两项按采集/环境问题处理；焦点优先主入口已修正并重新通过。公开截图均为当前审查实际捕获、未经裁切重绘的已核对视口。未发布本地路径或失败堆栈。

40项目录、旧版/停项、引擎、关卡、游戏存档及所有原始数据/素材保持。样本之外的每款导航入口未逐一审查；真机触控、性能、读屏、声音、审美、真人首次理解与持续手感仍需单独验收。源码来源/机制的既有产品差距不因本次路径通过而消失。
