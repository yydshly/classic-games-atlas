# 回声走廊 v2 · 余烬协议

第33项独立候选，2026-10-18。原有 `games/echo/` 与 `versions/v1/games/echo/` 均保留；本轮不新增第41项。入口为 `versions/v2/games/echo/`。这不是《DOOM》的移植或完整复刻。

## 参照与已存在的能力

参照口径是初代经典《DOOM》，不是2016重启版，也不以跳跃或垂直瞄准为初代缺失判据。[Bethesda官方产品页](https://doom.bethesda.net/en-US/doom_doomii)确认经典作品与现代合集的区别；现代合集附加内容不能倒推为1993版的规则。2026-10-18查阅了[id Software公开敌人逻辑](https://github.com/id-Software/DOOM/blob/master/linuxdoom-1.10/p_enemy.c)和[武器定义](https://github.com/id-Software/DOOM/blob/master/linuxdoom-1.10/d_items.c)，仅用来核对动态敌人与多武器结构，未复制其代码或素材，也不声称本作重现其精确行为。

旧回声走廊已有8张单层地图、真实水平移动与侧移、光线投射遮挡、钥匙门、有限补给、静止敌人锁向蓄力攻击、暂停与日志重放。旧源码中的敌方更新只蓄力/发射，没有敌人位置更新；单一光脉冲12伤。不能把这些既有能力误写成v2首次加入。

## 本轮有限变化

- 3个固定11×9仓段：余烬入口、分流仓库、静默撤离。120秒限时；每段100光息、8光匣，独立资源。
- 巡猎者：36生命、视线追击1.05格/秒，1.15格内起手，48tick预警、16伤。浮空守卫：48生命、缓进0.55格/秒，6格射程，66tick预警、12伤。两者只在7格内且有视线时追击，蓄力停步并锁定方向，不隔墙追踪，不会复杂寻路。
- 精准脉冲：1匣、12伤、18tick冷却、9格射程；破阵散射：3匣、40伤、54tick冷却、3.2格射程，较宽容的瞄准截面，只打最近一个目标。不是多弹丸或范围爆炸。两种共享弹药，换枪不能重置冷却。
- 每关钥匙在远侧；补给有支路。持钥匙开琥珀门，到出口按E即可撤离，不要求全灭。避战与争取补给都是允许的选择。
- 原创AI生成工业机械敌人，单张透明WebP图集约121KB；程序绘制工业墙面与武器。敌人是静态billboard随模型移动，非骨骼动画或多朝向步行帧；全程只创建一次图片对象，逐帧不重建资源。
- 第一人称960×420画布和紧凑地图/操作区；桌面目标1181×757同屏。桌面实际像素与触屏体验仍需分别检查。

## 设计价值是待验证假设

视线追击让玩家需要先判断路线、再决定战斗位置；停步预警为侧移和退角提供可读窗口。高耗近战与低耗远程之间的距离/资源取舍，可能增加熟练感与即时决策；补给绕行与不必全灭的出口，可能支持多种节奏。这些是设计假设，不是已被真实玩家研究证明的乐趣、留存或满意度结论。

## 存档与边界

独立 `echo-v2-session-r1` 本地键，记录版本、关卡、固定tick和合法输入日志，不直接接受生命/位置快照。恢复重放后先暂停，清除旧按住输入；无离线推进。坏存档保留原字节且本会话禁写，仍能游玩。存储失败不阻断游戏。重试/选关清除合法旧会话，不清除损坏记录。无账号、后端、联网对战或付费功能。

没有完整DOOM武器库、怪物阵容、多高度关卡、投射物体系、秘密房/大型关卡、多朝向角色动画、音效或音乐；不宣称完整FPS成品。现有工程测试与离屏截图不能代替浏览器实玩和玩家品质验收。
