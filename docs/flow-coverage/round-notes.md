# 本轮截图时序与执行恢复说明

本轮只验证溪谷第二场、光轨第二至十二关、花笺第十至二十页；不等于四十款全关卡验收，运行代码未改。

## 光轨第十二关的即时截图

[第十二关原图](../prism-later-qa/level-12-attempt-1-won.png)中结算面板是5125分、157.9秒，侧栏仍是最后一次采样的4235分、51/52和余1块。原图保留，不裁改或用合成图补成一致。

[实际顺序实玩记录](../prism-later-qa/public-report.json)在同一自然终局读取到remaining=0、destroyed=52、score=5125，原生存档也写入5125；之后十二关最好、最后关重试和刷新已验证。这些结果与即时截图的HUD采样时刻分开陈述，不把原图说成“所有数字同帧同步”。

[生产控制器源码](../../versions/v2/games/prism/game.mjs)的frame持续requestAnimationFrame，HUD约每80毫秒刷新；据源码推断，抓取刚进入胜利状态的截图可能先看到结算面板、后看到HUD更新。该原因属于推断，不是对第十二关延迟后画面的重新实拍。

为排除同一控制器的持续终局显示错误，另用正常鼠标、发球完成一次首关，等待150毫秒后读取实际HUD：1800分、0块、20/20、最好1800均一致。本次首关的即刻采样也一致，因此它没有精确复现第十二关的短暂时差。参见[独立实际记录](prism-terminal-hud-probe.json)、[原生首关图](prism-first-stage-hud-after-150ms.png)、[脚本](prism_terminal_hud_probe.py)。它不是第二次第十二关通关，也未注入终态。第十二关在150毫秒后的同步画面仍未单独实拍，作为证据边界保留；未据一次即时截图修改物理、规则或难度。

## 花笺执行中断与正常恢复

原执行会话句柄失效后，只读检查发现旧Python/浏览器进程已不在，原报告停在已完成1–16页且未写终态，原因未确认。未将中断说成游戏失败或20页完成，也没有重复提交任何不确定发布。[旧记录与执行核查](../petal-later-qa/execution-interruption.json)及[中断原数据](../petal-later-qa/interrupted-report.json)保留。

恢复使用新的隔离原生持久浏览器，通过页面提示和正常点击重新取得必要前置，再完成17–20及终局。没有导入存档、改解锁或跳过关卡。完整恢复运行的实际数据见[花笺报告](../petal-later-qa/public-report.json)。重走前页是执行中断后的必要前置，不作为新增测试主题或无辅助成绩。
