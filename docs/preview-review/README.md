## 实测结果

- [35 晴湾篮场](./court.md)：首场8:6、第二场解锁与刷新保留最佳+2；宽窄布局及按钮失焦取消通过。其余七场及更多边界待验。
- [36 雨街修理所](./repair.md)：前两日自然结算分别8单/311币和10单/356币，均0流失；刷新保留第三日解锁。400/500 CSS三态布局回归和建设派工存档通过。宽屏底部按钮仍需约13px微滚。
- [38 云岬游乐园](./coaster.md)：前两园真实完整通关；活动局优先恢复、结束局刷新进入最新解锁园已复验。后六园待验。
- [39 林野杯赛](./kart.md)：首站双圈67.6秒、第4名，正确未达标；失败、重试、道具入口与布局已验。胜利解锁链路待低延迟人工操作验证。
