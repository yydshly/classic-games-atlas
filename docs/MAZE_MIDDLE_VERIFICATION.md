# 爆破迷宫第 2–9 关补验

本轮在第三款实现之前，用正常 Chromium 浏览器键盘补验中间八关。不录制八段完整视频；保存结算截图、按阶段状态和失败尝试，避免录像增加验证成本。

每关使用隔离存档开放选关菜单，然后全程通过键盘移动与放弹。没有注入胜利、删除敌人、更改生命或加速时钟。完整汇总在 [middle-summary.json](maze-qa/middle-summary.json)；对应 JSON 中有逐段状态和最终状态，PNG 是实际结算画面。

补验期间没有修改游戏运行文件；`engine.mjs`、`levels.mjs`、`renderer.mjs`、`game.mjs` 与已发布第二款 `3d375fb` 相同。只调整了验证程序的输入规划：受伤保护时允许正常撤离，避开即将爆炸的火线，使用可达路径评估追踪机距离，避免把隔墙距离误当作即将接触。

失败尝试完整保留，不计为通关；它们曾暴露操作程序在窄道中拒绝移动的问题，未发现确定的游戏逻辑阻塞。已有首关/末关通过不用于替代本次中间关卡验收。
