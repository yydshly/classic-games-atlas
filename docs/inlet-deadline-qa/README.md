# Inlet v3 期限预览候选

独立于线上版本；尚未真实浏览器复验，不以模型测试作为手感或趣味证明。

## 玩家问题与修复
第 2 湾从出生点合法沿岸走 7 格向右、1 格向下到 (8,1)，不改任何状态地等候：
- 84.00s 向左可在 84.86s 闭合；同位置向右原先也显示“预估可闭合”，实际 85s 超时，闭合数为 0。
- 84.40s 向左也原先误绿；仅余 0.60s，原 HUD 却四舍五入显示 1s。
- 84.14s 向左是另一种边界：85s 确实闭合一次，但整湾目标未达而超时；不能说成“没闭合”。

现在只在模拟实际闭合且未超时失利时显示可闭合。未闭合超时、同一步闭合但整湾超时、碰撞分别给出真实结果；未知未闭合不猜安全。期限不足按钮与落脚标记不再用安全色。余时显示两位小数，与 0.02s 模拟步长一致。期限、难度、敌人、布局、移动、胜负顺序和存档格式均未修改。

## 固定步 ETA 复核
满移动时钟也必须等下一次 0.02s 逻辑步才移动；不再把它当作瞬间移动。本例闭合 ETA 已由 0.84s 改为真实 0.86s。首步按时钟余量向上取整到逻辑步（至少一步），后续格仍用原移动节奏。没有改变 tick 或时限规则。
`forecast-audit.mjs` 可重复扫描并逐一核验 710 条可闭合路径的 ETA 与真实闭合时刻一致；边界测试同时核对碰撞时刻及超时前未闭合。

独立复核额外覆盖 102 次预览：移动时钟全部 7 相位、4 种子步 accumulator、70 次开放线续行；49 次实际闭合 ETA 误差小于 1e-8，46 次碰撞时刻一致，102 次暂停预览无状态改变。原模型与合成 DOM 回归仍过；这不替代真实浏览器视觉验收。
