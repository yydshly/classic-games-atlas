## 已确认缺口与最小改进

本轮公开页面普通UI：营地卡片只显示属性、定位与成长；选队前看不到技能名、消耗或作用。现有“玩法”源码提供公共流程/属性/技能概述，没有逐位技能摘要。这里是编队信息缺口，不是战斗不可用或任务判定错误。

在原有伙伴卡片内常驻显示技能名、固定消耗2能量和基础作用，不加按钮/弹层/折叠状态。复用原SPECIES.skillHint定义，将攻击明确为**基础威力10**，治疗/安心明确为**最多**，护盾为本次18；没有目标时不计算或承诺精确伤害。成长后营地注明**轻击威力+2**，不将该加成套给技能。相遇/终挑战继续使用原动态技能预览。

## 步骤与健康状态

1. **已验：选队前。**三位原有伙伴的固定技能作用可读，无额外Tab停靠点。
2. **已验：普通键盘换队。**Enter让岚翎留营、Tab跳过唯一留队的不可移除伙伴、Enter选择澄汐；队伍严格保留原追加顺序`[b,c]`，焦点可见。刷新后队伍/领队/进度精确保持。
3. **已验：回到探索。**正常调整到`[b,a]`，岚翎领队，普通出行与羽结招募；场内无营地摘要，原动态缠风仍预览15实际伤害，营地只写基础10。
4. **已验：新伙伴入册。**回营后晶雾芽显示固定安心/减弱作用；正常键盘换入，队伍顺序`[a,bud]`保留。
5. **已验：成长后。**再出行切磋使岚翎按原规则成长，回营显示轻击加成而技能基础仍10；再次刷新精确保留。

本地1440×1000/390×844各27个记录动作、7个截图观察点、2次精确刷新。修改前后14份完整游戏状态、全部动作及原生Tab顺序一致。公开报告保存观察字段与完整origin/commands，原始完整快照留在私有测试目录。已知路线/策略脚本辅助；不注入游戏、时间、体力、存档或结果，不是无辅助玩家理解证明。线上在发布后同范围核验，实际结果与SHA在交付记录另列。

16组**离线模型fixture**：五位伙伴的摘要只读且不随成长/残余能量误变；两类相遇各五种技能与原模型实际消耗/作用对照；满体力治疗实际0而营地正确写最多28。fixture不安装到浏览器。普通UI本轮显示四位伙伴，第五位露纹鳍的规则摘要仅模型覆盖，不冒称本轮真实招募五位。
