# 星羽同伴 v2：回声浅滩

状态：独立有限候选，尚未公开浏览器验收，不代表完整游戏或用户品质认可。原有8章战斗与全部旧34运行文件保留。

## 本轮要补的核心

原32《星羽同伴》在基线 `ceb6edce9a21ab86eefb0aeeb343fa71378830d4` 实际有8章固定三伙伴回合战斗、风/苔/泉相克、技能、有限补给和合法命令恢复，没有地图探索、捕捉或持续队伍培育。

本版只验证一条短链：选择两位同行 → 沿一处小区域真实移动 → 遇见两种已有原创生灵 → 切磋削弱或安抚 → 用有限羽结尝试招募 → 回营让新伙伴加入 → 改变下一次队伍 → 记录一次有限成长。

这是新的独立模型，不是找回隐藏在旧引擎中的功能，也没有改良或替换旧引擎。旧引擎把固定HEROES、章节敌群和每章预算直接耦合，不适合通过外围剧情卡冒充持续招募；本版重新实现旅途状态机，仅沿用项目已有原创伙伴、属性相克概念和合法命令重放思路。

## 参照范围与证据

目录的参照是宝可梦主系列，用户没有指定具体世代。本版没有自行把某一代设为复刻目标，不复制宝可梦角色、名称、界面图、地图或声音。

参考的是“探索发现不同伙伴、捕获选择、队伍互补与培育后再出行”这一层价值。以下官方来源支持该层机制的存在，但不证明它解释销量，也不证明本实验会产生相同的情绪体验：

- [宝可梦官方家长指南：Video Game Basics](https://parents.pokemon.com/en-us/video-games-and-apps/)：遇见/捕获记录、多样伙伴及不同技能与后续挑战的联系。
- [《晶灿钻石／明亮珍珠》官方战斗指南](https://diamondpearl.pokemon.com/en-us/trainersguide/fundamentals/battling/)：野外相遇、削弱而不击倒、捕获可能失败、换队与资源行动取舍。此页作为明确版本的机制例证，不把本版写成该重制版的复刻。

上述页面于2026-10-18读取。安抚、羽结、日光、2人队和本版数值是原创实验规则；不冒称宝可梦跨世代统一规则。具体作品的亲密度、进化、图鉴、交易、育种及社交意义不在本次范围。

## 有限参数

- 一张回声浅滩画面；9×5逻辑空间里只有17个连通步点。真实渲染锚点沿绘画干地和沙路布置，不铺大网格，也不允许踩入池水/岩石。方向键/WASD、原生方向按钮或点击相邻亮点移动。
- 起始仍为岚翎、苔灯、澄汐。出行队伍2位，需让一位留营才能换入新伙伴；领队决定本次技能和来招属性效果。
- 野外只有原项目已有的晶雾芽、露纹鳍两种，不增加新物种。每次出行各触发一次，莓丛也只采一次。遇见记录持续保留。
- 每次出行24日光、2羽结、2露莓，所有伙伴回满体力与3能量。移动和每次相遇行动各耗1日光；营地整备及主动安全回营免费，无现实等待、每日奖励、连续签到或离线推进。
- 露莓共用：分享使安心增加20+伙伴安抚值；吃掉恢复26体力。绕路莓丛多1颗，但付出日光。不能同时消费同一颗。
- 轻击按基础威力×属性系数向下取整，风克苔、苔克泉、泉克风1.5倍，反向0.75倍。攻击增加警觉4；打到0则结束切磋、本次不可招募。各伙伴另有独特2能量技能，守息回1能量并挡本次16伤害。
- 羽结成功率 = clamp(22 + floor(50×损失体力比例) + 安心 − 警觉, 5, 88)。每次消耗1羽结，无退款；失败安心−10、警觉+8并承受来招。没有100%保证。概率不是来自宝可梦公式。
- 野外以试探、观察、重击循环；安心≥30来招×0.65。弱化仅在真正来招时扣次数，观察不扣。技能与数值见model.mjs。
- 成功招募先进入本次同行名单，回营后才加入可编队名册。任意失败回营也保留已经招募的伙伴。已加入种类不重复消耗羽结；可以切磋或安心达到60后和平道别。
- 参与有结果相遇的伙伴获得1经历，2经历成长一次：体力上限+8、基础威力+2。之后不再加级。无大地图、联网、交易、装备经济、全套养成或无限升级。
- 两位同伴都倒下、日光用尽、主动回营或走回营地都能安全结束出行并免费重试。不会永久失去伙伴。

## 本轮验收五项

1. 正常输入可以从营地走到不同目的地；绕路采莓、移动、相遇行动真实改变日光/资源，并有可读路径和遭遇点。
2. 切磋与安抚对体力、安心、警觉和捕获率的影响不同；轻击到0会真实错过本次招募。
3. 成功与失败捕获都按规则扣资源；失败不是剧情预设自动成功；两位倒下、日光尽、主动退出均可回营再试。
4. 回营招募真实增加名册；新伙伴换入、独特技能和一次成长真实改变下一次遭遇状态。
5. 新存档key `classic-atlas.feather.expedition.v2`，种子+合法命令重放固定随机状态；刷新不会给同一次羽结重掷。旧key `classic-atlas.feather.v1` 和8章入口不变。单份记录上限4000条合法行动；页底可确认清空本版重开，不影响旧存档。无法恢复的原值先保留，临时游玩不覆盖。

模型验证与实际渲染离屏图只分别证明规则/绘制可运行，不能代替公开浏览器正常操作、窄屏布局、真实输入、存储可用性或玩家感受验收。没有使用本地Chromium重试已知socket拒绝。

## 美术边界

回声浅滩绘画底图和五位伙伴均为本项目原创AI辅助美术。伙伴为单张静态关键姿态；大小、朝向与脚锚随实际场景展示，不宣称完成行走/受击/施招动作动画。离屏图必须注明不是浏览器截图。美术素材的透明边缘、角色裁切和路径位置在实现记录单独检查。
