# 遗迹灯火 · 第24款固定范围

8关、35间相连原创石室，苔影/铜阶/霜廊三环境。小型格子节拍地牢冒险；一键一拍，由玩家主动移动、横扫、闪步、等待、恢复或互动后推进敌方。无自动时间倒计时，站定可思考，不宣称实时反应型动作或大型RPG。

每房9×7格，边墙与内柱阻挡；只有开放门可切房，进入对侧内缘并有到达宽限。移动一格，碰墙/敌人/闭门不穿过，但尝试会转向并推进一拍。闪步最多两格，仍受墙/敌人阻挡且不跨门；当拍及下一拍短暂保护，4个其他行动后可再次使用。横扫1格8邻域，视线/墙角阻挡，2个其他行动后可再次横扫。无效冷却攻击不推进拍数。

苔卫2血，近身预警目标格；棱眼2血，直线视线内预警到墙的光束；壁铠3血，近处预警两格十字，斜角有空隙。敌人意图锁定2拍后命中原区域，随后恢复2–3拍；不造成无预警接触伤害。受击一次扣1、获得短暂冷却，同一拍多源不会叠伤。石刺随全局拍数6拍循环，3相位预警，4/5相位激活；站定不推进。

初始6体力、2药露，药露回2且不溢出，满体力不消耗。有限地面药露只拾一次，不自动治疗。钥匙与遗物各有唯一ID，钥匙门只扣1且两侧永久共用；灯门需指定灯座已亮，封门需指定房清开。灯座要清开本室并靠近互动；全部灯亮、归庭清开、靠近归途门互动才成功。离房保留敌人位置/体力/蓄力、物品与门锁，不刷怪、不回满体力、不重生补给。第8关终钥门另需北灯，避免第一钥匙误花造成不可恢复死局。

教程、地图/门条件、敌人文字状态与橙格倒数、命中/受伤反馈、死亡重试、8关解锁、最好成绩、原创Canvas与合成音。键鼠和触屏大按钮：方向/WASD移动、J横扫、K准备闪步后选方向或Shift+方向、H药露、E互动、空格等待、P/Esc暂停、R重整；鼠标点相邻格移动或邻近敌人横扫。按住键不连发。
