# 弯道邮差 · 验收与证据

第十六款固定范围见 [POST_SPEC.md](POST_SPEC.md)。8 条原创闭合赛道，三种环境；前四条两圈、后四条三圈，共 20 圈。加速、相对车头的左右转向、刹车、路肩减速和弯道路线为核心，非纵向躲车换皮。车辆、场景、地图、SVG 与合成声音原创。

## 规则与正常驾驶

[20 组规则](post-qa/logic-report.json)检查：赛道/闸门/安全点；三秒倒计时不可偷跑；加速转向、停车不能原地旋转；松油减速、制动不倒车；固定步长和生产速度限制；路肩减速；外沿碰撞与主动复位的安全点、加时和输入锁；扫掠闸门高速穿越、逆向/远侧/重复穿线拒绝；漏门和终点来回不能刷圈；完整圈顺序/路线进度；逆行提示；不连续路线跳跃；末圈唯一结算；时限同帧优先；暂停冻结；安全检查点恢复；损坏版本/圈时/闸门拒绝；恢复加时超时；步长分块一致及原始数据未修改。

隔离规则测试会设置人工位置、速度、时间与末圈状态，这是边界夹具，绝不作为正常通关证据。地图参数末尾检查未被修改。

[八条生产规则模拟](post-qa/simulations.json)只读快照并输出油门、转向与刹车，真实局仅调用发布引擎更新；不写车速、坐标、时间、闸门、圈数或胜利。八条均完成全程、共 218 次有效过闸，生产模拟零复位。实际路线、生产加速度、最高速度、刹车和时限不为测试更改。

另用[较慢目标节奏策略](post-qa/slower-input-policy.json)复跑八条，只降低普通控制策略希望达到的行驶节奏为 0.6，仍使用同一生产车辆和时限。均正常完成，用时约占时限 33%–51%；普通策略约 21%–32%。时限给学习路线、刹车与复位留出空间。这些策略能读取完整路线与车辆遥测，不是人工玩家评测，也不能据此宣称人类易上手。

## 观察到的失败与修正

保留[首次失败](post-qa/first-strategy-failures.json)和[第二次尝试](post-qa/second-strategy-attempt.json)。首轮以极小的中心线投影变化当作路线跳跃，急弯内侧正常行驶时最近投影会切换到弯后，误触复位。现连续性容差按道路宽度计算，仍保留严重越界、安全复位、路线突变和实际正向有序过闸判定。

第二次七条通过，第四条正常贴内侧仍漏判均匀布置在尖弯顶点的闸门。现在把闸门明确放到每条直道中段，既覆盖所有弯段，也避免要求玩家为触发顶点闸门而走不自然外线。不是删除闸门顺序或直接给圈数。

[首次浏览器夹具失败](post-qa/initial-browser-fixture-failure.json)中正常驾驶已胜利，但后期菜单初始化脚本每次刷新都重写本机存储，造成成绩回归断言失败。已改成仅在存储缺失时初始化菜单偏好，游戏记录逻辑不为该测试改变。截图改为异步记录，减少测试采样暂停对驾驶输入的干扰。

## 本地实际输入与界面

[首/中/终三条](post-qa/local-first/report.json)与[其余五条](post-qa/local-rest/report.json)使用真实浏览器键盘 down/up，正常完成全程并验证最佳圈速、全程、解锁及刷新全新重玩。后期赛道只用菜单解锁/教学/声音偏好夹具，实际通过菜单选择；没有时钟、闸门、车速、坐标或胜利写入。

[22 项界面验收](post-qa/local-ui/report.json)通过：真实按键倒计时/转向/刹车、锁定关卡、暂停冻结、自然驶出道路后的安全复位、主动复位加时、真实检查点刷新加时后继续通关、最佳/解锁、坏当前局、反复正常复位按钮加时导致超时后重试、合成失焦事件，以及[真实双指油门+转向](post-qa/local-ui/two-finger-steering-390.png)、触摸取消、暂停释放、画面滚动。宽度 320/360/390/768/1280，无横向溢出，起跑与选择按钮完整；[末条赛道 320px](post-qa/local-ui/final-course-320.png)仍能看到完整闭合路线和四个控制。图鉴 72、16 款/202 关及前十五款手机入口回归通过。

失焦使用合成 DOM blur 事件，因为无头 Chromium 的标签切换不产生实体窗口焦点变化；这验证处理逻辑，不冒充实体操作系统切换。真实触屏通过 CDP 多点事件模拟，未实测实体手机。
