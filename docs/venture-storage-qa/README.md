## 修前公开页面复现

这是明确的故障 fixture，不是玩家自然产生坏档的频率统计。隔离浏览器上下文预置不可解析的记录，公开旧版启动后写入一次新局，原字符串被覆盖且显示“进度已自动保存”。另一个隔离上下文仅让原生 localStorage.setItem 抛配额异常，普通定步按钮后的旧记录保留；恢复原生写入，再点购买，现金 670 的新记录已成功写入，界面仍错误显示“无法保存”。没有改变引擎、种子、现金、产权或胜负。公开 controller 的 canonical SHA-256 为 `871942cd3169faceeadefc0382ab309762de670d78ff290acc1a67df029b99c7`，与基线 git blob 相同。

## 最小修改

- 保持 `atlas-venture-rivals-v2.1` 与完整 v2 JSON 格式。结构校验只决定能否安全承接，不修补或清空原记录。
- 坏 JSON、不兼容版本、结构不安全或读取受限时，只开临时局并停止覆盖。重开或切局仍不会覆盖原记录；玩家能继续临时游玩，提示明确说明刷新或关闭的风险。
- 每次保存采用本次写入的实际结果。失败后保留旧有效记录，下一次操作保存成功即恢复成功提示。提示位于经营区，状态变化时才更新 aria-live 文本，不逐帧反复通知。
- 引擎、随机算法、价格、AI、胜负、素材、v1、其它作品及 40 项总数未变。不加入新的存储框架或坏档删除按钮。
