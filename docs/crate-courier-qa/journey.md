# 箱跃货栈三关本地候选

本轮以已发布r2 `6e5f0acd5b5563dd849c9b335b4288ad71b91847` 为基线，最多三关，不公开保存、不部署，不改指南55文件、其他45作品/99登记入口及旧档。当前版本 `crate-slice-3`。首关r2已有父线程有限电脑QA；本轮整段三关、存档和新界面仍须真实浏览器与玩家验收。

## 三关的行动与节奏

|章节|目标|实际取舍/变化|
|---|---|---|
|雨后货栈|穿过两水道到雨湾收货站|保留原地图、速度、跳跃与投掷。举箱投敌、跳跃绕行或借箱登上货架；不改水道难度。|
|双层货栈|到高处的上层转运台|下层投敌清路再逐级上台；上层可借箱垫脚，跨货架绕过下层巡逻。高低敌人与发射高度一致。新上层净空经过模型检查，下层跳跃不必顶着货架钻缝。|
|回湾夜递|沿分段水道回到亮灯灯港|组合投敌、矮货台、上层借高差跳下、重新落脚再起跳；有连续下层路线和上层绕行，最后用已学动作收束。没有Boss、新敌种、装备或第四关。|

三关共享单人移动/举放/固定弧线投掷。玩家可跳过敌人，不以清敌、箱子钥匙或第二个角色开门锁终点。每关体力独立为3；重试只重置本关现场，保留前面完成记录。到站后主动进入下一关，新的开场卡说明目标；第三关到站回顾三段真实的投中、跳跃、轻放和重试，不提供第四关。重新走三关须确认后才替换旅程。
