## 玩家价值及未过的门槛

玩家观察巡逻位置与平台边缘，选择举箱出手或保留移动空间跳过，空手/持物、落脚和发射时机反馈连续影响下一步。投掷不是一个打开门的按钮，目标不要求指定击杀数或交箱；货架可通过实体箱子垫脚绕行。本关证明这些动作在规则中成立，没有证明玩家觉得好玩。

《松鼠大战》的核心参照与删改明示在[首关说明](../../experiments/crate-courier/README.md)。原先强制两人切换解谜的设想在写游戏代码前取消，没有发布该版本；现在单人动作核心先成立，双人合作尚未实现。

当前绝不扩关的门槛：真实浏览器中开始前说明是否可读、投掷/跳跃手感是否成立、玩家能否看懂脚下边缘/持物/敌人受击、手机上是否看得清和按得住。通过后父对话才能决定是否做第二/第三关。无敌人种类扩张、装备、排行榜或额外系统。
