# 弯道邮差 · 第十六款固定范围

八条独立原创闭合赛道，俯视角单人计时赛。晨城、海岸、秋丘三种环境；前四条两圈，后四条三圈，分别 95、100、105、115、150、160、160、175 秒总时限。全部几何图像、车辆、赛道、SVG、合成声音原创，只参考街机竞速类型，不复制原作资产。

- 油门、相对车头的左右转向、刹车与自然滑行；停车不能原地转向，刹车不倒车。固定 1/120 秒生产物理，上限 255 游戏距离单位/秒，转向随速度响应。触屏方向与油门可真实多点同时按住。
- 三秒倒计时禁止移动且不计赛时。沿闭合路线正向、依序穿过各直道中段闸门，最后穿过格纹终点；每圈需要足够实际路线进度。逆向或漏门不能刷圈。闸门采用扫掠线段判定，生产速度与固定步长约束穿越。
- 路肩减速，严重越出外沿或出现不连续路线跳跃回最近已过闸门前方 10 单位，车头沿路、速度归零；加三秒、锁输入 0.45 秒。主动 B 复位遵循同一规则，顺序进度保持。
- 时钟为零先失败，包含同一步最后圈穿线；胜利只结算一次。完整教学、渐进赛道提示、暂停/失焦、失败重试、选关解锁、最佳圈速/全程与声音。
- 当前局只保存圈数、有效闸门、圈时历史、已用时及复位等统计；刷新只恢复已声明的安全闸门，加三秒并暂停，不能刷新清除当前圈用时。倒计时恢复先暂停并重新三秒倒计时，不收比赛加时。拒绝损坏/旧版当前局；最佳和解锁独立保存。不是可信的防外部恶意编辑成绩系统。
