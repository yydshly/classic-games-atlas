## 观察与改进

本轮真实公开页面普通UI：新旅途→出行→五步遇晶雾芽→缠风。按钮仍写基础10威力，实际相克造成15伤害；能量余1后禁用，原因“需要2能量，守息可回1”只在title。不能将基础威力称为伤害计算bug，原规则正确；这里改善决策反馈与不依赖悬停的可读性。

现有技能按钮改为只读实时预览：当前能量/消耗、当前目标下的实际伤害或有限恢复/安心、禁用原因。禁用保留原生disabled，虚线边框及正常可读文字说明暂不可用；守息、换位和属性变化后随正常绘制更新。预览中的治疗是承受当拍来招前的恢复量，不保证净体力增长；已有护盾/弱化/相克规则保持。

## 本轮步骤与真实覆盖

1. **已验：**营地出发、普通方向按钮到相遇；当前缠风预览15伤害。
2. **已验：**施放后能量1，按钮禁用且原因可见；真实鼠标点击不耗行动。
3. **已验：**原生Enter守息到2能量，技能恢复；再次施放耗至0，两次守息恢复。目标仅余12体力时预览封顶12。
4. **已验有限链：**普通露莓/羽结招募、回营、再出行切磋成长、换入晶雾芽后开始终挑战。已知路线/策略脚本辅助，不是无辅助发现证明。
5. **已验：**终挑战技能禁用时普通数字2不耗拍；守息恢复、主动换位后显示晶雾芽合奏安心+22，施放实际+22；主动回营、刷新精确保留。

## 三条后续品质候选（本轮不实现）

1. **营地编队前可比较伙伴技能**

证据等级：已观察界面与源码；不是已确认玩法bug。营地仅显示角色定位与成长；玩家能选择同行，却要进入相遇才看到具体技能。当前改进只处理行动中技能，不处理选队前比较。

价值：让发现新伙伴后的换队选择有实际依据，减少盲选和往返试探。

验收：先用普通UI确认现有玩法帮助是否已足够；有价值才利用既有卡片显示或按需展开技能与属性，不强制指定队伍、不改技能；390与键盘可读可收起，原编队/保存不变。

2. **未完成里程碑在出行时给出匹配的当前目标**

证据等级：已观察界面与源码；行动区已有清楚目的地，不是无目标或不可完成。新旅途刚出行时，顶部进度提示变为“先回营，再一起准备”，而尚未结识伙伴；右侧行动区仍正确说明晶芽草间与回声浅湾。

价值：保持跨界面的目标连续性，让玩家知道当前应先寻找伙伴还是带已结识伙伴回营。

验收：先验证新旅途/待入册/成长待完成三种普通UI状态；只在确有理解收益时改善当前指引，与既有四里程碑一致，不新增任务追踪系统/奖励/地图规则。

3. **完成后自由出行时能否重读旅途总结**

证据等级：仅源码线索/待当前普通UI复现；未确认用户障碍。continue会清ending，campPanel完成文案写“旅途总结已记下”，但未见重读入口。本轮未重复自然结局，不能把源码线索称为已复现缺陷。

价值：完成短冒险后能回看伙伴与旅途成果，保留收束感；不是新增结局。

验收：先核现有记录/入口并用正常结局后自由出行复现；如确实无法重读，再在不重新结算、不改存档格式、不覆盖旧档的前提下提供只读入口，键盘和窄屏可返回。
