# 云隙巡航 · 第九款阶段验收

本阶段范围见 [CLOUD_SPEC.md](CLOUD_SPEC.md)。八段原创航道已实现；图鉴保留 72 条、10 组，实验区增加为 9 款、98 关。前八款游戏的运行文件保持原样。本阶段交付后回到主对话报告并安排下一款。

## 规则、画面与输入

关卡数据、生产规则、Canvas 绘制和界面分别位于 `games/cloud/levels.mjs`、`engine.mjs`、`renderer.mjs`、`game.mjs`。图形、云层、机体、弹型、SVG 封面和合成音效均为原创；《雷电》只作为图鉴原作关联，不使用其素材、关卡或代码。

方向键 / WASD、鼠标目标跟随和触屏单指拖动共用速度上限；自动射击。中心亮点为半径 5 的受击核心，装饰翼面不参与受击。掠翼直射、折翼瞄准预告位置、弧翼扇射，精英交替使用三种弹型。弹型同时以颜色、形状和虚线预告区分，瞄准弹发射后不追踪。拒绝近距离或画面过低位置的敌方开火。

每关三格机体、两次风幕、火力 I 至 III；风幕清除当时敌弹并保护 1.8 秒，受伤保护 1.35 秒。普通敌机离场无击杀分、不扣机体；击败末段精英并结束编队后通关。致命伤和末段击杀同刻发生时失败优先，随后修复不能复活。刷新只保留选关、解锁、最高分/用时和声音偏好，从该关初始配置重新整备。

## 逻辑与正常策略

`node scripts/test_cloud.mjs` 通过 9 组边界测试，原始记录为 [logic-report.json](cloud-qa/logic-report.json)：

- 八份不同编队、三类普通敌机和单个精英；弹型锁定及近身发射限制。
- 连续线段对圆扫掠，高速穿越、擦边与未命中；中心核心和无敌期只计一次伤害。
- 火力 III / 机体 3 上限、重复拾取去重；风幕有限、清弹、有效期间重复激活不扣次数。
- 普通敌机离场回收、击杀分只发一次；精英击杀与致命弹/修复同帧仍失败。
- 暂停冻结机体、敌机、弹体、预告和资源计时；重试与只读快照不污染状态。

边界测试在独立的规则实例里构造输入与碰撞位置，不作为通关证据。另对全部八关使用生产规则，以限速移动目标、自动射击和有限风幕接口进行正常策略模拟，全部通关，见 [simulations.json](cloud-qa/simulations.json)。第 3 关模拟受到两次正常伤害并拾取两次修复后通关；没有额外生命、冻结敌机或改写胜利状态。
