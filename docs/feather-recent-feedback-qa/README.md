## 本轮最小改进

1. **默认收起的最近三拍。**沿用原生details/summary，显示角色、动作、本拍属性/来招、能量、体力净值、余势，以及有变化的安心/露莓。体力明确为行动和来招后的净值，不冒称单项治疗量。最多三条；回营可看上次，下一次挑战清空。
2. **不编造细节。**状态差值来自已有有效命令的确定性重放；来招/护盾描述只取已有结果文本可明确识别的事实。终局覆盖了细节则不补猜伤害或吸收，也不假写0。
3. **守息按实际显示。**满能量时仍可用护盾，按钮写能量已满，最新提示写实际增长0；正常恢复1保持原文。规则模型仍为原样，游戏状态和存档文本不改。

显示读取器在独立对象上增量处理新命令，内存只留三条摘要；刷新时从原记录还原。资产重复绘制不重复处理命令。新旅途/承接换对象时重置，不增加存档字段、奖励、任务或规则，不将副本重放的结果写回当前游戏。
