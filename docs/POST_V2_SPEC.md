# 弯道邮差 v2：单赛道三车竞速实验

独立入口 `versions/v2/games/post/`，独立本机存档 `classic-atlas.post.v2`。原 `games/post/` 八条单人计时赛道与 v1 存档保持不变。

## 本轮范围

- 一张地图：沿用原版晨光街区；每场两圈、三秒倒计时、95 秒比赛时限。
- 三场挑战是同一地图上的不同固定能力对手组合，不是三张新赛道。完成两圈即解锁下一场；只有第一名称获胜，超时不解锁。
- 玩家黄色 1 号，青鸟蓝色 2 号、赤狐红色 3 号；车头灯、尾灯、车窗与编号区分方向和身份。原创 SVG，不使用原作车型、标志或素材。
- 三车均经固定 1/120 秒物理步和普通油门、转向、刹车输入移动。AI 使用固定前视追线、弯前减速与车道偏移，不按玩家距离瞬移、秘密提速或动态调难度。
- 轻量实体接触，只分离和降低部分速度，无损伤、淘汰或撞飞。
- 排名依据已合法通过的圈数、顺序闸门及当前闸门段进度；完赛车按完成时间排序。前车差距以有效路线距离估计。
- 手动或越界复位回上次已过闸门前方，车速归零、停驶三秒。三秒内对手照常驾驶、比赛时钟照走，不额外重复加时。
- 暂停冻结三车、计时、倒计时和罚停。刷新保存并验证三车完整状态，恢复后先暂停；不会仅把玩家移回安全点而让对手重置。
- 最后结果显示名次、用时、复位。第一名才称获胜；比赛上限到达也结算一次。完赛并不等于第一名。

## 明确不包含

分岔路网、氮气、警车、交通、车辆升级、联网排行榜、八图重做或完整《极品飞车》复刻。原版“投递”只是主题表达，原引擎没有包裹取送机制，本版也不声称保留或新增配送系统。

## 验证边界

规则夹具、普通输入策略模拟、控制器模拟与人工实玩分开记录。机器追线完成或夹具通过不能证明好玩。有限实玩最多三场：一场原版基线、两场 v2；失败也有效，不无限追加追胜。尚未执行的人工验证不得写成通过。
