实际 Chromium 自动化覆盖1173×751、1440×900、1366×768、1280×600、1024×600。没有调用引擎推进、注入状态、编辑生命或伪造存档。正常按钮开始，键盘移动/E进入守卫室，短移动攻击；在暂停时切换窗口，再点击页面控件验证：

- 完整石室、目标/生命、暂停、重试、四方向和四动作全部同屏，鼠标点击目标未被遮挡，也未引起页面自动滚动。
- 原始画布仍为960×576。显示比例约0.76–1.12，关键DOM文字至少13px，主按钮至少44×44px。
- 暂停时原应用保存的快照及显示计时/生命冻结；继续后正常推进。测试只读取localStorage，保存仍由原应用执行。
- 验证一次当前房间检查点重试：房间保留，生命恢复到上限，位置按原入口检查点恢复；继续移动/攻击后再次核验同屏。
