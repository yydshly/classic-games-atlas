## 正常输入完成证据

`scripts/old-house-routes.mjs` 为有限人工路点；每个路点有步数上限。模型完成与浏览器完成分开，不做状态注入或无界求解。浏览器只读取 `canvas.dataset.snapshot` 来观察位置，执行正常方向键、举枪射击、E、背包检查/使用/组合与铁柜按钮。浏览器回放的实际转向/按键时长会带来少量距离差异。

| 证据 | 清廊路线 | 温室绕行路线 |
|---|---:|---:|
| 纯模型完整救援 | 149.1225米、4发、4次命中 | 195.645米、0发 |
| 本地真实 Chromium 完整救援 | 155.7675米、4发、4次命中 | 204.0225米、0发 |
| 撤离时体力 | 100 | 100 |
| 巡馆偶状态 | 停止，回程沿清空回廊 | 保留，回程走较远温室 |
| 实际寄存 | 弹盒，带4发枪 | 枪及弹盒，9发均保留 |
| 开内闩/救援/撤离 | 均完成 | 均完成 |

双方先取同一温室线卷并开同一储物回环；都把药布组合成敷包。不是用不同任务比较。清廊消耗4发，换约48.3米较短的浏览器回访路径；绕行保留全部弹药但搬运更远。清廊不是强制条件，技术熟练者也可以在廊内无伤绕敌。

另一个独立的**真实浏览器正常输入**反例：不先压缩或寄存，拿钥匙后六格满，熔芯第一次拾取失败；组合药布后可拿熔芯，但温室线卷第二次拾取仍失败。实际回值班室寄存弹盒，再回来才拿到线。该用例同时以侧移/穿行无伤绕过活动巡馆偶，0发、体力100。这证明背包和返程改变行动，物品不是“钥匙开门”装饰。
