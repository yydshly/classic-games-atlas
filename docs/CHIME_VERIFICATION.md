# 风铃绳旅 · 验收记录

本款采用正式固定步长物理；正常策略只调用开始、剪绳与时间更新，不改位置、速度、绳长、重力、星点或终态。`scripts/chime_plans.mjs` 保留基准策略和较从容的逐根剪法。静止起点先等一秒，多锁逐根相隔 .2 秒；单绳已在摆动的四关仍使用首摆窗口，不把随意等待说成可行。

## 本地规则与浏览器

- 21 组逻辑验证覆盖可行起点、长时间多约束稳定、松绳、剪序、防重复、暂停、切区几何、梁扫掠碰撞、危险优先、风力、出界/夹住/静止、固定帧分区、日志重放与坏记录拒绝。仅碰撞边界的单元夹具直接设置测试世界，正常策略没有这些改写。
- 16 关基准均过关，独立 ±.1 秒剪绳时间扰动共 90 组过关；16 关另有正式引擎三星见证，基准第 9/14 关只有两星。另 16 次从容逐根策略均过关。时间参数和每次结果见 `chime-qa/strategy.json`，这些是自动化工程证据，未宣称人工测试。
- 本地十六关真实键盘通关：普通 `1`–`4` 按键，原始参数、正常帧率、无状态写入。后关隔离测试只预置菜单解锁/教学/静音，不补绳、不改结果；全部零控制台错误、失败请求与 HTTP 错误。
- 23 项界面检查：准备全场可见、锁关、教学/取消、键盘/选绳、鼠标点剪/同段双绳、端点、拖铃无指令、重复按键、暂停旧手势、刷新精确恢复再赢、菜单暂停、失焦、声音、原生 Tab/Enter、最好星数优先、存储禁用仍可通关、窄屏菜单、正常失败重试、坏存档、六种宽度。手机原生 touch 点剪第 1 关和五段划剪第 12 关完整过关，分别三星与一星；触屏通过不等于三星。

第一次本地 UI 测试在选关夹具处停止：测试在重载前写 localStorage，被页面卸载自动存档覆盖。夹具改为初始化时写入，正式游戏代码无需为此改变；原失败报告保留在 `chime-qa/local-ui-initial.json`。早期布局搜索第 8 关终点偏离轨迹，发布前已调整关卡数据，并对全部关卡重做正式策略验证。公开验收以最终发布数据为准。

## 发布验收

代码提交后等待 GitHub Pages 成功，再对公开 URL 运行全部十六关真实输入、界面、触屏、图鉴回归以及所有运行文件的 SHA-256 比对。公开报告、实际星数、代码 SHA 与 Pages run 在证据提交后补齐；本段在完成前不代表已上线。

## 范围与限制

测试环境为当前 Windows 上已安装的 Chromium / Playwright，含 320–1440px 视口与 Chromium 原生 touch 输入；尚未在 iOS Safari、Firefox、低端实体手机或屏幕阅读器全面验收。绳是最大距离约束，灰梁对圆铃使用保守矩形包络，未模拟柔绳、绳间碰撞或三维物理。触屏大幅不同的剪序仍可能少拿星或失败，这是规则的一部分。自动化定时通关与有限窗口扰动不能替代多位玩家的可玩性研究。

全部美术/音频为原创几何与本地合成，无外部资源、ROM、新凭据、付费或运行依赖。原 72 条图鉴与前十七款运行文件保持。下一款由主对话安排。
