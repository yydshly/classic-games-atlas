# 靠泊末段提示 · 云端候选（2026-10-23）

## 玩家问题与范围

渡台每岸停留6秒，原画面在刚停稳与即将离岸时使用相同阶段文字与泊位灯；货箱压板后也一直提示等船靠稳。此次只让即将启航这件事更可预判，不增加关卡、倒计时或新机关。

- 从既有物理快照的 `phase` / `dwellRemaining` 读取停靠最后2秒。
- 近岸显示“即将离岸”，对岸显示“即将返航”；泊位与船灯转暖但不闪烁。
- 岸上不鼓励追船；船上提醒制动或等下一次靠岸。已经上岸仍保留接应灯指引。
- 不修改物理、6秒节奏、碰撞、存档、原45款、暂停项目或实验计数。
