# 弯道邮差 v2 · 候选验证记录

状态：本地候选技术验证完成，人工有限实玩与公开页面检查尚未执行。规则正确性、控制器行为与趣味性分开评价。

## 本轮技术检查

- 11 组引擎固定夹具：三车与单图、暂停、真实三秒罚停、顺序正向闸门、跳门拒绝、实体接触、完整三车存档、已完赛对手恢复、损坏记录拒绝、一次结算、自然超时。
- 额外独立夹具：碰撞分离不白给闸门、截止时刻超时优先、220 份真实运行存档逐字段精确往返。存档不是加密防作弊系统。
- 7 组普通输入策略模拟：只输出油门、方向盘与刹车，不修改比赛坐标或进度。包括三个难度的常规追线、三个难度的更快内线，以及停驶自然失败。
- 控制器 DOM 模拟：暂停/失焦/教程清空输入，三车刷新恢复，超时文案，失败结果持久化，存储不可用/损坏容错，重复起跑。完赛保存最佳、第二名也解锁下一场、第一名获胜流程使用明确标注的状态夹具，不冒充驾驶获胜。
- 绘制命令模拟：车辆三张图片与背景缓存持续复用，没有逐帧创建图片节点。该检查不等于像素或浏览器视觉验收。
- 1181×757 静态 CSS 估算：场地约在 y=201–679，主要驾驶按钮约到 y=724；真实浏览器同屏仍待检查。

## 最终普通策略结果

- 常规追线：三档均第三名，37.692 / 24.983 / 22.608 秒，三车均零复位。
- 更快内线：三档均第二名，35.150 / 23.383 / 20.400 秒，三车均零复位。
- 停驶玩家：95 秒失败，两名 AI 均合法完成。

这些结果支持“不同普通驾驶路线可以改变相对名次”，尚未证明人类能够理解和稳定利用它；也没有当前最终版第一名可达性的实测证明。首档仅做一次固定目标速度 155→125 的降低，重跑原有策略后仍无第一名证据；此后未追加调参或试跑。更早碰撞版本的第一名记录已失效，不计入本版证据。

## 已发现并修复

1. 接触分离能把静止车推过闸门并白给进度：驾驶过闸检查与碰撞校正分开；将碰撞校正截在未过闸门之前，避免白给或把车丢在漏门一侧。
2. 车身碰撞尺寸过短：采用前后双圆，接触范围更接近 48×26 的车身显示。
3. 同向接触对两车同时持续扣速会形成 30 秒以上粘连：改为法向冲量传递和小幅损耗。独立三档追逐复验，起步三秒之后所有车低于速度 10 的累计时间均为零。接触计数按每对车每物理步累计，不代表事故次数。
4. 前车差距单位、超时标题与结果持久化已按实际引擎语义修正。

## 仍待的有限实玩

最多三场：原版基线一场、v2 正常驾驶一场、v2 改变一次刹车点或内外线一场，安排一次暂停/恢复。失败有效；没观察到有效交互则结论为“未能判断”，不继续无限追胜。另检查车头方向、三车识别、HUD 与按钮同屏、控制与刷新。

同一物理步内同时完赛按固定车辆顺序打破平局，最多约 8.3 毫秒时间量化；不是亚帧竞技裁判。罚停按模拟时间计，页面暂停冻结所有车辆。前车差距是合法路线进度估计，不是精密测速。
