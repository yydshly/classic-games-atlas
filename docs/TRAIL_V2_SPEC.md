# 风行小径 v2 · 逐风补给

独立有限原型，原版 `games/trail/` 和 v1 快照完全保留。原版已经有八关、可变跳高、跳跃缓冲与离地宽限、移动台、敌人巡逻、检查点、三命与重试；本轮并不把这些写成新增或原版缺失。

## 本轮变化
- 三段短路，正常熟练输入每段约 18–25 秒。少量尝试或等待会更长，不以关卡数代替深度。
- 新增有冷却的前向弧线种子弹，可击退巡游者。投掷关键姿态、飞弹与命中消失反馈可见。
- 体力每秒消耗 5；果实补充 32，上限 100。后两段部分食物在高台，形成走地面与额外跳跃补给的选择。正常熟练路线两者用时相同，不声称存在耗时取舍。
- 三命，碰敌、跌落、体力耗尽扣命。检查点后重生；耗尽生命进入失败卡，可重试本关。过关后手动下一段，末关完成可重玩。
- 暂停冻结规则。自动保存当前关、位置、体力、生命、果实、敌人和检查点；刷新以暂停状态恢复，清空按键/飞弹并提供短暂保护。不是逐帧无损回放。无法解析的旧存档不覆盖。
- 新原创森林背景、披肩旅人与甲壳巡游者。角色使用待机、奔跑、跳跃、投掷关键姿态；单个奔跑姿态不宣称完整走跑帧动画。
- 键盘与多指触屏；失焦、隐藏及离页清理输入并暂停。HUD、场地、主要操作按 1181×757 单屏设计，待真实浏览器核验。

## 固定边界
不复制商业原作角色/素材；不声称具备原作全部关卡、武器、Boss 或完整动作深度。本轮没有新增移动台，也不削改原版移动台关卡。新增机制是对平台动作和食物生存节奏的有限补充。

## 素材
原创生成图经裁切、透明合成检查与 WebP 压缩。六张运行素材共约 394 KB。森林为绘制背景，平台仍为几何判定地形；本轮不把它称作完整手绘关卡或成套跑步动画。Image 只在 renderer 创建时加载并缓存。Canvas 对象与存档使用独立 v2 键，CSS/module 带版本号。
