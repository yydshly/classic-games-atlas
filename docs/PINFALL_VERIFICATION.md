# 落星弹庭 · 验收与证据

第十四款原创瞄准弹珠消钉实验，固定范围见 [PINFALL_SPEC.md](PINFALL_SPEC.md)。12 个不同布局，目标星钉、普通圆钉、一次性涟漪和不可消除的回弹石。所有布局、画面、SVG 与合成声音原创，只参考 Peggle 式规划反弹，不使用原作地图、角色、图形或音乐。

## 玩法与物理边界

一次只发一球；重力作用下在圆钉与石障间反弹，没有玩家移动的挡板。命中的钉在本球内保留碰撞，回收后统一移除，重复碰撞不重复计分。目标全部点亮后仍等本球回收，再先判胜利、后判球数耗尽。初始预算为 4–7 发，只有完整接住且本球至少命中过一钉才返球，空球不能刷球。

接球槽只随飞行物理时钟移动，瞄准时静止，使每球规划不依赖玩家停留多久。涟漪半径 110，间接点亮的其他涟漪不再扩散。回弹石不消除且不计分。

物理使用固定 `1/180` 秒和连续扫掠圆碰撞，接触分离、有限迭代、球速上限。低速停留 1.2 秒后轻推，每球最多两次；12 秒仍未回收则回收本球，仅结算实际点亮的钉，不瞄向目标、不替玩家清场。规则在玩家手册和保护计数中公开。

## 跨运行时精度与修正记录

[逐关比较](pinfall-qa/cross-runtime-comparison.json)显示全部 12 关的角度、目标/普通/涟漪钉结果、得分、返球、预算和统计与生产模拟一致。第 3 关在 Node 与 Chromium 的物理回收时间相差一个固定步，约 `0.0056` 秒；其他 11 关一致。实测两环境 `Math.cos(-55°)` 分别为 `0.573576436351046` 和 `0.5735764363510462`，长反弹过程中末位浮点差异使回收跨过相邻采样步。Chromium 中同图同角度的三种输入分块均为 1661 步，Node 为 1662 步。没有为对齐报告修改物理；不宣称跨 JavaScript 引擎浮点逐位相同，后续公开验证会继续记录时间差，玩法结果仍需一致。

开发预检曾发现第 8 关普通钉与涟漪中心过近，将涟漪中心从 y=470 移至 y=510，几何检查和全部关卡验证通过，重叠草案未发布。初次 UI 脚本在触屏暂停断言中误把带 `await` 的生成器传给 `all()`，发生脚本类型错误；改为先读取一次快照再比较，完整 22 项通过，未因此改变产品代码。
