## 待真实 UI 验收的三条场景

1. **立即回应**：未完手记→真实走到长座→共同双色笔迹→回桌续写。共同活动中刷新一次，确认暂停恢复、占用正确、作品不重复。截图需同时看见人物位置与作品变化。
2. **稍后回应**：各自完成→携带手记去长座→交换两份成品。重试后在分享中取消，确认手记随返程回桌、原作品保留、没有假称分享完成或软锁。
3. **不回应**：关闭请求→各自完成并正常收起；重试后请求只重新出现一次。检查原三日入口与旧档不变，键盘焦点、窄屏布局和控件可达性。

不得用注入作品完成状态、预置结局或模型报告代替上述真实 UI。原有云浏览器限制未重探测；本机仅由主任务安排辅助 QA，当前能力受限，以上场景均**未执行**。

## 实现中修正的有证据问题

- 定向检查发现暂停可能保留不足一逻辑步的累积时间；恢复校验现允许暂停态保留该小数步，避免合法暂停档被拒绝。
- 画面／模型契约审查发现取消分享返程时手记仍标在长座；现改为携带状态，跟随实际位置回桌。
- 控制器取消共同安排后把焦点送回可见的暂停／继续按钮，不留在已经隐藏的取消控件上。
- 独立只读代码审查发现邀请／分享时纸张在人物手中和长座重复绘制；现手持时不再画座上副本，结束后放回。场景两侧明确标记的作品近看不计为实体副本。
- 离屏像素检查发现长座下方人物的动作气泡盖住纸张；共作／分享时气泡移到人物旁边，笔尖朝向实际长座上的纸。此为离屏图检查，不扩称浏览器可读性通过。

这些是实现与夹具检查的结果，未声称已获浏览器视觉复验。
