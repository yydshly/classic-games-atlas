- 第二湾stepping每次准备前多等0.10s的盲重放，在61.00%时损灯，已织158格保持；开放线清除。
- 第三湾long每次准备前多等0.20s，实际首次出线由0.46s变为0.58s，预测已转danger；0.54s后实际碰线，绝对时间1.12s。report另记录16次等待变体，有通关、损灯和按键结束仍未达标的结果；仍playing不能称game over。
