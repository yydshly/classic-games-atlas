# 星砂勘探 · 验收与证据

第十三款原创玩法实验，固定范围见 [SAND_SPEC.md](SAND_SPEC.md)。20 关固定逻辑排雷战役，从每关明确标出的安全观测点开始。首次只允许揭开该点，点及其八邻域无雷；本轮没有随机模式，不宣称任意首点安全。名称、地图、SVG、星砂界面与合成音效均原创，只参考扫雷机制。

## 可见线索与无盲猜证明

`games/sand/deduction.mjs` 不导入引擎、地图、种子或答案，只接收公开几何、起点、总雷数、已揭示数字和玩家旗标假设。规则包括数字减邻旗、未知格全集、真子集差；派生集合保留原始数字依据。`scripts/sand_pilot.mjs` 只调用这个模块，不导入固定关卡或雷位。

- [20 关认证日志](sand-qa/campaign-certificates.json)：固定种子离线采样，仅在整张地图能由公开线索逐步完成时接受。第 18–20 关还要求实际用到集合差。认证保存逐步公开依据、结论及生产规则动作，不采用固定坐标答案表驱动运行。
- [正常生产规则模拟](sand-qa/simulations.json)：20 关全部胜利，475 次正常揭开、标旗或快捷展开，零提示。每次只把脱敏公开观察传入推理器；选定动作后才由测试断言核对隐藏真值，真值只用来审计结论正确性，从未作为策略输入。
- 浏览器策略进一步移除关卡编号等 UI 字段，只传可见格、总量、几何及公开起点。每个实际动作记录 `visibleBefore`、推理依据和结算进度，前期后期采用同一公开规则。游玩结束才允许显示雷点。

旗标是玩家假设，不自动核验。错旗可能产生错误结论甚至快捷展开触雷；提示明确说明这一前提，并能指出可见关系中的矛盾。不会用隐藏雷位“纠正”错误旗标。所有默认星图有从正确起点出发、无需盲猜的完整路径，这不等于任意错误旗标都能继续安全完成。

## 逻辑与存档

[12 组逻辑检查](sand-qa/logic-report.json)通过：20 图雷数与独立八邻域计数、缺口、起点零邻域；公开观察不泄漏隐藏数字；首点限制；零区/旗标/缺口边界；旗数上限；错旗快捷展开失败优先；正常快捷展开与唯一胜利结算；暂停与提示；提示假设与脱敏模块边界；带版本日志恢复及损坏拒绝；重开清空；20 关正常推理。

极端零区、错旗与同次胜负边界使用隔离 `buildGame` 夹具，未改发布地图。脚本末尾验证全部原始地图数据未被夹具修改。当前局保存格式包含版本、状态、关卡、合法动作日志和用时；恢复从原始地图重放生产动作，不信任存档中注入的雷位或数字。未知版本、非法首点、非法动作、非法数值与超界日志会被拒绝。未揭开但已开始的局也恢复为暂停。

静态客户端地图本身可被查看，不提供反作弊保密承诺；本处保证的是推理与提示算法的数据边界，而非隐藏资产加密。纪录仅为此浏览器个人纪录。

宽度覆盖 320、360、390、768、1280px，检查页面无横向溢出、结算卡和按钮实际在棋盘边界内。触屏使用 CDP 真实触摸事件，验证长按释放不再揭开、拖动实际滚动且取消操作。图鉴 72 条详情、搜索、主题/类型组合筛选、空结果、键盘与六种屏宽另用原有 `scripts/test_browser.py` 回归。

## 开发中发现与修正

1. 初次浏览器脚本在第 10 关立即对刚揭开的同一格再做快捷展开，触发生产环境 220ms 防连点而等待超时。没有触雷或绕过规则；脚本现对同格后续操作等待正常 240ms 输入间隔，所有 20 关通过。没有修改游戏计时或取消保护。
2. 检查首点交互时发现起点特例可以绕过显式标旗模式。改为标旗模式首次点起点不揭开，清楚提示先切换揭开模式；新增真实输入验收通过。
3. 提示的完整集合依据保留在勘探手记，状态栏改为简短定位说明，避免窄屏重复堆放长段推理；数字、依据和结论均仍可读。
