# 街巷护送：第34项限定修整

本轮只处理环境光与接触影、多人辨识和手机实战布局。没有启动第35项，没有新增关卡或美术素材。保留暖金/靛蓝、晨街/雨巷/夜岸/归巷四种环境及开场版式。

[打开实景对照与动作视频](https://yydshly.github.io/classic-games-atlas/docs/escort-qa/refinement/) · [直接游玩](https://yydshly.github.io/classic-games-atlas/games/escort/)

## 画面调整

- 同一组现有 WebP 按环境缓存明暗和色温；夜岸降低环境亮度，灯车附近的受光面保留暖光，雨巷使用偏冷环境光。灯车、轮子和人物一起处理。
- 根据每个动作帧的实际脚底重设绘制锚点。脚下使用渐隐接触影及柔和投影，移除硬椭圆、受击大轮廓和高亮整身闪烁。
- 人物保持按脚底纵深排序；来敌稍缩小，主角保留细轮廓和“你”标识。自身光息只在明确标注的界面显示；来敌使用独立名称/血条、错位标签与指向头部的引导线。
- 战斗时略降背景饱和度和对比，缩短命中火花；保留真正攻击范围与纵深的地面预警。没有增加叠加闪光。
- 手机进入战斗后折叠标题和次要信息，使用整屏实战布局。“信息”可查看连击、成绩和最近记录，并暂停战局；“手册”和选关继续可用。

## 实景证据

[对照页](escort-qa/refinement/index.html)保留晨街、夜岸的单人/多人/出手原尺寸 PNG、修整前后各约11秒的真实动作短片，以及雨巷和归巷出手画面。PNG可点开查看原图。不是原游戏截图或概念图。

多人/出手对照由修整前的真实操作产生合法输入存档，再由原引擎重放。修整后4组对照逐项核对24个战局字段相等。没有写入生命、坐标、补给、时钟或结果。单人图为各关待开始状态。录像是独立的正常操作，不能当作逐帧相同输入比较。

视频由 Playwright 以实际视口尺寸录制：桌面1440×1000、手机竖屏390×844、横屏844×390。使用环境中已有 FFmpeg 转码 H.264，无缩放、补帧、生成片段或安装软件；最终手机短片截取真实完整录像的前12秒，原 WebM 同时保留。修整前和最初采集的手机视频中，旋转后的画面适配在原竖屏录像容器内；最终横屏另起原尺寸录制。[编码与尺寸](escort-qa/refinement/video-metadata.json)
