# 灯塔小队 · 第十七款固定范围

十关独立原创 8×7 方格战役，潮岸、林庭、山脊三种主题。第 1–3/6 关清除，第 4/7/9 关护送，第 5/8/10 关守灯。每关都必须清除全部威胁且至少一名战斗队员存活，另合并各关特定目标。回合上限 12–18，思考不限时。

- 礁卫护甲 9、射程 1、伤害 3；弧手护甲 7、射程 4、伤害 3；灯医护甲 7、射程 2、伤害 1，修复范围 2/修复 3；引航员护甲 8、只移动。敌我同一原型。每个自己回合 2 AP，机动/攻击/修复花 1，移动最多三格；修复每单位每回合一次，不能复活。机动与攻击可按 AP 重复，但旧指令不能重复提交。
- 四邻 BFS、占格互斥、不能穿单位/高墙/水；射程为曼哈顿距离。高墙与单位挡视线，射线采用 supercover，角点同时接触高墙也阻挡。水面不挡视线，掩护/灯台减距离大于 1 的来袭伤害 1，最低伤害 1。固定伤害、无隐藏敌人、随机命中或增援。
- 移动范围、攻击范围、路径、AP 花费、伤害和目标剩余护甲先预览，再显式确认。选中/取消、待命、鼠标、键盘及触屏；没有撤销。行动携带棋盘版本，拒绝过期或重复指令；结束回合和重开均二次确认。
- 敌方只读取已提交棋盘，逐步按同一规则移动/攻击/修复/待命。每次消耗至少 1 AP，待命放弃余下 AP；每轮最多初始敌方存活数×2 次行动，随后交还小队，UI 标准间隔 0.38 秒。
- 护送必须引航员活着到出口；守灯在敌方回应结束时计一轮，战斗队员必须仍站在灯台，离开则连续进度归零。清空敌人不会跳过目标。小队全灭/引航员倒下先失败；最后允许回合达到联合目标仍胜利，结算一次。
- 保存精确双方单位位置、护甲/AP、每轮修复状态、回合/阶段、目标进度、已提交指令版本与统计。恢复先暂停，不回满、不补 AP、不重复开始敌方回合；当前界面计划不存档。结构、版本、地形、占格和资源边界校验，合法最佳与解锁独立保留。不是对恶意外部编辑本机成绩的防作弊系统。
- 成绩 = max(0,1000 + 存活战斗队员×100 − (当前回合−1)×25 − 实际承受伤害×3)。只在胜利记录最佳；十关解锁、教程、暂停/失焦、失败重试、声音。本轮不增加长期经济、养成、账户、服务、联网、付费或依赖。

十关发布规则正常策略与公开浏览器真实输入通关。策略可以在自己的副本中用同一引擎推演，不写真实战局的护甲、AP、敌人或胜利；边界夹具另列。角色、名字、故事、地图、图形与声音原创，只参考通用战棋机制。保留前十六款与 72 图鉴，独立 main 提交并验证最终 Pages/128 个运行文件后交回主对话；不自行启动第十八款。
