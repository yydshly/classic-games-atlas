2. 轻击使野外体力 42→18，岚翎体力 84→75，警觉 0→4，招募概率 22%→46%。分享露莓后露莓 2→1、安心 0→28、招募概率 74%。

5. 第二次普通相遇中，切换晶雾芽并使用晶雾：安心 +22、能量 3→1，预告的 16 伤害实际变为 8，体力 70→62。已入册种类不能再次系羽结，按钮有明确说明。

7. 刷新后出现恢复提示，保留第 2 次出行、日光 14/24、羽结 2/2、露莓 2、名册 4/5、新队伍、岚翎 83/92 及成长，晶雾芽 50/70、能量 1/3，旅途记录 33 条；继续按钮可用。
8. 首页 #compare=feather 正常打开。实际点击 v1 进入原八章页，返回后点击 v2 进入回声浅滩并恢复记录。冻结 v1 仅核对链接目标，没有新增实玩。
