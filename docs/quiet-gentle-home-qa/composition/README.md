## 实际修改

- 删除空墙与大挂图。缩紧相机取景高度，保留全部真实承托和角色；机器人、目标与桌沿获得更多画面空间，不新增摆件。
- 将同一盏灯移到修理师椅子的外侧角，底座有可见承托，整盏灯离开台面与机器人承托包络。没有新增灯具碰撞体。
- 袖管、肘、袖口和手掌围绕同一肩部枢轴连接，手放在围裙前方。惊醒时向前抬起，肩部不平移脱离身体；整条手臂也避开保守承托包络。
- 恢复 DPR 上限 1.25。阴影仅留给 12 个主要物体，贴图从 1024 降到 512。合并静态缝线、螺钉和工具顶面的同材质几何；工具主体、面罩、球壳、关节和状态指示保留独立对象。

运行修改仅为 `scene.mjs`、`view.mjs` 和新增 `batch.mjs`。物理、关卡、阈值、输入、存档、现有网页入口不变。内部 `metal-table` 标签仍用于原物理归因，但玩家文字已是“工作台边缘”，不把木台说成金属材质。

## 实际 P2 复现与修复证明

`tests/quiet-lamp-envelope.test.mjs` 通过合法控制走 `[0,2.5] → [3.64,2.5] → [3.64,3.94]`，在三种输入间隔下到达约 `(3.6396,0.3400,3.9152)`，仍 grounded / playing / noise=0。逐三角形计算球体与旧灯几何的距离，复现约 **0.181** 的穿入量；这是可执行模型和真实渲染几何的故障证据，不是浏览器画面。

当前灯具的所有几何最小 x 约 **5.70**，超出全部真实承托最大 x=3.8 再扩张两倍机器人半径后的 **4.48**。上述路线位置与新灯的球体净间距约 **5.20**。测试也检查了静止/惊醒时手臂仍在保守承托包络之外。没有用新碰撞或改路线隐藏缺陷。

详见 [lamp-envelope.log](lamp-envelope.log)。

## 离线渲染的限制

投影读取真实 Three 几何和颜色，用 CPU 深度缓冲处理不透明三角形。这次统一修正了旧离线导出中过严的视锥排除和正交相机背面判断；新旧比较图都使用同一修正后的算法。没有修补 PNG 掩盖场景问题。

仍未复现 WebGL 的顶点平滑着色、金属度/粗糙度、真实光源强度、阴影、色调映射和浏览器抗锯齿。材质基本类型均被识别，但这里只近似颜色，不是完整材质渲染。离线算法没有通用近裁剪面多边形裁切或透明排序；本组主场景为不透明且位于近远裁剪范围内，视口外部分用栅格边界裁切。页面 DOM、动态动作可读性、实际手感、触控与帧率全部未验收。
