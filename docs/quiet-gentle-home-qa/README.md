## 实际实现

- 将工作台、真实金属工具盒、缝边软垫、维修标签、桌灯和旁边的茶杯/眼镜组成夜间维修场景；装饰不填补真实空隙。原六个障碍体的实体外形按 ROOM 尺寸保留，包括两件练习体。
- 小机器人球壳按真实 quaternion 滚动，铜色修补片与接缝一起转；面罩单独自稳。制动低头、真实撞击缩眼和轻微后仰，场景与按键不是两套运动。
- 修理师的呼吸、头手眉反应读取真实噪声和 impact。惊醒时抬头睁眼，物理照旧当帧判负；终局表现继续完成，但不推进世界。
- 在原目标位置制作低矮充电窝。进入目标圈但仍过快时亮双竖线、触点不接通；只有 `state=charged` 才亮触点与稳定眼灯，面罩短暂点头收尾。没有自动归中、磁吸、新操作或新胜利条件。
- 缩短开始卡，完整键位说明留在原生 dialog 中。暂停冻结物理和表现；重试清理旧动画。失败保留现场和原落点小叉，结果条仍在画布外。

主要文件：`scene.mjs` 负责程序化几何、材质、镜头和骨架；`presentation.mjs` 是只读表现状态；`view.mjs` 连接 WebGL；`game.mjs` 传递制动/暂停信息；原页面、样式和反馈文案相应调整。物理文件未改。
