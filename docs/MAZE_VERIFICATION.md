# 爆破迷宫验收记录

本轮交付第二款独立原创机制实验。十张地图与规则完整实现；不将图鉴内原作称为已经复刻。后续第三款仍是待开发候选，按[逐款交付规则](DELIVERY_POLICY.md)另行推进。

## 已完成的规则与界面

- 2.4 秒炸弹、十字爆风、石柱阻挡、木箱破坏与截断、连锁引爆、离开炸弹后不可穿回。
- 三种巡逻机行为，容量/范围/速度三种强化，三格护甲与受伤保护。清空敌人后仍需进入出口才胜利。
- 十关逐步解锁、最佳得分、声音偏好与教学记忆；本地保存，无账号或后端。
- 键盘和触屏、暂停/恢复、失败重试、重新整备、选关、离开页面自动暂停。

## 逻辑与真实输入证据

[逻辑测试](../scripts/test_maze.mjs)的 [14 项检查](maze-qa/logic-report.json)覆盖十张独特地图、移除木箱后的连通性、出生与出口、第一弹撤离空间，以及炸弹/爆风/连锁/自伤/强化/三类敌人/胜利条件/暂停/重启/状态副本。逻辑夹具会直接构造场景，不能作为真实通关证据。

[首关真实键盘记录](maze-qa/first-clear/report.json)：第二次尝试清空 3/3 台巡逻机并进入出口，80.18 秒、剩余 1 格护甲、19 次放置、26 个木箱。第一次因接触伤害失败，原记录保留。该轮使用仅开放选关菜单的隔离存档夹具，未改变战斗、敌人、生命、时钟或胜利；不声称它证明了自然战役全程推进。录屏位于同目录 `video/`，包含该轮失败与成功。

[真实界面最终验收](maze-qa/ui-final/report.json)使用全新浏览器存档，实际拾取容量模块、放置两弹并触发连锁（护甲 3），连续三次自身爆风触发失败并重试；验证暂停时钟、教学与声音偏好保存、帮助 Esc 恢复、未解锁关卡、触屏点按移动与放弹、360/390/768/1280 宽度、图鉴往返和待开发项无试玩链接。短触屏点按漏输入在这次检查中被发现并修复为单步输入缓冲，复验通过。移动信息面板的窄列布局随后也已调整。

[末关真实键盘记录](maze-qa/final-guarded/report.json)：7/7 击破后走到 (13,11) 出口，119.08 秒，护甲 3、零受伤、29 次放置、24 个木箱、2450 分。只用存档夹具开放第十关菜单，战斗全程真实按键。此前三次接触伤害失利记录在 [首次末关尝试](maze-qa/final-clear/report.json)，改进保持距离的操作路径后完成；未改变规则或降低末关难度来获得通关。该轮最佳纪录在重载后保留。

[无解锁夹具的自然首关复验](maze-qa/natural-first/report.json)：全新存档从教学开始，3/3 击破并进入出口，66.55 秒，护甲 3、零受伤，1430 分、三星。通关后自然解锁第 2 关，刷新后仍为已解锁 2 关且保留最佳纪录。末关约 60 FPS、平均绘制 0.26ms；该次自然首关约 60 FPS、平均绘制 0.31ms，数据为此环境观测值，不保证所有设备相同。
