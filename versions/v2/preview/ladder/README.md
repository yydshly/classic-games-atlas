## 新增的规划组合

| 地图 | 路线选择 | 错误与恢复 |
|---|---|---|
| 借位砖室 | 先从左侧进内室，还是先走高索取远核再从右侧进入；外口与内层埋核有先后依赖，一处初始开口仍取不到内核。 | 第一入口回填后，内绳室仍有落脚，可继续开内层并下撤；一直留在要回填的软砖格仍会失败。 |
| 双汀货栈 | 左埋核→右埋核→高核，或高核→右埋核→左埋核；接近埋核时可比较两侧站位，困卫换路或退底层绕错梯。 | 提前落底可沿另一外梯回到阳台；盲穿共用中索会迎面遇巡卫。没有困卫次数门槛。 |
| 落井环仓 | 左上/左中先行，或先开右口下落；中央梯只连上中，落底后要选侧环返回，远侧路线有额外走位代价。 | 漏上层核仍可走侧环补回；右上短索给错过梯口的操作一个可见落脚。直走最近底路会遇巡卫。 |

每图仅3至4核，少于或等于首篇；不是拉长走廊或增加收集数量。两种取核顺序及绕行有模型证据，不要求唯一解。第一图的主价值在几何挖掘，并不要求每条合法路线都困卫；第二、三图的被测盲路线被截，也不等于所有不读敌路线必败。

原动作与数值完全保留：步长0.14秒、巡卫0.38秒、下落0.12秒、洞5.5秒。引擎仅把独立存档版本改为2，其余源码与首篇一致。暂停可用于规划，没有强制等待门槛、额外敌速或计数配额。模型中故意等入口回填只是恢复测试，不是通关要求。

## 操作与保存

方向键/WASD移动，Q/E挖左下/右下，P/空格暂停；画布获焦时Enter可开始/暂停。按钮与链接使用原生键盘行为。触控方向可按住，松手/取消/失焦清除输入；不需拖拽、没有跳跃。软砖可挖、硬钢不可挖，剩余灯芯与归灯门状态显示在地图上方。

独立键 `classic-atlas.ladder.v2`、schema2，不读写或迁移 `classic-atlas.ladder.v1`。活动刷新先暂停，洞/巡卫/灯芯状态保留，明确继续才行动；关间、失利和完成态保持。重试只重开本篇当前图，前关记录不丢；确认新旅程只清本进阶篇，取消则保留。首篇按钮会打开原三关和原档。

写入失败继续游玩并准确警告，原有效档不删除，成功重写后清警告；读失败或坏档保留原字节并停止覆盖。没有独立最佳纪录或额外奖励，重读结果不会重复结算。
