# 汀光织界 v2 · 分湾织航

首版的一刀捷径已成为本轮内容改进目标：只用全图百分比，且潮影集中一侧，初始长直线能将另一侧大片水域直接填满；首版浮岛并不是完成的必要决策。v2把关卡目标改为整体织地 + 独立分区织地，不用强制刀数、等待或提速拖时长。

总体目标仍是50% / 60% / 65%，织针、潮影、岸巡的步速和三灯不变。第二湾两处、第三湾三处初始水域各自有潮影及40%目标。安全堤是安全落脚点，也会让风险线立刻闭合，因此不能一条开放线直接穿过多个分区。初始分区范围固定，不随织地重新分母；填区仍从所有潮影做洪泛，只填不含潮影的水域。

玩家要决定先处理哪个分区、从堤/浮岛何处落脚、横切或纵切及哪一侧能收起；闭合后依据新的安全地和未完成区安排下一刀。不同分区的阶梯边界/浮岛组合提供不同出发路线，实际路线与限制见本轮验证记录。

操作：方向键 / WASD，或按住方向按钮；空格 / X准备织线；P / Esc暂停或继续；R请求当前湾重试（需确认）。Tab / Enter操作按钮，画布获焦时游戏快捷键生效。开放线不能取消，回踩第一格退回原岸也会伤灯；潮影碰针/线、自交伤灯，已织区域保留。外岸巡游者也会伤灯，短青环只挡岸巡。三灯用尽或超时失利。

独立保存键 `classic-atlas.inlet.v2`，版本2规则与目标单独校验。完全不读取、迁移或覆盖 `classic-atlas.inlet.v1`。活动局刷新先暂停、开放线和分区进度保留，旧按键不复活；关间/失利/结局按原状态保留。当前湾重试保留前湾航记；确认新旅程只清v2三湾和航记，无额外最佳纪录。写失败保留旧有效字节并提示，恢复写入清除提示；坏档保全且禁止覆盖。

[首版与原进度](../../../../preview/inlet/)完整保留，首版约3秒一关的历史证据不改写。v2仍是原创Qix/Xonix式圈地小品，不是官方复刻；原创海图、美术、封面与代码，不使用原作素材。官方机制来源仍为[Nintendo平台QIX介绍](https://www.nintendo.com/us/store/products/arcade-archives-qix-switch/)。原72条图鉴与其他43项不变。
