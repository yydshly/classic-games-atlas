# 潮汐珠径 · 供珠篇

两条可直接选择的原创珠径，独立于原版十二关与原版存档。

## 一局的三段节奏

- 开阔湾为两色，入口每2.7秒尝试供一珠；回弯湾为三色，每2.3秒尝试供一珠。入口没有完整珠距就等待，不挤压已有珠链，不堆积迟到的供珠。新供珠接入本身不自动消除三连；发射或消除后的断口回接才触发匹配。供珠以随机同色双珠为一组，颜色与弹仓使用可复现随机序列。
- 开局珠和后续供珠均有来源标记。只有消除这些供珠才填潮表；玩家射入的珠既不填表也不刷原珠分。
- 潮表分别达到36 / 42后，入口永久关闭一次。此时仍要清空场上所有珠，包括自己射入的珠，才获胜。达标前短暂清空不会提前结算，入口会继续供珠，弹仓也能恢复。
- 同一步触及终点与清空末珠仍判失败。两关均有150秒有限上限；准备与暂停不计时。标准策略目标约一至两分钟。

三连消除、断口实际回接、相邻同色连锁、第一碰撞射线、交换当前/下一颗均延续原版规则。这两关无礁屏、缓潮或回汐，不增加无尽模式。发射、回接与装填期间锁定下一发。

## 操作与保存

鼠标移动后点击发射；触屏拖动瞄准、松手发射。左右键转向，空格/Enter发射，X换珠，P/Esc暂停，R重来。也可使用滑杆、微调和大按钮。失焦自动暂停，旧指针手势不补发。

使用独立浏览器存档 classic-atlas.tide.supply.v2。刷新按实际操作重放正式引擎，核对供珠、潮表、随机状态和珠链后暂停恢复；不补珠、不重抽、不重置供珠进度。损坏记录被拒绝。存储不可用时仍可游玩，但不能刷新续局。这不是防本机恶意修改系统。
