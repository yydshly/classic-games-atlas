TIDAL THREAD / 潮汐手册

给下一颗，留一段回声。

  1. 旋转潮灯，把同色接起来。

    鼠标移动后点画布；触屏点画布，或拖动瞄准后松手。三颗以上相邻同色才消除，单颗也可先接成一对。每色有独立符号，不必只靠颜色。左右键转向、Enter/空格发射，滑杆与3°按钮可微调。

  2. 看清下一颗，再决定是否交换。

    X / 换珠只交换当前与下一颗，不生成新色；只抽取场上仍有用途的颜色。发射珠在飞行、珠链在衔接或短暂装填时，下一发和换珠会锁住。按住空格不会连发，暂停后的旧手势也不会补发。

  3. 断口会靠拢，连锁要等实际接上。

    清掉中间一段，前段会回接。接上后又凑到三颗，会继续消除并增加连锁；隔着断口或不同色不会隔空算相邻。瞄准虚线停在第一颗珠；近段会遮住远段的射线，弯道上的珠始终沿连续路径行进。

  4. 潮量达标，入口只封闭一次。

    初始珠和新补给珠消除后计入潮量，自己发射的珠不计。目标达成前，即便短暂清空，补珠仍会继续。达到目标后停止补珠，再清空全部场上珠才赢。两关均无能力。

任一颗珠触及终点即失败，触线优先于同一步的清场。每局最多 150 秒；以 HUD 剩余时间为准。P/Esc 暂停，R 重来，失焦/切页自动暂停。刷新按正式引擎重放操作并暂停恢复珠链、弹仓和补珠进度。V2 使用独立存档，不改动 V1。潮分奖励补给珠消除与连锁，玩家插入珠不刷潮量或基础分。
