      三次行动，留给下一轮一个更好的海岸。 无广告 · 本机存档 · 单人规划

      先把日子安排好。

      每章从一座小村庄开始，完成目标才能解锁下一章。地图可以点选；键盘地块索引支持方向键，P 暂停，H 打开手册。

      1. 先看天气与目标。每轮3行动，建设、派工、铺路、探索和研究各用1次；“结束回合”才推进时间。
      2. 建筑不等于收入。农田、林场、采石场、书院必须派驻1位居民才生产。居民无论在哪都吃1粮。
      3. 先活下来，再扩展。农田占用木材与居民；让人去书院可解锁桥梁和增产，也会挤占生产岗位。新村增加2人，同时增加口粮支出。
      4. 贸易需要整条道路。村庄、集市、港口必须上下左右连续连通；每轮用1木1石送2货，风暴停航。
      5. 决定前检查账本。结算预览显示真实产出、口粮与送货消耗。缺粮会失败。结算前可撤回本轮全部安排，结算后不能倒退。
