雨街修理所 v2 · 八日营业样片 · 本机进度独立保存

SINGLE PLAYER / 8 DAYS

THE SHOPKEEPER’S HANDBOOK

先把路铺好，
再等小灯亮起。

  1. 先接待，再按需求修理。

    机器人自动经过接待、所需工位与收银。完成收银才计入目标；选中工位可看近景、排队人数与处理进度。

  2. 空位建工位，工位配技师。

    点画面里的 A–F 工位或下方同名按钮，用紧贴工坊的操作按钮建造、派驻与升级。按钮会说明费用及暂时不可用的原因。

  3. 时间与耐心，都要留意。

    达到流失上限就会歇业。升级能提高后续维修速度；红灯故障需要花 25 币、用四秒保养。后几天每十五秒发工资，收银前别把钱花光。

  4. 八天，一天比一天热闹。

    完成目标并顺利打烊，才解锁下一天。可以重试已解锁的日子，本机最好成绩会保留。重开会放弃当天尚未完成的营业进度。

P / Esc 暂停，H 打开手册。所有建造、调度与升级均有键盘可用按钮。切换标签页、窗口失去焦点或打开对话框会暂停；关闭后仍需主动继续。刷新可恢复最近保存的营业进度，并先保持暂停。
