# 云岬游乐园 v2 · 有限高程设计与游客反馈

本轮新增独立版本，不替换 `preview/coaster/` 的 v1。八座原公园、十二段地面走向、模块和有限班次闭环保留。既有海岛、轨道、人物与列车的代码绘制风格延续；本轮是玩法与可读性增量，不声称完成美术质感升级。

## 这一轮的可玩改动

- 1、4、7 号段末端的峰顶可相对原高程上下最多 8 米，每步 4 米。每米改造费 8，降低也需改造支架，复原退回费用。
- 相邻两段的坡度、长度和重力能量同步重算；两段已装提升/驱动若会失去合法坡度，先拒绝改造并说明需拆换哪段模块。
- 渲染、支架、列车位置和高程剖面直接读取同一动态几何。基准虚线只画实际改动的节点和相邻轨段。
- 舒缓派与挑战派各有有限需求与预留座位。试车后显示愿上人数、不愿人数和满意；实际上车数决定每班营收，满意决定口碑。
- 游客牌位于海面空白处，避免遮挡轨道及编号点击区；HTML 两组卡片提供更大文字与表情。完整回站才结算，并保存上一班反馈。
- 每次结构或模块改动使旧安全报告失效，必须重新试车；运行、暂停和终局不允许直接编辑。返回设计可以放弃未完成班次，保留已完成结算。

## 两个真正能完成第一园的方案

均用 1 号段提升、12 号段制动，其余普通轨，按正常命令试车并自动载客，不改状态、时钟、现金或胜利标记。

| 方案 | 峰顶 | 建造/余款 | 刺激/舒适/峰速 | 两组愿上 | 每班收入/口碑 | 达标班次 |
|---|---:|---:|---|---|---:|---:|
| A 省预算 | 28m | 220/160 | 33.2 / 97.2 / 20.8m/s | 5/5、3/5 | 128/74 | 3 |
| B 快达标 | 32m | 252/128 | 36.9 / 95.2 / 22.5m/s | 5/5、4/5 | 144/84 | 2 |
| 继续加高 | 36m | 284/96 | 40.2 / 92.9 / 24.2m/s | 4/5、5/5 | 144/83 | 2 |

32m 使用更多预算、牺牲部分舒适，换来较少班次达标；36m 让挑战派更开心，却损失舒缓派、口碑略降。因此升高按钮不应一直按到最高。

## 游客规则的精确定义

每班舒缓派需求人数为座位数的一半向上取整，挑战派为剩余座位；这些是两个群体，不是独立游客寻路 AI。设本园刺激门槛为 T、舒适门槛为 C，测得刺激 t、舒适 c。

- 舒缓派满意 = clamp(100 − max(0,t−T−6)×5 − max(0,C+5−c)×4, 0, 100)，四舍五入。
- 挑战派满意 = clamp(100 − max(0,T+8−t)×6 − max(0,C−c)×3, 0, 100)，四舍五入。
- 每组愿上人数 = round(该组需求 × 满意 / 100)。安全未通过时均为 0。
- 收入 = 两组实际上车人数 × 票价。
- 口碑 = round(按两组需求人数加权的满意 × 系数)，体验达标系数 0.9，未达标 0.3；安全未通过为 0。

## 原作价值和差距

具体参考：Windows 版 RollerCoaster Tycoon 1 / Deluxe（Deluxe 包含初代与 Corkscrew Follies、Loopy Landscapes）。参考其逐段搭建、试车与游客自主反应相互影响的循环。创造、挑战与看人们使用自己设施的乐趣是根据官方介绍、手册和创作者访谈所作设计分析，不是完整受欢迎原因研究。

原作使用 Excitement / Intensity / Nausea；本作的刺激/舒适及安全门槛是原创简化模拟，不能等同原作运动物理。仍无自由延伸/连接轨道、道路商店布局、独立游客路径与需求、员工故障检修和长期全园经济；不能称完整 RCT 复刻或真实工程设计工具。

## 版本与证据边界

- 独立进度键 `atlas-coaster-v2-progress-v2`、`atlas-coaster-v2-current-v2`；不读取、迁移、覆盖 v1 键。
- 当前局 schema 为 `cloud-cape-coaster-v2`、version 2；高度命令进入可验证重放。刷新中途列车暂停，明确继续后才走。胜利后刷新打开最新解锁园；损坏记录不会凭空解锁。
- `comparison.html` 并列原作介绍、v1/v2 同状态离屏图、两种有效方案和过度加高反例。
- `evidence/` PNG/视频由正常命令与固定步长引擎到达状态后原生 Canvas 离屏渲染，图内带标记。视频是12秒、20fps载客片段，经过第1–6段；不是完整试车、浏览器实机或真手机录制。
- Node 物理、控制器模拟、恢复、几何与存储隔离验证不能替代公网浏览器、移动触屏、视觉布局、可访问性和性能验收。这些阶段由发布后另行验证。
- 本轮不新增公园、模块种类、票价操作或更多经营系统。没有外部字体、运行网络依赖或付费模型资产；原作介绍小图使用图鉴已存在素材及明确来源，不作为自制游戏素材。
