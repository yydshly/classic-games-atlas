      参考原作、这版做到了什么，以及差距

      RollerCoaster Tycoon 1 / Deluxe · Windows

      参考价值：自己搭轨道、试车发现问题，再看游客愿不愿意坐。创造的自由与预算约束相遇，一点改动会连到速度、感受和生意，这也是本轮选择借鉴的乐趣。此判断是设计分析，不代表我们测量过原作受欢迎的全部原因。

      v1 是固定高程的模块配置。v2 新增三处峰顶的有限升降：高程会真实改变相邻坡段长度、重力能量、速度与支架画面；两类游客的意愿影响实际上座、营收和口碑。原八园保留，两个版本分别存档。

      明确差距：仍不能自由延伸、旋转或连接新轨道，也没有全园道路、商店、员工、独立游客寻路及长期经营。原作使用兴奋、强度、恶心评级；这里的刺激/舒适是原创简化模型，不能等同原作物理或真实工程。

      01 / 读懂环线

      每园有十二段环线，地面走向与弯道半径固定。点击选段，改造1、4、7号段末端的峰顶；同一节点连接的两个坡段、长度、速度和画面会一起变化。每段只装一种模块。

      02 / 在预算内配置

      03 / 先派空车

      空车试跑不计入载客班次，也不产生营收。诊断会给出停滞、速度或转弯问题所在的轨道。修改高程或模块都会清除旧报告，必须重新试车。

      04 / 安全与达标

      05 / 有限班次的经营

      06 / 随时停下来

      暂停会停止列车和计时。离开窗口、打开手册或公园列表也会暂停；关闭弹窗后仍保持暂停，按“继续”才恢复。刷新后，未结束的当前局会恢复方案，保存中的试车或载客会暂停等待。已结束的局只保留通关记录与解锁；没有可恢复的当前局时，进入最新已解锁公园。

      速度与受力是游戏简化模拟，不能用于真实设施设计或安全认证。

      快捷键：P / Esc 暂停或继续，T 试车，O 开放，D 返回设计，R 重试，H 手册。输入框和弹窗内不触发全局快捷键。
