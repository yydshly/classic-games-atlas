      三段短航程 · 一座成长的港

      用每笔交付，开出下一条航线。

      1. 先看委托起终港、箱重、出库回合和期限。建设航道后填写港序购船。
      2. 开始营业，单步或自动推进。船自动装卸与往返；轻舟1格，驳艇2格。实际卸货才到账。
      3. 用收入继续建航道、买船。共享港可花钱升级双泊位，但同一航道仍只容一船。
      4. 改线必须停港且空舱，并包含船所在港。可暂停后投资；暂停不会推进期限。

      键盘：空格推进 · P暂停 · R重试。点击地图港口可填写路线；全部功能均有文字按钮。
