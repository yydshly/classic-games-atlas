# 街巷护送 · 战术篇 v2

三个有限街区：晨街学习纵深避开锁定直冲；雨巷保护灯车并决定停靠或随行；夜岸在监守的直冲/横扫间等待破绽。每街仍有三个路口，灯车抵达才推进，第三街结束后可重玩。v1保留，v2使用独立本地存档。

## 保留与新增

保留原有纵深移动、三式连击、有限耐力闪步、E停靠、两份H灯露、灯车路径、失败重试、暂停及合法输入重放。沿用原守灯人、敌人、灯车、三环境绘画WebP及环境光。

新增纸鸢影锁定直冲；监守交替直冲和横扫，蓄势/有效阶段护势只受25%伤害且不被普通拳打断，90帧收招受150%伤害。收招期间连续拳不会重置或延长破绽。完整三式原始伤害16/20/28，护势中实际4/5/7，破绽中24/30/42；监守112光息。每招每个对象最多一次接触，闪步保护接触也消耗该次命中。

冲线的起点、终点、纵深和方向在蓄势开始锁定；冲出只沿锁定线移动，不追踪玩家，不越当前封路。横扫为固定左右105、纵深62的矩形地面区域。矩形预警与判定共用区域函数；直冲还要求冲锋实体接近目标，不在起手时提前命中整线。普通近战保留原前方矩形。

岩肩守优先追灯车；灯车本身不会因为玩家离开就免伤。E停靠可留在后方，H仅在150范围内兼修灯车。所有关卡资源有限，没有自动回生命或新增装备系统。

## 检验边界

规则控制器通过合法输入驱动60Hz引擎，和浏览器按键/手机触控实测是两类证据。离屏截图调用实际renderer，但评审夹具的初始位置经过设置，不作为普通通关证据。当前不把目标时长称为实测，也不把历史v1手机记录用于v2验收。

## 素材

原四张原创AI辅助绘画以同源根目录资产复用。动作补帧为本项目新生成的透明位图，接入运行时的实际连击/冲锋/监守阶段。没有使用商业游戏角色、截图或音轨；仅保留清版动作的一般机制借鉴。
