# 战术篇 v2 · 验证范围

## 已核验

使用合法输入的确定性控制器完成三关，无坐标、血量、资源或结算写入。晨街15.22秒、雨巷17.75秒、夜岸20.63秒。该控制器快速精确操作，以上不是人类游玩时长，也不是浏览器UI实测。

夜岸读招路线零自损、无需灯露；主动贴近连续拳路线自损48、用一份灯露。两者均普通输入完成关卡。另有独立静止监守测试：固定位置持续拳死亡；读招移动反击胜出。这是隔离规则检验，不是普通关卡证据。

首关另跑完整躲线示范，17.88秒通关，零自损、一次闪步。雨巷路线验证了一次近车灯露维修。冲线锁定、封路边界、单招单次接触、护势与破绽、重装袭车、停靠/维修、耐力/灯露、暂停/输入重放/胜败终态均有规则测试。轻量DOM适配测试检查末关重玩、开始、暂停、继续与重试接线；不等同浏览器布局、原生按键或触屏验证。

## 浏览器普通路线复核

1. 从v2独立干净存档开始，关闭手册后开始晨街。方向键/WASD移动，J/空格连击；K/Shift闪步，H灯露，E停靠。先让纸鸢影出现橙色长条，再往上下纵深移出；不要沿冲线向前躲。冲出结束后对齐脚底回去连击。
2. 灯车在240范围内才跟随；敌人靠近时会自行停下。清完来敌后回到车前约60单位，跟它一起走，抵达路口才出现下一群。三段清完也需送车到终点。
3. 雨巷的岩肩守优先袭车。可先E停靠，回车边打重装，再E跟随。车受损后站在150范围内H，确认灯露减一、车生命增加，满血对象不超上限。灯露共两份。
4. 夜岸末段只有监守。橙色狭长条是直冲，往上下离带；宽矩形是横扫，向范围外退。金色“护势”时拳不能打断；青色“破绽”出现后迅速对齐连击。直冲/横扫交替，收招结束前不会重新追身。
5. 验证三关完整胜利和从晨街重玩；前两关至少一次失败后重试。途中暂停并释放按键，刷新应先暂停且保留合法进度；胜败后刷新保持该终态。帮助、选关、失焦时不继续推进。

仍需真实浏览器确认整个普通控制链、视觉遮挡、整页响应式和按键体验。窄屏、多指和实体手机未在本轮验证；不引用v1历史记录作为v2通过证明。离屏画面调用实际renderer，普通路线快照和隔离评审夹具分别标注。


## 浏览器反馈后的脚点可读性修整

真实浏览器记录：晨街28.13秒胜；雨巷22.32秒及23.42秒两次灯车归零失败，守灯人均120光息。第三关和监守的浏览器普通实玩仍未验证。控制器结果不替代此范围。

仅增加脚底定位标：玩家圆圈、附近敌人菱形，颜色和形状均区分；中心严格位于实际脚点，并在人物和灯车之后绘制，避免车辆遮挡。标签可能为避让而偏移，定位应参考脚点。此修改不改变血量、伤害、判定、难度或解锁，也不保证通关；需要后续浏览器确认可读性。
