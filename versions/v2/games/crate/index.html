WAREHOUSE MANUAL / 仓格手册

先给自己留一个站位。

  1. 只能推，不能拉。

    方向键 / WASD 或触屏方向盘移动。也可点相邻格一步移动。箱子前方有空格才能推，不能同时推动两只箱子。把全部箱子推到金框目标上即完成。

  2. 撤销，不限次数。

    Z、退格或撤销按钮退回一步，胜利后也能撤销继续尝试。R 重新开始当前关；切换关卡会开始所选关卡的新局。胜利后不会自动跳关，点“继续下一仓”再出发。

  3. 看目标，也看墙角。

    归位箱变为青色并显示勾号，金框仍然可见。非目标静态墙角会有提醒，但不会阻止操作，也不能识别所有复杂互锁局面。别急着把每只箱子推到最深处。

刷新可恢复当前棋盘及撤销历史；三关均可直接选择，两项个人最佳另行保留，不代表最优解。P / Esc 暂停。短按一步，长按有节奏地重复；切关会清空旧输入。
