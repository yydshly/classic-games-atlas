# 仓格计划 · 三个小仓

本版本是三个原创短推箱题。原20关继续保留在四层上级的 games/crate/；本版只使用独立的 classic-atlas.crate.authored.v2 本地存档键。

## 三次发现

1. 留一个站位：下方的目标也是推动上方箱子所需的站位。立即把近箱推到目标，会堵死这个站位。先向上让开，再完成另一箱。
2. 先深，后浅：第一个箱子经过浅位时，继续送到尽头。浅位有箱而深位未完成时，再将第二箱推入入口，会无法继续。这里说的是最终停放顺序，不是不能经过浅位。
3. 暂借泊位：开始已有一箱归位，但它挡着另一个箱子的推箱站位。可向左或向右暂时移开，用过后再送回。

三关均可直选。思路提示默认折叠，不提供自动执行或逐步答案。只有全部箱子归位才算完成。错误路线可以撤销或重开，不添加武断的失败弹窗。只提醒确定的非目标静态墙角，不声称识别所有死局。

## 保持简单规则

只推一只箱子，不能拉箱，也不能同时推动两只箱子。普通走动和推箱都计一步；推箱另记次数。不限次数撤销，胜利后也能撤销继续。个人步数和推箱纪录可以来自不同完成局，不代表全局最优。

- 方向键 / WASD：移动；Z / 退格：撤销；P / Esc：暂停；R：重开。
- 触屏方向盘短按一步，长按受控重复；可点相邻格移动。
- 暂停、切关、失焦清空待处理输入。当前局刷新后先暂停。
- 存档只保存合法动作记录，重放恢复棋盘和撤销历史。不可信数据拒绝恢复；存储受限时仍可游玩。
- 恢复日志上限20,000步，防止异常存档长时间阻塞。现场撤销没有这个限制；超过上限会提示棋盘动作不再继续保存，刷新将回到此前保存的位置；个人纪录和设置仍会尝试保存。

## 验证和边界

三题分别有13、15、15步合法开发参考解，生产规则逐步重放和计数检查通过。独立穷尽搜索验证三个发现点：
- 禁止第一题向上让开中箱，77个状态穷尽后无解；立即推到近目标后，13个状态穷尽后无解。
- 第二题采用带历史标记的搜索，验证所有“浅位已占、深位空、第二箱进入入口”的路线都不能获胜：295个状态，其中8个已发生错误顺序。仅禁止深目标归位会形成平凡结论，因此不把那项弱检验作为顺序证明。
- 第三题禁止箱子离开初始已归位目标，12个状态穷尽后无解。左右两侧都能借位，不把左移说成唯一解。

已完成生产引擎、DOM事件夹具、存档和撤销检查。DOM夹具按开发参考解输入，不能代替真人自行解题；未做真人难度评价。生产Canvas绘制器通过原生离屏画布输出初始、借位和通关图，已检查棋盘表现；这不是浏览器页面截图。浏览器中的真实布局、键盘/触屏、音效和实际刷新验收仍待完成。
