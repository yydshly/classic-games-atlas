# 夜航拾光 v2 · 双港短航

独立入口，两座可直接选择的原创小迷宫。环堤穿灯有41处可收集光点，双湾交汇有46处；收齐即胜，三盏航灯耗尽可重试。默认普通玩法，无难度暗改、角色养成或复杂积分。旧版十港与旧存档不在本版本修改范围内。

## 这一版新增

- 左右贯通航道。玩家与三类巡灯共用同一邻接规则；出口不设安全区，敌人寻路与回巢都可穿隧。画面从一侧离开、另一侧进入，不横扫地图。
- 公开巡游／围追节奏。巡游4.5秒，围追12秒，循环交替；巡游各赴编号航标，围追沿用原有循迹、截路、巡航角色目标。辉光退避、反制回巢优先于普通目标；阶段钟仍继续计时。这些时长是本作原创设定。

三种敌人、前方三格预判、辉光反制回巢、提前转弯、三命收点规则均继承旧实验，不作为本次新增。

## 操作与保存

方向键／WASD或触屏短按转向，方向提前缓冲，反向也在下一格点执行。P／Esc暂停，R重开本关；失焦会暂停并清除残留输入。刚拾辉光同刻生效，到期立即失效；同刻普通末点与致命碰撞以扣命优先。

浏览器键 classic-atlas.lantern.v2 保存选关、个人纪录及声音；刷新从所选关重新启航，不恢复未完局。两关无需解锁。坏存档回退默认；存储被拒时仍能游玩。

全部地图、风帆、几何巡灯、码头画面与音效为原创程序绘制，无原作角色、图片、迷宫、音乐或外部素材。静态资源远低于2MB，无外网加载或账号。

## 验证范围

纯引擎测试覆盖图连通、真实隧道寻路／碰撞、阶段改变路线、缓冲反向、辉光及回巢、单次扣命、末点死亡优先、暂停和自然三命失败。四组正常输入收点路线均胜，额外以30／60fps、两种提前转向窗口重放16次，均胜，无修改游戏状态或参数。UI有模拟DOM存档与选关测试。离屏图片由实际生产Renderer生成，只验证绘图，不代替浏览器／触屏实机验收。
