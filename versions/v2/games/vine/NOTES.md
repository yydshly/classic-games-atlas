# 青藤回廊 · 两座开放花园

两张 12×10 原创地图：晨露庭（8 枚青芽）、双石岛（10 枚青芽）。身体从 3 节逐枚增长，收齐目标后实际进入出口才能获胜。两图均直接可选；原版 16 关仍位于 `/games/vine/`，没有修改。

方向键/WASD、滑动与方向按钮；最多两步转向缓冲，禁止直接反向。固定节拍为 0.29/0.27 秒，重试同一种子。食物仅在当前可达空格生成，既不挪走现有食物，也不替玩家规划安全路线。碰墙与身体会失败。不增长时可进入本步释放的尾格。

独立存档键 classic-atlas.vine.open-gardens.v2。逐步保存身体、方向、食物、进度与随机状态。恢复先暂停，清除旧缓冲；失焦或页面隐藏也暂停。两图切换开始新一局。
