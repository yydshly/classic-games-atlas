# 街市双商 v2：设计与来源

## 参考的核心体验

设计参考《大富翁 / Richman》系列的骰子移动、地产投资、升级、玩家间租金和相对财富竞争。官方产品介绍可见 [Richman 11 商店页](https://store.steampowered.com/app/2074800/Richman_11/)。本作把这一循环收束为两位商人、十二格街市、八间铺面和三场有限对局；并非原作复刻，也没有使用原作角色、商标、美术或音频。

## 原创内容

庭院背景、茶铺 / 包点铺 / 绸缎铺的一二级精灵、青衣与朱衣商人均为本项目用图像生成工具制作的原创位图。透明精灵经过单元格排布与 WebP 压缩后直接参与游戏渲染。所有权旗帜、铺面名称、价格、等级和路径由渲染器叠加。晨市底图在雨桥与灯会场景以不同光色、雨丝与灯光复用；不是三张独立背景。商人为静态关键姿态沿路径插值移动，不是完整逐帧行走动画。

代码、玩法数值、场景布置和界面文字为本项目独立实现。无外部付费运行服务，不含股票交易、在线对战或拍卖。游戏在浏览器本地运行，进度存储在本机浏览器。

## 完整玩法边界

- 晨市：8 个完整轮次，对手偏保守；雨桥：10 轮，对手偏抢铺；灯会：12 轮，对手偏平衡。
- 每轮双方各行动一次，先青旗再朱旗；双方起始现金 850、定步券 2 张。
- 买入为 1 级，最多升到 2 级；持有同类至少两家店，租金乘 1.5。
- 租金从付款方现金转给产权方。付款不足先自动清算产业补款；资产用尽仍不足才破产。
- 出售回收投入的 70%；轮末结算净资产按现金加产业购入及升级原值计算。净资产相同即平局。
- 骰子状态和掷骰结果在行动后立即保存。重新载入延续现有结果；重新开局才生成新局。

## 验证范围

自动规则测试覆盖三局各 100 个种子，共 300 个完整对局。使用保留现金、买入与升级的普通策略，三局均出现玩家与对手获胜，不保证任意种子或任意策略必胜。测试检查现金流水恒等式、唯一产权、租金只支付一次、非法动作不改变随机数/资金、债务清算、回合边界与刷新恢复。

Canvas 离屏渲染已检查素材实接入、门牌与角色分离。控制器使用 DOM 模拟按钮测试；这不等于真实浏览器鼠标、性能或触屏验收。窄屏样式提供可横向查看的棋盘与换行按钮，尚未通过真实手机触屏验证。
