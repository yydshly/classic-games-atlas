# 堡垒防线 · 双车共守 v2

## 设计
保留原版十关为独立入口。本版只包含两张原创短图，支持单车或同键双车，共享基地、独立出击次数、方向、开火、速射与车体护盾。左右入口适合分守，中央砖带可破开换防。每张六台敌车，目标约一分钟至两分钟，不是时间生存模式。

1P 金色 / WASD + J；2P 蓝色 / 方向键 + Enter。Enter 在待命/暂停时开始或继续，必须释放后才作射击键。P / Esc 暂停；窗口失焦、页面隐藏清除输入并暂停。触控仅提供 1P。

两车实体互挡，死亡车辆不阻挡。失去一次出击后搜索没有墙、基地或车辆占据的安全格；不能安全重生时暂候空位。拾取维修补充拾取者出击次数并修复基地，速射和车体护盾不转交队友，基地护盾共享。一人耗尽可由另一人继续；全队出击耗尽或基地毁坏立即失败。终局先处理败因，不由随后清场覆盖。

## 来源与明确差异
参考 Nintendo 发布的《Battle City》官方电子说明书第 3–5 节（PDF 页 5–7）：https://www.nintendo.co.jp/data/software/manual/man_FCTJ_00.pdf

参考范围是双人护卫司令部、清除敌军、基地被毁失败，以及分辨两个玩家。原作友弹命中会暂时令友车无法移动；本版明确简化为友弹穿过友车且不造成伤害，不宣称原作一致。关卡坐标、六敌编组、能力时长、三点基地耐久和图形均为本项目原创/自有实现，不含原作图像、音效或地图。

## 保存边界
使用独立 classic-atlas.fortress.v2 键，只保存最近行动/人数选择与按地图、人数分别记录的最高分。没有战斗快照、刷新续局或虚构检查点。原版 classic-atlas.fortress.v1 不读取、不写入。坏记录/拒绝存储不会阻止当前游玩；坏记录不自动覆盖，显示无法保存。

## 验证边界
Node 输入回放是一个自动控制器分别输入两车，只证明规则与输入通路，不证明真人合作体验。离屏画面由实际 renderer.mjs 绘制，证明绘制内容，不是浏览器页面截图。未验证实际浏览器的键盘防冲突、触控、窄屏和短屏观感，未宣称浏览器验收或已公开发布。没有联网、AI 队友、关卡编辑器或新增道具种类。
