战场手册 / 操作与简化

黄色 1P 与蓝色 2P 各有三次出击。拾取维修只补充拾取者出击数并修复共享基地；速射与车体护盾属于拾取者。护盾也保护共享基地。砖墙可击碎，钢墙不可破，水域不可驶入但炮弹可穿过。敌我炮弹可相消。

本作原创两张短图。参考《Battle City》双人共同护卫基地的规则；原作友弹会令友车暂时瘫痪，本作明确简化为友弹不伤。没有联网、AI 队友或地图编辑器。

仅记录最近选择和各图各模式最高分，不保存战斗中途。刷新会回到整备；P / Esc 暂停，失焦或隐藏页面自动暂停。双人模式需可同时识别多键的键盘。
