# 光轨砖阵 v2：布局可用性修复候选

此版本只处理完整砖区、光球、挡板、即时状态和操作按钮的同屏可见性，**不是全面品质升级**。原版和固定 v1 文件不改；美术、600×720逻辑场地、十二关、物理、音效、强化规则保持原样。

## 布局范围

- 压缩页眉及重复说明，保留原有按钮尺寸；余命、剩砖和光球状态在场地上方常显。
- 根据视口高度扣除实际 HUD、操作条、提示行占用，等比缩放完整场地，不裁剪砖区或挡板。
- 开始、教学确认及继续时对齐游戏区，避免焦点返回后仍停在偏下滚动位置。
- 视口和提示高度变化时重新计算；较短屏幕的结算卡可内部滚动，侧栏详细资料保留在下方。
- v2 使用独立存档键 `classic-atlas.prism.v2.viewport.20261018`，不读取或覆盖 v1 进度。

2026-10-18 已完成源码核对、JavaScript 语法检查、13项既有物理/规则回归及四组尺寸预算模型检查。尺寸模型使用假设的 HUD 高度，不是真实浏览器几何测量。没有重跑十二关或新增美术。
