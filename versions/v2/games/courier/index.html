THE POSTMAN'S FIELD NOTES

看见路，再转弯。

山路会真的向左或向右延伸。进入金色转弯窗口后，按一次对应方向，抵达路口便转过去。

  1. 直路　← → / A D 换道收信
  2. 转角　金色提示亮起，← 或 → 预约转向
  3. 橙栏　↑ / W / 空格 跳跃
  4. 蓝梁　↓ / S 滑行

转弯窗口约 1.3 秒；方向锁定后不用连按。转完回到中道。长按不会重复操作。
