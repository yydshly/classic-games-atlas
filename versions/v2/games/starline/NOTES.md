# 星泡航线 v2 · 两张下压星图

原创泡泡清场小品。几何绘制的五色星泡、符号、星图和合成音效均为本作设计，不使用原作角色、音乐、贴图或关卡。

## 玩法与差异
- 同色六邻接连通三个及以上消除；失去顶端连接的泡泡掉落。
- 两侧墙面反弹。虚线与落点使用实际飞行的同一碰撞与附着规则。
- 两张固定星图：浅层多支撑悬岛“悬岛落潮”，深层双塔与侧通道“双塔侧航”。
- 每结算4发，顶板与仍在场的全部泡泡向下移动一个六角格行高（约41.57画布单位）。换弹不计发射；瞄准没有时间限制。
- 本发先消除并结算悬岛；清空立即胜利，不再下压。否则执行应有的下压，再检测固定底线。
- 没有有限弹药失败。落点无空间或星群触及底线失败。
- 每发可交换一次当前与下一颗；新球仅从场上仍存在的颜色中抽取。
- 独立v2保存，不读取或覆盖原十二关v1记录。刷新时恢复最近完整结算；飞行中的这一发回到发射前，避免重复下压。
- 每4发、下降距离、底线位置、固定随机种子与两张关卡都是本作的原创参数，不声称等同街机原版。
