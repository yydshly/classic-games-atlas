STEEL GALE / 作战手册

读高低线，再向前。

  1. 伏低之后，枪口也降低。

    A D / 左右移动，S / 下键在地面伏低并停步，松开后起身。空中按下不会缩小身体。伏低仍可按 J 向当前朝向射击，低位装置需要低枪口反击。伏低不提供无敌。

  2. 高线与地波，分开应对。

    金色胸高线闪烁约一秒后发出三连射，保持伏低可从弹下避过；第二关会交替发出红色贴地波，先松开伏低再按空格跳过。敌方射线高度固定，不会跟着你的伏低下移。空格长按高跳、早松短跳；不会自动连跳。

  3. 清除装置，走到出口。

    每关两座低位装置，全部清除后出口打开。两关可直接选择。W / 上键上斜射；K 每关有两次近距脉冲，清除近弹并提供短暂保护，伤害三格，不回血。

  4. 复归不等于原地续局。

    五格护甲、三次出击，受击后保护 1.2 秒。护甲耗尽消耗出击，从起点或已到达的检查点满护甲复归；清除的装置、剩余敌方护甲、武器与脉冲消耗保留。最后一次失败后重试重置整关。

触屏可同时按住伏低与射击，松开伏低再跳跃；上斜射按钮切换。松手、取消和失焦都会清除旧输入。P / Esc 暂停，R 重开。刷新从最近检查点重新整备，保留当前护甲、出击、武器/弹药、脉冲、敌人护甲和拾取结果；不保留当前坐标或飞行弹，恢复先暂停。个人最佳仅保存在本机，与原版存档独立。
