这一回合，按顺序运转

  1. 汲露塔产5水（终章第2回合仅2水）。
  2. 芽穗圃用1水 → 4食物。
  3. 匠作坊用1水+1食物 → 1匠作箱、4岗位。

      让一座小岛，慢慢安家。

      1. 先接通路。从有旗帜的驿站沿上下左右铺路。建筑任一占格邻接连通路就接通；建筑本身不替你传路。石脊与普通水面不能覆盖；第二章只在G4/G6桥位建桥，两格工坊要预留空间。
      2. 把建筑放在合适土地。水塔紧邻水面，芽穗圃只能在绿土；花园须通路才覆盖2格内小屋。每座开工工坊提供4岗位，一座小屋要2岗位、1食物和1水。
