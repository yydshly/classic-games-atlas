# 林野杯赛 v2 · 读弯追风

限定一轮增量，独立入口 `versions/v2/games/kart/`；原 `preview/kart/` 完整保留。保留八赛道、四车双圈、原物理、AI、碰撞、道具强度和解锁目标。本轮延续原插画美术，不声称完整复刻或视觉质变。

## 可感知收益

- 单份主要 DOM HUD；移除画布内标题/顺位/底栏，赛道有效视野扩大。
- 原车体已有真实 heading；本轮加强前鼻、车灯、尾灯及车手朝向，增加可辨玩家标签。
- 漂移阶段对应实际蓄力：白色进行中；蓝色达到 0.55 秒释放门槛；金色在 1.15 秒后表示已积累较多。冲刺时长仍连续增长，没有新增离散等级或隐性加速。
- 前方 30–65 单位的实际曲率提示急缓；车前短箭头沿真实道路，仅为方向提示，不是最佳线路。
- 脉冲候选完全沿用纵向环距、横向距离、54 单位半径、护盾与完赛排除规则。只标识附近当前有效对象；无目标时明确提示，使用后报告实际命中数量。
- 修正视觉动画时间单位，使冲刺/受击表现使用毫秒，不以加速模拟制造效果。

## 可选辅助与存档

初次默认关闭，可在 ready 状态选择；起跑后不允许变更。辅助仅通过普通 steer 输入补偿 75% 曲率并阻尼车头误差；左右键仍选择路线。没有位置/速度/进度写入，没有自动追中线、刹车、漂移释放或道具。所有 AI 控制不变。

当前局的 `assist` 随 checkpoint 保存/恢复；结算包含 `assisted`。进度内 `best` 和 `assistedBest` 分开保存，明确标记。使用辅助达标也解锁下一站，但不覆盖手动纪录。独立键：
- `atlas-v2-kart-20261018-progress-v1`
- `atlas-v2-kart-20261018-current-v1`

## 验证与限制

本轮本地检查：原 26 组引擎（135,780 断言）、16 组进度、43 组原控制器事件以及新增辅助控制器回归；v2 针对性检查覆盖默认关闭、ready-only、恢复、成绩隔离、范围/护盾/跨起点、阶段阈值和无输入不通关。手动八赛道逐步差分与已核实 v1 保持一致（排除新增模式标签），未降 AI。

模型普通数字方向每 100ms 更新可完成原八站；可选辅助测试每 500ms 更新普通按键，首场可完整双圈，含漂移和道具。它们是 Node 模型/模拟事件证据，不能冒充真人或浏览器驾驶。持续刹车、不操作和一直转右均失败。

原生离屏图来自同一通过实际 start/step 输入达到的 8 秒状态，渲染不改 state。它们只支持画面结构比较。正式发布后仍须验证正常速度完整比赛、400px 外部 HUD/赛道/触控同屏、暂停恢复、真实触屏多指、输入延迟和手感。无本轮音频验收。

所有资源均沿用/修改本项目原创 Canvas 几何，没有下载第三方美术、安装新软件、联网模式或付费服务。具体系列机制来源与边界见 about.html / SOURCES.json。
