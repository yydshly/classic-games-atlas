DRIVER'S FIELD GUIDE

先读弯，再追风。

四辆赛车，两个完整圈。你驾驶橙色赛车，按当前赛道的名次目标与时限完成比赛。

  1. 自动加速，自己掌方向。

    三秒倒计时结束才开表。赛车自动向前加速；A / D 或左右箭头相对车头转向，S / 下箭头刹车，不会倒车。触屏按住下方按钮，可以同时转向、刹车或漂移。偏离路面会减速，持续转向会驶向路肩，及时回正。

  2. 漂移要转向，也要收手。

    转向时按住空格、Shift 或“漂移”蓄力；达到阈值后松开漂移，获得短暂加速。先在宽弯练习，急弯先刹车。蓄力条会显示是否可以释放。

  3. 一个槽位，等一个好时机。

    空槽驶过菱形补给箱获得道具；满槽不拾取。E / J 或“使用道具”消耗当前道具。松果冲刺加速 1.3 秒，苔叶护盾保护 2.8 秒，铃果脉冲使附近前后方 54 赛道单位内未受保护的对手减速 1.1 秒。四车共享补给箱，拾取后 5 秒刷新。

  4. 两圈冲线，名次也要达标。

    起跑后沿同一方向完成两圈。名次按比赛进度排列；冲线后看实际完赛顺位。须在时限内达到本场目标名次，否则本场失败；超时也失败。比赛结束即停止，重试同一赛道或完成后解锁下一站。

  5. 暂停之后，等你继续。

    P / Esc 暂停；打开手册、赛程或离开页面也会暂停并松开全部驾驶输入。关闭弹窗仍然暂停，需要明确继续。刷新可接续未完成比赛，恢复后先暂停，不计算离线时间。损坏的当前局会舍弃，独立纪录尽量保留；存储不可用会明确提示。

v2 可在起跑前选择弯道辅助（默认关闭）。它只通过普通转向输入补偿 75% 弯道曲率并稳住车头，不会自动选线、刹车、释放漂移或使用道具。辅助与手动纪录分开，赛道、AI、碰撞、拾取和名次规则相同。

按钮也可用 Tab 聚焦，再按住 Enter / 空格驾驶，松键或移开焦点停止该次输入。画布外提供圈数、名次、时限与道具文字；竞速仍需要观察赛道。
