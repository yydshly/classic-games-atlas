01 / FIND AN ANGLE

先找角度，再蓄力。

带球靠近右侧球门。脚下金环标记球权，白环标记你控制的人。浅色短箭头就是出脚方向。朝前或斜前移动调整射门角度；停下会保留朝向，背向或侧向射门会转向对方球门。按住空格或射门按钮蓄力，松开射出。蓄力更久，球速更快。

02 / KEEP IT MOVING

一脚传球，换一个机会。

先带到边路吸引防守，再按 J 传给另一名外场队友；自动切到接应者，等球到脚下再转向右侧射门。J 无球时近身抢断。K 切换两名外场队员；门将会自动站位、扑球和出球。

03 / PLAY TO THE WHISTLE

围栏之内，踢到终场。

球碰围栏会反弹，进球后重新开球。没有越位、犯规、界外球和点球。终场领先才获胜，平局也需重赛；胜利解锁下一场。

THE MEADOW RULES

这块草地，怎么踢。

  1. 深蓝球衣的草甸伙伴向右进攻。每队两名外场球员和一名自动守门员，亮环标出你控制的球员。
  2. WASD 或方向键移动、带球；触屏可同时按方向与射门。朝前或斜前移动调整射门角度，停下后保留朝向；背向或侧向射门会转向对方球门。
  3. 按住空格或“射门”蓄力，松开才射出，最长 1.2 秒。只有控球球员能够射门。暂停、换人和传球 / 抢断会取消蓄力，取消触摸也不会误射。
  4. J 有球时传给队友，无球时在近身距离尝试抢断；K 在两名外场球员之间切换。门将自动扑球、接球并出球。
  5. 围栏会让球反弹，需要踢出的球完全穿过球门才得分，不能只带球走进球门，随后重新开球。没有越位、犯规、界外球或点球。每场时间见记分牌，比赛终场领先获胜；平局算未获胜，可重赛。
  6. 胜利解锁下一场，共 8 场。每场独立计时，最好比分与当前比赛分开保存。刷新只恢复有效的未完赛存档，并保持暂停，离线时间不计入比赛。
  7. P / Escape 暂停，R 重赛，? 查看玩法。打开窗口、切出网页都会取消旧输入并暂停；返回后请点“继续比赛”。聚焦方向或射门按钮时，按住 Enter / 空格也可操作。
