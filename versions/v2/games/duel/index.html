操作与面向

先点画面聚焦键盘。面向沿最后移动方向；向右靠近对手后再格挡，背向无法挡住。按住方向再按W/↑，即可沿该方向跃起；稍离地后J变为空中踢。起跳方向在空中保持，松键不改变轨迹。出招与跳跃清除旧长按，落地后移动需重新按下。所有招式需再次按下，不自动连发。

跳跃、对空与投技

W/↑跳跃持续0.72秒，消耗12耐力；起跳前按住左右可定向跃起，空中轨迹保持。稍离地后按J踢击。I在地面使出升龙，对付跃起的对手。O是近身投技，无法用格挡防住。

跳跃不是全程无敌。空中踢、升龙和投技都有各自范围、前摇与收招；投技必须贴近，空挥同样会留下空档。没有搓招输入、连段取消或联网对战。

守住，也要松开

格挡须面向来招，且不在攻击或受击中。每秒耗6耐力；挡短拍再耗6、长挑12，分别受1点、2点擦伤；投技不能格挡。耐力不够会破防，承受全额并硬直0.65秒。

非格挡且非受击时，空闲每秒恢复24耐力，动作中14；最大100。不能靠一直举盾撑完整场。

退步不是消失

闪避耗20耐力，向面向的反方向退步；总长0.32秒，其中0.04–0.20秒无敌。蓝色轮廓是当前无敌窗口；起手和末段仍会被命中。

双方受场地边界与碰撞约束。每次来招仅结算一次，被闪避的同次攻击不会在窗口结束后再次扣血。

八种节奏

对手按公开的动作节奏与思考间隔决策；根据当前距离与场上状态，按自己的冷却和耐力出手，不读取你的未来按键。越往后移动与起手更快，预警仍遵守同一碰撞规则。

THE COURTYARD HANDBOOK

先读风，再出手。

  1. 保持距离。左右/AD移动，面对最后移动方向。J短拍近而快，U长挑远而慢；走进范围再攻，空挥会留下收招空档。
  2. 看预警。橙色扇线与“前摇”显示对手即将攻击，亮色实线是出招，灰线是收招。对手也遵守耐力、范围和冷却，不会瞬间连扣。
  3. 面向来招。按住K或格挡按钮，松开恢复耐力。背向、正在攻击/受击、耐力不足都不能完整防住。格挡仍受少量擦伤。
  4. 退步再反击。L耗20耐力退步，蓝色轮廓期间无敌；起手与末段不无敌。挡完或避开后，在收招空档选择短拍/长挑。
  5. 跃起与对空。按住左右再按W/↑可定向跳跃，起跳后轨迹保持；稍离地后按J踢击。I在地面使出升龙。跳跃不是无敌，留意对手的对空招式。
  6. 贴近后投技。O使出不能格挡的近身投技。距离不够就会空挥，需承担收招风险。

60秒内赢下8场递进挑战，逐场解锁。P/Esc暂停、R重赛；触屏共用大按钮，移动/格挡可按住，攻击、跳跃和闪避每次按下一次。起跳保留当时的移动方向；出招与跳跃清除旧长按，落地后移动需重新按下。暂停、失焦和刷新清旧按键，活动招式按原样恢复并先暂停。
