剪绳，也戳泡泡。

点绳或数字剪开；碰到泡泡会被包住并上浮。点包住铃的泡泡、下方戳泡按钮或按 B 可戳破。浮力消失，横向速度仍保留。数字键 1–2 剪绳，P 暂停。

CHIME TRAIL / 玩法手册

看清这一摆，再松手。

  1. 先看，再开始。

    准备时物理静止，可慢慢规划。开始后重力使铃摆动。剪绳与戳泡是仅有的两种操作；不可拖铃。

  2. 一根根剪，也可以一划剪多根。

    绳端不可剪，亮色中段与编号是剪区。轻点剪最近的一根；拖划按划过顺序剪开绳，单段划过多根时一起生效。下方编号按钮和数字键同样有效。

  3. 留意风，也留意梁。

    泡泡只捕获一次，包住铃后提供浮力；戳破保留动量并恢复下落。灰色梁阻挡铃但不致命，红尖纹一碰即失败。同一步碰到危险和收集台时，危险优先。

  4. 过关与满星，是两种目标。

    落进浅色收集台即过关。三题从一开始均可直选。每关三颗可选星点，最好纪录先比星数，再比用时。星点不影响解锁。45 秒观察期结束可重来；绳全剪后静止在台外三秒也会结束。

P / Esc 暂停，R 重来。失焦、切换页面及打开菜单自动暂停；暂停不计时也不可剪。刷新重放已发生的剪绳和戳泡记录并暂停恢复；重来会清除本次进度，保留解锁、星数与纪录。存档只在当前浏览器，未上传账户。
