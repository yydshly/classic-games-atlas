# 风铃绳旅 v2：三口轻风

三道独立、可直接选择的原创物理解谜。只增加一种机关：一次性泡泡。保留原版十六庭院与原版存档，本版使用独立存档。

## 玩什么

- 一 · 借一口轻风：剪绳落入泡泡，等浮力托住铃。上升取星后戳破，回落到台。
- 二 · 过梁的弧线：先借摆动获得横速，让泡泡包住铃，再剪绳。越过石梁右缘时戳破，继续带着横速落台。
- 三 · 留住一个支点：先剪左绳，保留右支点，向右绕开危险台。泡泡包住后剪最后一绳，离开危险上方再戳破。

泡泡与绳索可以同时作用；浮力不会解除绳约束。捕获与戳破都不改变位置或瞬间设定速度。戳破仅移除向上力，横向动量与上升惯性仍存在。泡泡只捕获一次，破裂后不会再生。灰梁是真实碰撞，红台是危险。落台必须向下且已经离开泡泡；危险先于收台，安全收台先于同一步超时。未完成时有 45 秒明确观察上限，允许重试。

## 操作与恢复

点绳的编号或亮色中段，或数字键 1 / 2 剪绳；划过绳也可剪。点包住铃的泡泡、戳泡按钮或 B 戳破。P / Esc 暂停，R 重来。三题可直接选，星不锁关。每题通常 2–3 次主要输入。

失焦、后台、菜单与离开页面暂停。刷新后按剪绳、戳泡事件重建物理状态，并保持暂停；泡泡包住和已经破裂的状态均恢复。重来重新提供泡泡。坏存档安全忽略，浏览器拒绝存储时仍可游玩并明确提示。存档仅在当前浏览器，键为 `classic-atlas.chime.bubbles.v2`，不读取或写入原版键。

## 可复核解法与宽容度

计时以按“出发”开始为准，时间只是便于复核；实际可直接看铃与台的位置判断。

| 谜题 | 一组合法操作 | 模型结束 | 宽容窗口 |
| --- | --- | --- | --- |
| 1 | 0 秒剪 1，12 秒戳泡 | 约 16.93 秒，2 星 | 同样剪绳后，9–15 秒间每隔 0.25 秒测试戳泡均通过；上升更高可取第三星 |
| 2 | 3 秒剪 1，6 秒戳泡 | 约 10.13 秒，3 星 | 固定 3 秒剪绳，4.5–7 秒间每隔 0.25 秒戳泡均通过 |
| 3 | 0 秒剪 1，3 秒剪 2，4.5 秒戳泡 | 约 8.07 秒，3 星 | 固定两剪，3.5–5.5 秒间每隔 0.25 秒戳泡均通过 |

这些解法使用正常开始、剪绳、戳泡和时间推进，不修改位置、速度或胜负。第二题立即剪绳且不戳泡、第三题先剪右绳或同时剪双绳、第一题始终不戳泡均会失败。未在泡泡里按 B 不消耗任何操作，也不会错误获胜。
