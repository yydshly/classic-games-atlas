BROOKWARD / 守护手册

把每滴露，用在缺口。

  1. 先看预告，再决定花在哪一行。

    来敌从右侧进入，越过左侧红线即失败。晶枝弩与雾环灯只攻击本行，不能替隔壁补射。同帧先结清伤害并移除死敌，再判活敌突破；全部预告出完、来敌清空才过关，波间空场不会提前结算。

  2. 生产先行，也要留出第一笔防守钱。

    凝露台花40露，每8秒结25露。天露首次第4秒出现，之后每6秒25露。露珠14秒过期，点单颗或 C / 收露按钮收齐。装置卡显示预算、费用与独立全局冷却。

  3. 五种搭档，各有位置。

    晶枝弩60露，持续远攻；苔垒35露，用生命拖住接触来敌；雾环灯95露，伤害并减速2.5秒。砾壳每击减伤8，掠叶移动快，组合使用比只堆一种更灵活。跃行者首次碰到阻挡会跃过一格，随后正常被挡。蓄根伏石45露，成熟8秒后对地面敌造成260伤害并消耗，不阻挡、不抓空中。

  4. 选格是预览，部署才扣费。

    鼠标/触屏点格，或行列框选好，再按部署；键盘方向键与 Enter 同样有效。浅石滩仅限制建造，不阻挡来敌；已有装置和来敌占据的位置也不可建造。X 撤收不退款，也不重置冷却；重复点击不能重复花费或占格。

P / Esc 暂停，R 重来；失焦、切页和菜单暂停并清输入。可选1×/2×，只改变推进速度，不改规则。刷新按普通操作记录重放后暂停恢复，预算、冷却、敌人血量、弹体、资源过期与波次都延续。存档只在本浏览器，损坏当前局拒绝。150 秒观察上限，到时仍未清场记为未完成；失败可重来，最佳成绩保留。成绩基础1000，清除每个来敌+30，装置损失−45、撤收−10、每秒−3。
