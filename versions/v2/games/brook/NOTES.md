# 溪谷守芽 v2：两岸互克

## 范围与来源

独立新增的两场分路布防练习，入口 `versions/v2/games/brook/`。原 `games/brook/` 的四装置、十关入口、资源及旧存档不修改。v2 保留凝露台、晶枝弩、苔垒、雾环灯，限于新增一类跃行者和一种蓄根伏石，没有扩张植物图鉴、英雄或地图系统。

参考：[EA 官方 Plants vs. Zombies 介绍](https://www.ea.com/games/plants-vs-zombies/plants-vs-zombies)，2026-10-19 阅读。官方页面介绍植物对抗不同来敌及环境变化；本实现借鉴分路防守中装置组合与敌人规则的配合。角色、数值、场景、波次、植物石质精灵和声音为原创，不是初代完整复刻，不使用原作角色、素材、音频或关卡。

## 可见机制

- 跃行者：360 生命、35 像素/秒、每 0.8 秒近战 20。首次遇到阻挡才跳跃，1.1 秒连续位移 80 像素，画面以弧线高度、地面影子和连线显示起落；跳过后永久显示“已用跃”。落地后正常被下一座装置挡住。空中仍受普通弹体伤害，不隐身、不无敌，也不会再跳。
- 蓄根伏石：45 露、7 秒全局冷却、8 秒成熟。未成熟淡色并显示倒计时；成熟实体与状态牌；触发后消耗、短暂根刺特效。它不阻挡敌人，只对穿过触发范围或落到范围内的地面敌造成一次 260 伤害，忽略护甲。不会扫过空中路径误触发。跃行者满血不会被一座根直接消灭。
- 原有四装置保留产露、直射、承伤、减速作用。根与装置同格互斥；敌人占格也不能临时叠放。所有合法部署才扣预算并启动冷却。
- 先计算当帧地面触发和弹体伤害、移除死亡敌人并统一记击杀，再判断存活敌人是否突破。一个敌人不会重复奖励或死后突破。所有波次出现且敌人清空才胜；150 秒仍未清场为失败/未完成，绝不按超时给胜利。

## 两场节奏

1. 一跃之后：3 行，260 初始露，9 个来敌，末个预告第 63 秒。中路跃行者，右侧诱跳、左邻接住，让后排晶枝持续射击。第一只不能把唯一火力当诱饵；第二波前需补火力或换垒。
2. 两岸伏根：3 行，230 初始露，10 个来敌，末个预告第 62 秒。上路跃行、中路重甲、下路快敌；中路有不可建溪石。根提前成熟对重甲高效，临时补根会被穿过；起跳处的成熟根也抓不到空中敌。其余行仍需自己的火力和阻挡。

目标为正常速度约 1–2 分钟的短场，不承诺所有玩家耗时相同。正常预算指令模型实测 67.22 秒、70.98 秒，不是人工难度或真人体验结论。2× 仅加速时间，不改规则。

## 输入、恢复与布局

两场从“溪谷”菜单直选。1–4 保留原装置快捷键，5 选根；画布方向键选格，Enter / Space 部署，C 收露，X 撤收，P / Esc 暂停，R 重试。点选格子后需显式按部署。重复 Space、重复部署和占格都不会重复扣钱。

存档键为 `classic-atlas.brook.v2`，版本 2。保存确定性指令记录，恢复重放预算、冷却、根成熟、起跳/落地、敌人/弹体、资源过期与波次，然后先暂停。旧 v1 不读写。失焦、隐藏页面或打开菜单暂停；重试恢复该场初始预算、装置空场与第一个波次。存储被拒时提示不能保存，游戏仍可玩。

桌面棋盘按可用视高等比缩小，输入映射读取实际 canvas 边界；狭屏布局正常滚动。600px 以下准备/暂停/结果卡进入文档流，不用固定画布高裁掉按钮。1440×900、1366×768、1280×720 与 600/390/360px 等目标尺寸仍需浏览器视觉复核；没有把 CSS 设计或事件替身测试称为浏览器实测。

## 资产和性能

`guardians.png` 是通过 Canvas 路径与渐变离线绘制的原创 9 格透明位图图集（1152×128，约 53KB），统一植物石质装置与岩叶小怪；不是图像生成模型产物，也不代表美术品质已验收。未引入大图、外部运行库或在线素材请求。引擎固定 1/60 秒、积累器单次输入有限，重放上限 9000 tick / 2500 指令；暂停不推进。资源过期、死亡实体与特效及时移除。

## 已执行验证及限制

- 正常预算、正常部署/收露指令模型：第一场 67.22s 胜、3 次跳跃；第二场 70.98s 胜、3 次跳跃、3 次根触发。
- 同策略对照：第一场省去后方苔垒 31.75s 失败；第二场中路根延到敌人近身才补，69.28s 失败。两场完全不布防均 29.70s 失败。证明策略有不同后果，不声称列举全部可行解。
- 规则边界：只跳一次、跳中连续坐标、落地碰后垒、地面/空中根触发、成熟前后、弹体击中空中敌、同帧根/弹体不重复记击杀、同帧死亡与突破顺序、存活突破失败、150 秒未完成、原子占格/旧版本指令拒绝。
- 正常指令重放逐段对比，包括完整跃起期间、根成熟、暂停冻结和 v1/超界存档拒绝。
- DOM 事件替身调用生产 `game.mjs`：教学/开始、两场直选、5 选根、Space 重复拒绝、暂停/继续、失焦/隐藏、帮助返回、重试预算/波次、存储拒绝、仅访问 v2 键。不是浏览器和触屏验收。
- 生产 `renderer.mjs` 离屏渲染已检查：跃起/地面影子、根未熟、成熟、触发消耗四状态。产物明确标注 OFFSCREEN。此阶段未完成浏览器视觉验收。

最终部署和真人/原生触屏视觉验收应另行记录；本记录仅陈述上述本地证据。
