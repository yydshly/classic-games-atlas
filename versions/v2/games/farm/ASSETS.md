# 四季小田：三章成长 · 素材说明

本版本的背景、作物与两位邻居均为专门生成并整理的原创位图美术。通过AI辅助原创生成，经过透明边缘检查、图集裁切和 WebP 压缩后，直接用于游戏画布。没有使用《牧场物语》或其他既有游戏的人物、截图、音乐或素材包。这是制作来源说明，并非对独创性或权利状况的法律保证。

- 场景：斜俯视小屋、水井、石径和花木。田地保持固定位置，建设和作物绘制在同一张场景中。
- 作物：绯萝、青豆、金瓜、霜麦，各有嫩芽、叶丛、成熟三种独立位图。播种为嫩芽，第一次有效生长进入叶丛，达到作物周期进入成熟。
- 角色：林穗与陶禾，均为本项目原创邻居。人物对话随订单、章节和建设变化。
- 建设：围栏修复后实际增加两块田；长凳只改变场景和邻居回应，没有金币、行动、产量或生长加成。
- 反馈：浇水的水滴、湿土，收获的入篮，以及日结明暗和生长反馈。动画可跳过，跳过不会重复结算。系统偏好减少动态时直接显示最终状态。

本项目以经典农场经营游戏的通用种植、邻里关系与升级组合为参考。三章小游戏不包含完整畜牧、婚恋、城镇探索或多年模拟。

参考机制资料：[STORY OF SEASONS 农场生活](https://www.storyofseasons.com/fomt/lifeonthefarm/)、[居民与升级](https://www.storyofseasons.com/fomt/returntonature/)。
