# 归火石室 v2

这是原创有限动作冒险，三关共九房。参考小型俯视迷宫里“探索、取得能力、回访机关、首领战”的结构，不复刻现有作品的角色、地图、画面或音频。

参考介绍：[任天堂《织梦岛 DX》官方页面](https://www.nintendo.com/en-gb/Games/Game-Boy-Color/The-Legend-of-Zelda-Link-s-Awakening-DX--275946.html)。

v1 已经包含横扫、闪步、敌人预警、钥匙与灯座。v2 的主要变化是固定时间步实时战斗、连续移动、回声灯定向发射及能力回访，而非把已有机制称作首次新增。v1 入口、源码和存档保留。

所有环境、角色和物件均为本项目原创程序化 SVG 插画。角色采用四向有限关键姿态切换与小幅步行位移，不是完整逐帧手绘动画。无外部音画素材，无外部付费接口。美术可在 assets/manifest.json 核对。

进度：v2 独立完整快照，刷新先暂停；重试恢复本房入口检查点及生命。每关可以单独开始。回声灯不消耗弹药，不存在关键道具误耗。

验证边界：固定步长模型路径、碰撞与离屏画面检查不能替代普通浏览器手感和手机触屏实测；发布时以随附验收记录为准。
