# 晶簇花园 v2 · 棱光小谜题

两张公开固定 8×8 棋盘，6 / 8 步预算；两题均可两步完成。两题可直接选择，不要求解锁。原版二十关位于 `../../../../games/garden/`，其代码及存档保持独立。

## 这次改变

原版已包含三消、掉落连锁、四连行/列晶、T/L 及五连的 3×3 花蕊。v2 仅把直线五连改为无色棱晶：先制造，再与邻色交换，清除全盘该颜色。四连仍是行/列晶；T/L 仍是花蕊。没有扩展完整特殊组合表。

棱晶不属于六色，不参与普通匹配，不计入颜色收集。被旧特效命中时，清除当前棋盘数量最多的有色晶簇，含有色特殊；平局按日珀、叶翡、雨蓝、暮紫、莓红、月白顺序。两枚棱晶直接交换清全盘。命中其他特殊会继续触发；同一波每格只计一次清除、分数和松土。被效果命中的预留生成位不会再生成特殊。全部连锁落稳后才判胜负，最后一步先判达标。

动画顺序为交换、匹配/射线清除、形成保留、掉落、下一轮连锁。操作期间锁定棋盘；暂停冻结阶段。稳态保存，动画期间刷新回到该次交换前的存档，恢复后暂停。

## 公开棋盘与合法解

`levels.mjs` 完整公开初盘、特殊位置、土层、种子、预算与解。补落只使用公开种子的 xorshift32；没有按玩家操作修改棋盘或补给答案的逻辑。行列从1开始。

1. 把雨蓝留给棱光：种子109，6步。第3行第3列向下交换到第4行第3列，完成横五连。等所有掉落结束，再将第4行第3列棱晶向右交换雨蓝。正常结果：2步、460分、雨蓝20枚，目标14枚。
2. 远处的一束长光：种子580，8步。第3行第3列向右交换到第3行第4列，完成纵五连。棱晶会随空位自然落到第5行第4列；等待落稳后向上交换第4行第4列叶翡。叶翡清除触发第8列的旧清列晶，松开四处远土。正常结果：2步、叶翡12枚、松土4层。

第二题的基础布局采用转置和色号交换，重选补落种子，展示同一规则下的纵向掉落、选色与远端清土目标；不是另一个全新机制。两题附近均有其他颜色可选；测试中选错邻色未达成目标。解也在页面中公开，可只用普通点击、拖动或键盘复现。
