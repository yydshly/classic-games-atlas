# 弯道邮差 v2

单赛道三车实体竞速实验。晨光街区、两圈、三场固定能力对手组合；不是三张新地图。独立入口和存档，原版八条计时赛道不变。

方向键 / WASD：油门、刹车、相对车头转向。B 复位停驶三秒（对手继续），P 暂停三辆车，R 重开。
