CLUSTER GARDEN / 栽培手册

让相邻的光，开成花。

  1. 先交换，再等待。

    点击相邻两格，或向邻格拖动 / 滑动。横纵同色三连消除，下落补充会继续连锁。无效交换回弹，不扣步；动画中等待，重开可立即取消。方向键选格，Enter / 空格选中，Shift + 方向键直接交换。

  2. 四连成长光，五连开花蕊。

    横四连留下 ↔ 清行晶簇，竖四连留下 ↕ 清列晶簇；五连或同色 T/L 留下 ✺ 花蕊，清除周围 3×3。生成位置优先交换的目标格、再源格；级联选左上普通晶簇。生成格本轮保留，不计收集或松土；若被旧特殊效果命中则仍会消除。

  3. 读懂目标，把一步留给连锁。

    特殊晶簇同色匹配或与任意邻格直接交换都会触发。两枚特殊交换各自生效，效果可以继续引爆其他特殊；每格每轮只计一次。土层固定在格位，每次消除去一层。全部级联后先判断达标，再判步数耗尽；最后一步达标也获胜。

寻找一步不耗步。无有效交换时自动洗牌，保留晶簇种类、土层、目标计数和步数。每关使用可复验的固定种子。完整交换结束后自动保存稳态；动画中刷新回到该次交换前，恢复时暂停等待你继续。P / Esc 暂停，R 重开，H 提示。
