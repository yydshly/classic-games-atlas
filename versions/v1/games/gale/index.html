STEEL GALE / 作战手册

先读预警，再向前。

  1. 一边移动，一边还击。

    A D / 左右移动，空格跳；长按高跳、早松短跳，落脚后再跳，不会按住自动连跳。J 持续射击；W / 上键上斜射，方向随最后移动朝向。实心地形挡弹，单向高台可从下方穿过且不挡弹。本轮没有移动平台。

  2. 每种敌人，都有节奏。

    步兵巡逻后瞄准射击，炮台预告扇射，飞行机预告下投。跳跃不会踩死敌人；利用掩体、跳跃和上斜射。全部敌方单位清除后，出口信标才会开启。

  3. 补给和脉冲，各有分寸。

    S 是 24 发散射器，R 是 60 发速射器，耗尽后回到无限弹药的基础枪。维修箱恢复两格护甲，首次检查点激活修满。K / 脉冲每关两次：近距伤害、清弹和短暂保护，不恢复护甲，也不会随复归补充。

  4. 失误之后，仍有归路。

    五格护甲、三次出击，受击后无敌 1.2 秒。护甲耗尽或跌落消耗一次出击；剩余出击会在最近检查点满护甲复归，清空弹体并暂时保护，已清除目标、拾取和技能消耗保留。最后一次出击耗尽失败，重试重新开始本图。

  5. 最后的穹炉，有三段回声。

    进入末段检查点且其他单位清除后，首领屏障解除。三阶段依次出现扇屏、地面波、落星/扇屏交替，均先预警。转换阶段清除自身旧弹、重新预警；击败后走入出口才归航。同一帧致命失败优先，不会靠最后一击复活。

触屏可同时按住方向、跳跃、射击，上斜射按钮切换；松手、取消和失焦都会清除旧输入。P / Esc 暂停，R 重开。刷新从最近检查点重新整备，保留当前护甲、出击、武器/弹药、脉冲、敌人护甲和拾取结果；不保留当前坐标或飞行弹，恢复先暂停。个人最佳与解锁仅保存在本机。
