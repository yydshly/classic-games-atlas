    THE FIELD HANDBOOK / 先读半分钟

    把一天，过得刚好。

    1. 先播种。开始后选一格空田和作物，预览种子费与收益份数，确认用1行动。种下时有1格水。
    2. 照料，再结束本日。浇水用1行动补至2格。每次生长消耗1格；雨天自动补满。结束当天才生长，没有时间倒计时。
    3. 成熟后收获。绯萝2次、青豆3次、金瓜4次、霜麦3次有效生长。寒潮只有霜麦长，其他作物保水停长。缺水只停长，不会消失。
    4. 先入仓，再交单。收获与整单交付各用1行动；预留种子费与交单行动。最后期限当天可交，结束当天仍未交才失败。
