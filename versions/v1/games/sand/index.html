STARDUST SURVEY / 勘探手册

让线索，照亮下一格。

  1. 从安全观测点开始。

    每张固定星图都标有发光起点。首次只允许从这里揭开，该点及相邻八格保证无雷。之后数字表示周围八格中的雷数，缺口不计格。空白零区自动展开到数字边界，已插旗的格不会被自动揭开。

  2. 旗标是一条假设。

    右键、F、触屏长按约半秒，或切换到“标旗”模式来标记/撤回。旗数最多为公开雷数；计数归零不代表旗的位置正确。揭开全部安全格即胜利，不要求每枚雷都标旗。

  3. 快捷展开，要先核对。

    在揭开模式点已揭示数字，或按 C：只有相邻旗数恰好等于该数字时，才展开其余邻格。它不会检查旗的位置，错旗可直接触雷。触雷时优先失败并展示所有雷点与错旗；可以重试同一固定星图。

  4. 推理有依据，不必猜。

    提示解释可见数字减去邻旗、未知集合差或公开总量关系，只高亮依据和结论，不自动行动。结论以当前旗标正确为前提；出现矛盾先检查旗标。默认战役有完整可见线索解法，没有随机模式。

短点按当前模式；触屏长按只标记，释放不会再揭开，拖动滚动会取消按压。方向键选格，Enter/空格执行，F 标旗，C 快捷展开，M 切模式，H 提示，P/Esc 暂停，R 重开。无倒计时；保存合法操作日志与用时，刷新重放恢复后先暂停。损坏或旧版本当前局会被放弃，个人纪录独立保留。
