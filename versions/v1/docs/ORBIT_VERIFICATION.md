[31组规则检查](orbit-qa/logic.json)、[12关正常物理策略](orbit-qa/strategy.json)通过。四旋转与声明的六个偏移严格顺序尝试，边墙不足位移拒转，不能越界/重叠；影子为逐行合法碰撞求出的确切落点。硬降立即落到影子，四格唯一入板；满行同步移除、上部行顺序压下；顶出、额度与最后一枚成功优先级均有测试。
