## 核心攻防与守恒

[32组核心检查](duel-qa/logic.json)、[8场正常规则策略](duel-qa/strategy.json)通过。96/148中心范围含边界，背向攻击和范围外攻击落空，前摇不伤人，收招与额外0.1秒冷却不能再攻。每个唯一攻击ID首次接触后即消费，持续出招不会重复扣血；受击打断未完成招式。双方同一步先收集碰撞再结算，先执行的一击不抹掉另一击；同帧双KO明确单次失败。对应范围/同击/双KO等使用隔离碰撞夹具，不能冒充正常战役。

正面格挡扣每秒6与单次6/12，受1/2擦伤；背面全伤、耐力不足破防全伤并硬直0.65秒。非格挡非受击时，空闲每秒回24、动作中14，按实际上限记账，不足不施放。退步0.32秒、0.04–0.20秒无敌，启动/末段可受击；无敌接触消费同一次来招，窗口过后不追扣。身体和墙阻挡仍有效，不穿身。长帧舍弃0.1秒以上时间，30/60/144Hz分区重放同样的攻击、AI、耐力与结果。

模型结果与真实输入采样点核对12项不变量：位置边界、身体分离、体力初值减真实伤害、伤害事件账、耐力上下界、原始耐力加实际恢复减实际消耗、攻击ID唯一、每次攻击最多一个接触/空挥结果、真实范围、出招窗口、格挡朝向、单次终态结算。伤害不倒扣或重复，耐力不会负值。超时边界以明确冻结AI单元夹具检查；正常无输入失败另有真实浏览器证据。
