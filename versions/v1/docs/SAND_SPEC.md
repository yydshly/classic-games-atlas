# 星砂勘探 · 第十三款固定范围

20 关固定逻辑排雷战役，无随机模式。每关只允许从标明的安全观测点首次揭开，该点及其八邻域无雷，之后按可见数字推理。地图离线生成并经只读可见线索的推理器认证，不用固定坐标答案或读取隐藏雷位来宣称可解。

- 数字统计八邻域中有效格的雷数；缺口不计格，不会跨缺口扩散。零区自动展开至相邻数字边界；旗标阻止揭开。
- 旗标是玩家假设，不自动验证。点击已揭示数字、按 C 或数字上的正常揭开，在相邻旗数恰好等于该数字时展开其余邻格。错旗可导致触雷；同次快捷展开含雷时失败优先。揭开所有安全格即胜利，无需给所有雷插旗。
- 明确的一击失败展示、重试、教学、暂停、关卡解锁、存档恢复、最佳提示数/用时和可关闭原创合成音效。没有倒计时。重试沿用固定地图。
- 提示只用当前可见数字、旗标假设与公开总雷数，解释基础计数或集合差关系；可显示矛盾，不核验隐藏雷位。提示不自动行动，使用次数记录在个人成绩中。
- 鼠标点击揭开、右键标记；触屏短点按当前模式，长按标记，拖动滚动会取消操作，长按释放不得再揭开。提供显式揭开/旗标模式。方向键选格，Enter/空格执行，F 标旗，C 快捷展开，H 提示，M 切模式，P/Esc 暂停，R 重开。
- 同格短时连按、按键 repeat、合成 click 与长按释放保护。暂停/失焦取消未完成按压，冻结时钟并阻止操作。
- 以带版本的合法操作日志保存当前局；恢复时从固定地图重放验证，不信任存档中的雷位或数字。损坏/过期日志拒绝，保留可校验的解锁与个人纪录；恢复先暂停。

保留 72 条图鉴及前十二款运行目录。原创地图、SVG、名称、界面和声音，只参考扫雷机制。无新服务、依赖安装、凭据或付费。20 关生产规则正常推理模拟和线上真实输入通关，清楚标记选关/隔离夹具，验证最终 main 的 Pages 与运行文件一致后交回主对话。
