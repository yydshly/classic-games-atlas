# 风铃绳旅 · 第十八款固定范围

十六关原创剪绳物理解谜，青叶庭院、山谷风廊、暮色归途三个主题。每关三颗可选星点，共 48 颗。只剪绳，无拖动铃、额外冲量、移动支点或风力开关。灰梁是可碰撞实物，红尖台是危险；浅色收集台是终点。第 1–6 关学习重力、摆动和双绳顺序，7–12 关引入不同方向的风与梁，13–16 关合并多绳、危险和气流。关卡不是同一模板平移。

- 世界 720×560，固定步长 1/240 秒；重力 360，线性阻尼 .055，铃半径 13，速度上限 680。绳长从声明的可行起点计算，初速度严格为零。绳仅限制最大距离，允许松弛，不把铃向外推；16 次约束/障碍交替投影，去除拉伸方向速度。实际绘制和逻辑分离，帧耗时最多累计 .08 秒。
- 灰梁采用扩张矩形与扫掠段连续碰撞，再做约束分离；切向保留动量，小幅法向反弹。圆铃使用保守的矩形包络，不模拟柔性绳和绳间碰撞。风区按铃心位置持续施加标明方向的加速度，可叠加重力。不会随机改风。
- 危险扫掠先于星点和终点；同一子步触危与到台时失败优先。约束误差持续大于 1 达 120 步判夹住；出界失败。未剪完的静止绳可继续规划，不因静止失败；全部剪完且速度小于 2 连续三秒停台外失败。45 秒观察期用完可重来。所有终态只结算一次。
- 绳中间 12%–88% 是切区，端点不可点剪；点选最近亮绳（距离 16 世界单位），拖划切到的多绳按划过顺序排序，同一移动段整批剪断，编号相同不重复。触摸/鼠标指针释放才执行轻点，拖动阈值 10 CSS 像素。暂停、重来、菜单、失焦、取消指针都清除未完成手势。剪绳命令带当前版本，旧版本拒绝。
- 鼠标、触屏点剪/划剪；下方至少 44px 的编号按钮。键盘 1–4，聚焦画布后左右选绳、Enter/空格剪；P/Esc 暂停，R 重来，Tab 使用原生控件。重复按住数字不重复剪。准备时看得见完整场景且时间静止；初次教学、16 关选关/锁定、失败重试、声音偏好、最好星数与计时。
- 收集台即过关，星点不是门槛。最好纪录按星数优先，再比用时，最后比剪绳数。每关通关解锁下一关。刷新只用 tick 与剪绳日志在同一个正式引擎中确定性重放，再暂停恢复；不接受外来坐标、速度或星数。检查关号、时间、顺序、唯一绳号和已结束重放，损坏当前局拒绝。存档只在本机，不是针对恶意编辑本机成绩的防作弊系统。
- 原创 Canvas 几何景观、铃与 Web Audio 合成音。无外部素材、字体、ROM、账户、后端、模型调用、付费服务或新增依赖。只参考《割绳子》所代表的重力剪绳解谜通用机制，角色、地图、美术、声音全部独立。
