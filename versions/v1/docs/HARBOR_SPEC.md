# 云港调度 · 第二十二款固定范围

十二关、雾岸/云阶/星港三种原创地图主题，各四关。小型关卡运输经营解谜，按离散回合推进；不是持续挂机或完整运输模拟器。玩家建设候选航道、配置不重复站点的往返线、购置1格轻舟或2格驳艇，把所有委托送达指定地点。路线、成本、容量与等待共同构成玩法，不是只点数值升级。

货物为雾棉◇、灯芯✚和晶锚▣，图形与名称配合颜色。全12关共59箱，其中晶锚每箱占两格；其余每箱一格。每箱初始即有唯一ID、起点、目的地、出库回合、可选期限与回款，不会在经营中凭空新增。状态只有待出库、仓内、舱内、已交付之一，船舱仅引用同一份货物ID。

出航前可规划，预览不收费、确认才扣款。轻舟购置5币、1格；驳艇9币、2格。航道建设费、航时与每次出发的航费独立标注。所有币为本关虚拟经费，不跨关继承。拆售在出航前全额退款，只能退一次；在用航道先改线或售船。免费改线与撤销均可逆。出航后方案冻结，不能用拆售退款消除在途货物或创造现金。

账本恒等式：余币＝初始预算－净建设费－净购船费－累计航费＋交付回款。雾棉/灯芯每箱回款3币，晶锚5币；只在到达真正目的地并卸货时入账，一箱一次。每段出发扣一次航费，在途、候货与排队均不重复扣费。购买力不足时拒绝操作，余币永不为负。所有船停港且余币为0、仍有委托时自然失败，周转金也是规划的一部分。

路线包含2–9个已命名站点，不能重复站点，邻站之间必须有已建候选航道。允许双向往返和中途装卸；不做船间换乘。开始前检查每箱货至少有一条覆盖起终点且容量足够的船线，断路和舱位不足均给出解释。

每回合：先释放到期出库货；在途航程减一，到站后卸下目标匹配货并回款；先判断全部交付、再判断超期或总回合用尽；然后按轮转船序装货、申请出港并扣费。一段航道任一方向合计仅容一船，◇交汇站每回合放行一船，普通站最多两船，停车不阻塞卸货。航时1意味着第N回合出发、第N+1回合到站；可当回合接下一段。截止回合到站卸货算准时，最后交付优先于同回合失败检查。

已载货船沿路线朝最近的载货目的地行驶，只加装同方向且舱位足够的本地货；空船优先最近的已出库待运起点，再看未来出库点，在起点候货时不花运费。同站同方向按较早期限、再按ID装货。无相关剩余委托的船停港，不空跑刷费用。

第三关起引入单船交汇，慢航段在第七关清楚展示占用与等待；第八关起期限，第九关起两格重箱，后期含多目的地、返程货、未来出库与可选绕行。十二张图的节点、边、委托与预算组合独立设计，不复制Transport Tycoon地图、美术、声音或角色。

开始后手动推进回合，亦可每0.7秒自动推进。P/Esc暂停，R重来；打开手册/地图、失焦或离开页面会暂停。暂停时不能推进回合，恢复不补跑；重复键事件不连跳。鼠标可点地图两站预览，所有规划也可用选择器、文本、路线站点按钮与确认按钮完成，支持键盘和触屏。

教程、预览与确认、完整委托计数、船舱/在途/等候、账本、胜负重试、十二关解锁、本地最好与原创合成音齐备。成绩：通关1000＋余币×10＋剩余回合×15－船数×10；只保存获胜最好，失败/重来不擦除。每关独立预算，不承诺全面复刻运输模拟。

存档仅保存版本、关卡、阶段与已确认的普通操作序列。恢复由同一正式引擎重放建设、买卖、改线、撤销、开始与逐回合操作，不信任外来现金、库存、交付旗标、船舱或成绩。规划恢复原样；出航局恢复后先暂停且不自动推进。未确认的输入和预览不保存。坏当前局拒绝而保留合法解锁和最好；不是防本机恶意编辑的安全系统。
