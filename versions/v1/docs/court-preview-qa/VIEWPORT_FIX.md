# 晴湾篮场预览：完整比赛区可见性修复

日期：2026-10-18。基线提交：`99814b283c6bf03094499f176308cfa66121f8b8`。

## 真实浏览器复现

- 1180×757 CSS视口，开始后画布高720px、底部约777.8px，比分栏顶部约−24.2px；蓄力条还在画布下方，不能同时看球场、比分和金色释放区。
- 宽屏整块arena高918px，超过757px视口；单独修滚动无法让关键区域全部可见。
- 400×606 CSS视口，暂停面板在球场下方第二行。继续时该面板消失，但旧scrollY约348.8保留，比分栏约−158.4px，画布顶部约−93.4px，比分和部分场地被滚出视口。

## 最小修复

1. `preview/court/court.css`：桌面按视口高度限制arena最大宽度，保持画布原3:2比例和完整构图。先为比分、蓄力、工具栏及8px上下留白保留空间，剩余区域使用尽可能大的完整球场。高屏仍可使用原1080×720显示尺寸。
2. 桌面高度不超过800px时，只略收紧比分栏和工具栏的垂直留白，不改字号、颜色或球场绘制；coarse pointer预算额外包含方向/动作按钮行。
3. 宽度不超过560px时保留原全宽画布，并显示已有方向/动作按钮，即使窄窗口来自fine pointer设备。
4. `preview/court/index.html` 给现有arena加稳定ID。`preview/court/game.mjs` 在开始、暂停/继续、帮助自动恢复时，先更新面板再将整个arena顶端定位到视口，避免隐藏面板后保留旧滚动位置。

引擎、八场关卡、renderer、存档代码与独立存档键均保持基线字节不变；没有改玩法、难度或美术，也没有裁掉画面。
