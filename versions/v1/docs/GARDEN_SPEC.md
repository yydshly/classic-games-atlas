# 晶簇花园 · 第十款固定范围与验收

20 关原创 8×8 三消解谜。交换相邻晶簇，横纵三连或以上消除，下落补充并继续级联。五种至六种颜色各有独立形状和符号。原创花园画面、晶簇、布局和合成音效，不使用 Bejeweled 品牌素材。保留图鉴 72 条及前九款；无需服务、每日任务或付费道具。

- 无效交换回弹，不扣步。有效交换只扣一步，整段动画及级联期间锁定棋盘输入；重开立即取消旧流程。暂停冻结全部阶段计时。
- 横四连生成清行晶簇，竖四连生成清列晶簇。五连或同色 T/L 交叉生成“花蕊”，清除中心 3×3。每个相交匹配连通块最多生成一枚，优先落在玩家交换的目标格、再源格；级联优先左上普通晶簇。生成格本轮保留，不计收集或松土；若被旧特殊效果击中则仍被清除，不生成新特殊。
- 特殊晶簇参与同色匹配，或直接与相邻图块交换时触发；两枚特殊直接交换分别触发，无额外组合规则。效果命中其他特殊继续触发。匹配、爆破和横纵交叉对同一格每轮只计一次；覆盖土层每轮去一层。
- 有限步数完成分数、指定颜色收集、土层清除等渐进组合目标。级联全部结束后先检查达标，再检查零步失败，因此最后一步完成目标算胜利。土层固定在格位，不随晶簇下落。
- 初盘无现成匹配且至少一组有效交换；提示给出一组合法交换且不耗步。无合法交换时自动洗牌，不扣步、不增加分数或目标计数，不移动土层，保留特殊晶簇。每关显示固定种子，重试可复验；验证特定种子，不承诺所有任意随机局必胜。
- 鼠标点击/拖动、触屏点击/滑动，另有键盘选格与交换。教学、胜败重试、暂停、20 关解锁、声音、本地最佳分及进度。稳态保存棋盘、随机数状态、步数和目标；动画中刷新回到该次交换前的完整稳态，完成或失败后刷新重新整备。

验收覆盖横纵匹配去重、特殊生成位置/触发/连锁、级联稳定、动画锁与重开、最后一步胜负、目标计数、无效交换、洗牌与存档。20 关以生产规则正常交换策略验证；首/中/末真实浏览器交换通关，争取全部 20 关。回归旧入口和窄屏，独立代码提交、Pages 成功、公开地址操作与文件哈希核验后回到主对话安排下一款。
