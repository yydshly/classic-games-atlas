## 实际限制

Windows Chromium/Playwright原生触屏事件验证；Safari、Firefox、实体设备、屏幕阅读器与人工难度尚未全面验证。采用固定地块、公开循环天气和离散回合订单，不模拟完整牧场、社交畜牧或真实农业。存档供本地恢复，不是防用户手动篡改系统；拒绝存储时可玩完整局，刷新记录无法保留。
