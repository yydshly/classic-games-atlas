# 四季小田 · 第23款固定范围

12关、春圃/夏畦/秋庭三主题。4–6块固定土地，每日3–4行动、有限种子费、公开循环天气。小型回合农场经营解谜，不模拟完整牧场、社交、畜牧或真实农业。

播种、浇水、收获、整单交付各用1行动；开始、选田、预览和暂停不耗行动。种子费用为绯萝2币/青豆3币/金瓜4币/霜麦3币，收获分别2/3/2/2份，所需有效生长2/3/4/3次。种植有1格水，浇水补到2格，每次生长用1格。缺水停长不死亡；成熟后停止生长并占地，直到玩家收获腾空。细雨在日结先补至2格再生长；寒潮仅耐寒霜麦生长，其他作物保留水分。

每关天气序列完整写在数据里，界面显示当前与未来三日，没有随机天气。只有确认结束本日才推进，剩余行动作废，下一天补到本关每日额度。没有自动现金、作物、库存或离线收益，也没有真实时间倒计时。每个日结先进行天气/生长，再检查未交订单截止与本关最后一天；最后一天结束前仍可收获交单。最后一次交付立即成功，胜负只结算一次。

每株唯一ID、每次收获唯一批次、每份产物唯一ID。收获只入仓一次，仓库跨天保留；订单按组合数量整单交付，不接受部分扣货。回款只在实际扣除库存并完成该订单时发生，一单一次。账本：余币＝初始预算－全部种子费＋已完成订单奖励。没有自动售出或补贴；生长不产生现金，收获不立即产生回款。

所有有后果的田间操作先展示种子费/收益份数/回款/剩余币/行动；确认时检查版本，重复点击与旧确认不能重复扣除。开始与日结也不能偷跑。部分订单有开放日与截止日，逐步加入多种作物、资金周转、轮作和寒潮规划；12张地图的土地数、行动、资金、天气、周期与订单组合为原创。

教程、完整田间面板、订单/仓库/账本、失败重试、12关解锁、本地最好、原创SVG作物与合成音。支持原生鼠标/键盘/触屏按钮；方向键选田、1–4选作物、S/W/H播种/浇水/收获、D首个可交订单、N日结、P/Esc暂停、R重种。表单保留原生键盘行为；重复按键受抑制。手册/地图/失焦/离页暂停。

保存只包含版本、关卡、阶段与实际已确认的普通操作序列。恢复按同一正式规则重放，不读写外部现金、库存、生长或胜利快照；运行局先暂停，未确认预览丢弃。最好成绩按分数、同分更早完成比较；计分为1000＋余币×15＋剩余天数×40－总行动×3。各关资源独立，不跨关继承。存档是本地恢复工具，不是防手动篡改的安全系统。
