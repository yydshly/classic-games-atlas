# 汀光织界 v3 · 观潮择路

这是有真实敌位风险的原创三湾机制候选，未完成真人乐趣或成品品质验收。v1首版、v2分湾版及其存档完整保留，目录仍44项、原72图鉴与其他43项不变。

v2独立审查发现：默认固定坐标策略不读敌位；原初态2/3湾两套路线在50/100/200ms均无损，但自然移相会真实碰线。第二湾无暂停普通UI测得墙钟3.453秒、局内3.40秒，短不是模拟快跑。不能笼统声称敌人永远无威胁。

本轮只加一项机制：第二、三湾开放风险线出现后，同水域潮影会原地蓄势0.5秒，明确显示倒计时和锁定线点，再按原0.32秒/格步速追最近风险线。教学湾保持原巡游。没有加速、随机锁杀、强制等待或刀数门槛。主动撞进蓄势中的潮影仍伤灯。闭合或断线清掉追踪，已织区域与原分区目标规则保留。

出发前可点四向只读预览：按钮不移动织针；淡虚线与“估”标记是此刻状态下持续直行到下一汀地的推演，不是安全保证，转弯或拖延会改变结果。实线与追向箭显示真实锁定线点及行为，不把直线连线伪称导航轨迹。可以暂停观察。

两类思路：远岸长切，先看敌位再选能及时闭合的长线，收益高但暴露久；借岛/堤短闭合，用较短暴露创造新落脚，再分段展开，收益较小、换位更多。当前敌位不同可改变推荐出发点，具体因果与风险见验证页。不能仅靠各分区配额宣称深度，也不靠更长时间证明乐趣。

方向键/WASD或按住方向按钮移动，空格/X准备织线，P/Esc暂停或继续，R请求当前湾重试。Tab/Enter可选预览与按钮，画布获焦时使用游戏快捷键。风险线不能回踩或免费取消；潮影碰线/针、自交和岸巡伤灯，三灯用尽或超时失利。当前湾确认重试保留前湾，确认新旅程才清v3。

独立键 `classic-atlas.inlet.v3` 与版本3恢复，完全不读取、迁移或覆盖v1/v2。刷新活动局先暂停，开放线、预警/追线计时、目标和敌位保存，旧按键不复活。失利/关间/结局保持。写入失败提示并保留旧有效字节，恢复成功清除失败；坏档原字节保全并禁覆盖。
