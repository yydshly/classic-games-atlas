# 溪谷守芽 v3 · 三溪归途

独立可选的三场短战役。原v2两场自由选场、v1十关和全部旧档保留，目录仍为40项；新增的是溪谷内容升级。没有联网、账号、服务或新依赖。

1. 一跃之后：沿用原三行、260露、9敌与波次，理解首次诱跳、后排接住。
2. 两岸伏根：沿用原三行、230露、10敌与溪石，提前成熟的根应对重甲，其余行仍要自己的防线。
3. 三溪合流：新增原创三行、260露、12敌、四阵风。三行的跃行、重甲与快敌轮换，上路第6格及下路第5格的溪石限制布防位置。前两场固定分工不能原样照搬；所有来敌数值和装置作用不变。

第三场已有两种合法模型思路：伏根与后排火线（3次根触发、无减速），雾环与复合防线（无根、32次减速命中）。不是必须指定装置的钥匙，也未声称穷尽可行解或证明真人难度。空防、忽略收露会自然失败。第三场的差异是混合路序、时机和可建位置，不是增加旧敌血量。

三场依次推进，每场重新整备原预算/空场，不携带装置、露珠或冷却。胜利先看关间结果，再明确进入下一场；失败只重试当前场，前场真实结果保留。第三场后保留总结，没有第四场；重新开始战役需要确认。分数与活动时间只汇总本次成功场，不重复结算或发额外奖励。

新键classic-atlas.brook.campaign.v3、外层version3，隔离v1/v2。活动局仍使用相同的合法命令重放，刷新后先暂停，预算、冷却、弹体、敌人、露珠和波次延续；关间/失利/总结独立保留。坏记录保留原字节、只临时游玩；写失败保留旧有效数据并说明风险，后续写成功清除失败状态。原两场的规则、合法旧命令重放结果不变。

引擎正文复制自本次基线v2，未改数值或算法；只在新目录读取扩展的三场数据。前两场数据直接复用，行号提示也绑定三场数据；绘制仅调整图集相对地址与版本角标，图集仍为既有原创素材。沿用原键鼠、键盘与显式触控选格后部署，P/Esc暂停、C收露、R本场重试，1–5选装置；原生链接/表单的Enter不被游戏抢占。
