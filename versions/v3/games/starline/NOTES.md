# 星泡航线 v3 · 三锚归航

三张原创短谜题连续航行。参考 Puzzle Bobble 的瞄准、反弹、同色三连与断连掉落基础机制，沿用本项目 v2 的四发结算下压；不是官方复刻。原 v1 十二图与 v2 两图、旧记录均保留。

| 图 | 需要判断的内容 | 替代安排与错误余地 |
| --- | --- | --- |
| 支影回廊 | 先拆上方支撑，还是先清低挂枝打开射线 | 两种清理顺序均可解；空接一球仍有恢复路线。支撑直射有窄窗口，可先从侧面清枝。 |
| 侧窗折光 | 内侧遮挡下，比较墙反落点与当前/下一色 | 墙反换色与先拆左锚后走内侧直射均可解。只往中间堆泡会提前触底，空接后可重选清理顺序。 |
| 三锚回航 | 分辨挂枝归属，在侧翼回收与顶锚拆除之间排序 | 先清左锚与先清两侧低枝为不同顺序；四发后的下压改变下一刀落点，旧角度应重新观察。 |

规则数值、颜色袋、弹道与 v2 一致。没有实时瞄准倒计时或弹药上限；一发清空时优先判胜。预览与实际飞行使用同一弹道函数。三关模型解分别为4/4/6发，代表已知解的短篇规模，不证明盲解难度或持续乐趣。

每图只有清空后才封存战报；当前图重试保留前图成果，封存图不能反复重试累加。新旅程需要确认，只替换本篇进度/战报，保留声音与教学偏好；本篇没有另设永久最佳榜。独立键 `classic-atlas.starline.journey.v3`，不读取或改写旧版键。刷新活动局先暂停，飞行中回到完整出手前；失利、关间和最终总结也保留。坏档原字节禁止覆盖，写入失败非阻塞提示，后续成功会清除失败提示。

鼠标瞄准并点击发射；←/→ 或 A/D 微调，空格发射、X换色、P暂停、R重试当前未封存图。触屏拖动瞄准，单独点发射；方向按钮可以长按。目标面板只读，不跳关。新篇已接入本机最近玩过与大厅返回。
