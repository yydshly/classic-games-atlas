NAVIGATION MANUAL / 航行手册

让同色的星点相遇。

  1. 瞄准，观察虚线，再发射。

    鼠标移动瞄准、点击战场发射。键盘 ← → / A D 调整，空格或 Enter 发射；手机在战场拖动瞄准，再点下方发射。侧墙会反弹，落点圆环显示预计附着位置。

  2. 同色三连，断开悬岛。

    泡泡落在六邻接网格中。同色连通达到三个会消除；失去顶端连接的泡泡会一起掉落。不同颜色另有独特图案，便于辨认。

  3. 看下一颗，也看下压倒数。

    X 或交换按钮每发可以换一次当前与下一颗。只生成场上存在的颜色。清空获胜。每四次发射结算后，压板与星群一起下降一排；泡泡碰到底线就失败。若这一发清空，优先获胜。没有实时下压，可以慢慢瞄准。

P / Esc 暂停，R 重试当前图，保留此前完成的战报。本篇三图依次推进，目标面板仅供查看，不能自由跳关；使用独立记录，不覆盖旧 v1/v2。准备、暂停和完整局面可恢复；飞行中刷新会回到整发之前并暂停，包括颜色、分数和下压倒数。关间结算与最终总结也可刷新保留。清理浏览器数据会移除本地进度。
