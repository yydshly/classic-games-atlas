# 云隙巡航 · 三段连航

可选原创短战役，参考纵向射击与火力选择；不是《雷电》官方复刻。原两段自由模式、八段旧版与旧存档保持独立。目录仍为42项，本作没有新增编号。

## 三段取舍

1. **晨光横阵**：原横排轻编队，散射覆盖宽队；末段扇阵寻找弹隙。
2. **暮色装甲线**：原交错装甲，对准目标使用集中双轨；预告锁点后换位。
3. **交风编队**：新增原创十组宽队/偏侧装甲/扇形火力交错，武器舱左右换边，维修在右侧。决定横扫轻机还是集中清重目标，是否绕行拾取补给、保留风幕或清弹过线。精英组合扇形/锁点/直射；HP265、弹速170、扇数3与原第二段相同，运动/开火冷却也沿用第二段级别。不是加血加速换皮。普通敌机漏过不给分，但不扣生命；无需全歼普通敌机。

三段依次推进，清完编队并击退精英获胜。每段重新整备3点机体、2次风幕与集中双轨，仍为120秒活动上限。失败或超时只重试当前段，保留前段本次成绩。关间展示下一目标，完成第三段可回看本次成绩与返回大厅。没有关间刷奖励或成长系统。

## 输入与保存

方向键/WASD、鼠标画布内跟随、单指拖动；自动射击。空格/K或风幕按钮清弹保护。触控可一指拖动、另一指发动风幕。P/Esc暂停，R重开当前未完成段。链接、按钮等原生键盘行为不被游戏快捷键拦截。

独立键 `classic-atlas.cloud.campaign.v3`。约每秒、暂停/切后台/关间/终态保存快照；活动刷新先暂停且清输入，不自动恢复按键。关间与失败/超时/结局保留。明确确认的新战役从第一段重置本次进度，保留本战役最高分；不写原自由模式存档。取消不重置。保存写入失败准确提示刷新风险，旧有效字节不删除，后续写入成功清警告；坏档保留原字节并禁止覆盖。
