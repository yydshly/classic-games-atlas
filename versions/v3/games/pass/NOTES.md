# 山口守望 · 三隘短战役

独立、可选的三图原创路径塔防。参考《王国保卫战》的塔专精与援军接敌思路，不是官方复刻。原单图 v2、原八图及各自纪录不变；目录仍42项。

| 山口 | 路线与布防目标 |
| --- | --- |
| 断桥隘口 | 原v2路线与五塔位，守住弯桥与出口。 |
| 回折石谷 | 相邻纵向折返；中央塔位能覆盖多段，需要安排控制和范围火力。 |
| 双庭岭道 | 前庭与末段覆盖分开；先破甲还是留后段收尾，需要分配塔位与预算。 |

每图仍230金/12城门、原四波、原塔/敌人/盾卫数值。图间不继承塔和金币，保留战报；只有清完四波且城门存活才前进。失败重试只重开当前图。最终三图总结可刷新重读；新战役有确认和取消，覆盖本战役当前进度，不影响其他游戏。

独立键 `classic-atlas.pass.campaign.v3`，不读写旧 `classic-atlas.pass.v2.bounded`。活动局约每秒及操作后保存，刷新先暂停；切后台主动暂停。写失败准确警告并保留旧有效字节，坏档保全且禁止覆盖，恢复写入成功后清除警告。没有云存档。

点编号或1–5按钮选塔，点建造/专精；盾卫可点路或前/中/后段。全部功能可用原生按钮键盘操作；非交互区P暂停，Esc取消部署或暂停。触控不要求拖拽。声音默认关。
