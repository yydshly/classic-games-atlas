      PRISM GARDEN / 解谜手册

      把五束光，凝成一枚棱镜。

      1. 相邻交换，三连消除。

        点击相邻两格，或向邻格拖动 / 滑动。横纵同色三连消除，下落补充继续使用原有连锁规则。无效交换回弹，不扣步。方向键选格，Enter / 空格选中，Shift + 方向键直接交换。

      2. 看清新晶簇怎样生成。

        横四连留下 ↔ 清行晶簇，竖四连留下 ↕ 清列晶簇。T / L 交叉留下 ✺ 花蕊，清除周围 3×3；直线五连留下白色虹彩多边形棱镜。生成位置优先交换的目标格、再源格；下落连锁中选左上普通晶簇。生成格本轮保留，不计收集或松土；若被旧特殊效果命中则仍会消除。消除后，新特殊晶簇会短暂停留，再下落。

      3. 为棱镜选一种颜色。

        棱镜与相邻普通晶簇交换，清除棋盘上该颜色的晶簇，并触发被命中的特殊晶簇。其他特殊效果命中棱镜时，清除当前棋盘上有色晶簇（含行列晶簇与花蕊）最多的颜色，平手按日珀、叶翡、雨蓝、暮紫、莓红、月白的顺序；两枚棱镜交换清除全盘。棱镜与其他特殊晶簇交换时，各自触发。普通特殊晶簇也可直接交换或同色匹配触发。

      4. 三题旅程，依次点亮。

        展开「公开题面与解法」查看固定种子、起始棋盘和逐步参考解法。每次重开回到本题固定开局。寻找一步不扣步，但仅提示当前有效交换，不一定是谜题的参考解法。全部连锁结束后先判断目标，再判断步数是否用尽；最后一步达标也获胜。

      完整交换结束后自动保存稳定棋盘；动画中刷新回到这次交换之前，恢复时暂停等待。离开窗口自动暂停。P / Esc 暂停，R 重试当前题，H 提示。本旅程与原两题及20关的进度相互独立。
