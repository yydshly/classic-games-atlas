# 晶簇花园 · 三束光旅程

可选的三题连续原创三消谜题，参考经典消除玩法，不使用原作素材或关卡。原v2两题自由选择、原20关及各自存档保持不变；目录仍42项。

1. **把雨蓝留给棱光**：原第一题，先造棱镜再选雨蓝。
2. **远处的一束长光**：原第二题，用选色触发远端清列晶松土。
3. **双层远光**：原创静态棋盘，6步预算。先独立横扫剥开双层土，再造棱选雨蓝触发三个远端列晶；单次爆发不能代替分次剥层。公开解3步，并非唯一解承诺。
