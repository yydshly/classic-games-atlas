# 弯道邮差 v3 · 双赛道

独立可选的原创竞速模式。晨光街区保留 v2 几何与驾驶规则；新增水闸折线，长直道末端减速接连续反向弯。两图各三场固定能力对手，两圈、95秒上限；合法完赛解锁本图下一场，第一名才算胜利。没有配送、改装或在线排名系统。

复用 v2 原创车辆 SVG、渲染风格及驾驶数值；路肩、碰车、闸门顺序和复位罚停规则不变。新图不是镜像或旧图换皮，不引入原作资源。

稳定路线 ID：晨光街区为 `post-v2-morning-block-v1`，水闸折线为 `post-v2-sluice-switchbacks-v1`。几何数字 ID 仅用于渲染，不作纪录键。每图独立保存最佳、对手场次、上次结果及进行中比赛；切图保留原图比赛，重新接续先暂停。重开仅重开当前图当前场。

新命名空间 `classic-atlas.post.routes.v3`。首次使用只读导入可验证的 v2 档到晨光街区，不写入或删除 `classic-atlas.post.v2`。旧活动局只归旧路线；未知路线或不相符 checkpoint 拒绝。坏 v3 档保留原字节并停止覆盖；写入失败提示刷新风险，后续成功恢复保存提示。v1、v2 页面继续可用。

[验证与截图](../../../../docs/post-route-qa/)：普通UI辅助驾驶新图合法两圈第2名；非真人驾驶或真机验收，不声称新图三场均第一名。
