怎么玩与保存边界

两行动依序进行，各清六台来敌且守住基地。第一行动完成后先看结果，再整备第二行动；第二行动失败可只重试第二行动，首图结果保留。每图按原初态出击，不继承残血、临时补给或场内位置。

1P：WASD + J；2P：方向键 + Enter。P / Esc暂停，失焦或切出标签自动暂停。触控只提供1P；双车没有AI队友，需要两人共用键盘。单车同样可以完成全程。

只保存编组、当前行动及已结束行动的结果。战斗刷新回本行动整备；关间、失利和最终总结可重读。不读取或写入v1/v2选择、最好分或存档。不是联网、排行榜或完整《Battle City》复刻。
