# 堡垒防线v3 · 两段短战役候选

这是独立可选的短战役，不替代v2自由选图，不新增第41款。复用v2原有两张原创地图、引擎、绘制、输入与基地反馈；伤害、速度、六敌队列、掉落、基地耐久和每车三次出击不变。不是完整《Battle City》复刻。

顺序是第一行动整备→双翼哨口→关间结果→第二行动整备→交汇换防→旅程总结。单车与同键双车在出发前选择，本次两图编组一致；没有AI队友或联网，触控仍仅操作1P。五分钟是早期设计目标，不是通关时长保证。

两图各按原初态出击，不继承场内残血、位置或临时能力。自然失败只重试当前图；首图已完成的真实结果保留。第二图完成后没有第三图，最终总结可刷新重读；重新开始须确认。

独立键为classic-atlas.fortress.campaign.v3，schema1。仅保存编组、阶段、两场已结束结果与失利计数；不读写v1/v2记录。战斗刷新回当前图整备，关间/失利/最终总结保留；没有伪造战斗快照。坏记录或无法读取时保全原内容、只临时游玩；写失败保留旧有效内容并提示刷新风险，后续写成功可恢复正常状态。

总结的分数、活动时间、基地和出击余量取实际结束结果。输入时间只统计存活期间的控制输入，不是击杀贡献或真人数量证明。没有额外奖励、排行榜或成长经济。
