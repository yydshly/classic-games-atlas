    LANTERN WAKE / 夜航手册

    不要等到转角，才想起转弯。

    1. 点按方向，提前转向。

      方向键或 WASD 转向。风帆松手后仍会前进，遇墙才停；提前按下的方向会保留到下一处可行路口。反向也在下一个格点执行。手机方向键同样可以短按缓冲，不必卡着转角操作。

    2. 拾起辉光，暂时反制。

      收齐普通光点和大菱形辉光道具即可过关。辉光期间巡灯减速、退避，碰触可将它送回泊位；时长有限，拾取会刷新而不累加。返回中的空心巡灯和出泊虚线巡灯暂不造成接触伤害。

    3. 看清节奏与结算。

      循迹灯跟随，截路灯预判，巡航灯走固定航线。巡航与追逐按计时切换，辉光期间阶段计时继续，巡灯优先退避。左右灯门互通，风帆与巡灯都可穿行。受伤扣一盏航灯，回起点并有短暂保护，收集进度保留；三盏耗尽可重试。辉光刚拾起立即有效，到期立即失效；普通最后光点不会抵消同一刻的危险接触。

    P / Esc 暂停所有移动和计时，R 重开。受伤后松开再按方向，避免残留输入。三港依次前进，失败只重试当前港；活动刷新先暂停，关间和终态记录保留。第三港浅色支港为避风格，巡灯不能进入，但辉光计时仍会消耗；方向松开后仍前进，遇墙才停。原双港自由模式保持独立。
