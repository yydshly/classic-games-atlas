ASTRAL PINCOURT / 弹庭手册

把一条弧线，变成回声。

  1. 一球，一次计划。

    鼠标移动瞄准，点击球场或“发射”；方向键 / A D 每次调半度，Enter / 空格发射。手机横向拖动球场或滑杆瞄准，明确点“发射”；松手、竖向滚动与触摸取消都不会发球。虚线只表示第一段弹道，不显示后续反弹。

  2. 目标点亮，回收结算。

    亮色星钉是目标，普通圆钉提供路线和分数。命中的钉会发光，本球内仍可反弹，到本球回收才统一移除。每枚钉只首次计分；一球多钉有连击加分。全部目标点亮后等待本球回收，不要求清完普通钉。

  3. 把球，交给小舟。

    接球槽只在弹珠飞行时沿轨道往返，瞄准时静止。球完整落入槽口且本球至少命中过一钉，才返还一发并加分；空球无奖励。最后一发先结算命中与返球，再判胜败。

  4. 涟漪与回弹石。

    涟漪钉直接命中后点亮周围 110 范围内的钉；范围内其他涟漪钉只点亮、不继续扩散。浅色大圆环是回弹石，不消除、无分。它们从后期关卡逐步引入。

卡球保护公开：速度很低并持续 1.2 秒，会轻推一次，每球最多两次；12 秒仍未回收则回收本球，仅结算已命中的钉，不替玩家点亮目标。暂停冻结物理与槽位，切出页面自动暂停。完整一球结算后保存合法角度日志；飞行中刷新回到本球出手前，恢复先暂停。P / Esc 暂停，R 重开；重试回到当前图初始预算。
