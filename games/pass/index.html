PASS WATCH / 布防手册

先看山路，再落一座哨。

  1. 选点、建造、升级。

    点击 + 点位或点位按钮。弩哨擅长单体连射，石炮覆盖密集敌群，霜灯造成伤害并减速。每塔有 I / II 两级；选中显示射程和完整数值。出售返还累计投资的七成，向下取整。

  2. 看预告，再开波。

    整备阶段不会来敌。点击开始波次后自动战斗，塔优先攻击射程内最接近出口的敌人。击杀获得金币，清波另有补给。可以在战斗中建造、升级和出售。

  3. 守住六波，保住基地。

    全部六波结束且基地还有生命即胜利；漏过会扣命，重卫扣两点。霜灯只取当前最强减速，不会相乘叠加，效果到期恢复。暂停冻结战斗与计时，1× / 2× 改变整体速度。

鼠标和触屏均可点选；Tab 可访问点位及建造按钮。P / Esc 暂停，R 重新整备。刷新从本图重新开始，解锁和个人记录保留，未完战斗不会恢复。
