ESCAPE MANUAL / 撤离手册

放下之前，先想好退路。

  1. 点按放置，转过拐角。

    方向键 / WASD 移动，空格 / J 每按一次放置一枚。2.4 秒后爆炸；爆风呈十字，会伤到自己。石柱挡住爆风，木箱被摧毁后也会截断这次火线。

  2. 先清目标，再走进门。

    三格护甲，受伤后短暂保护。清空所有巡逻机后，右下角出口变绿，走进去才算通关。没有时间限制，所有敌人均可用一轮爆风击破。

  3. 强化与连锁，机会也有风险。

    木箱内藏有容量、范围和加速模块；等待火焰散去再拾取。爆风会提前引爆另一枚炸弹。放下的炸弹可走出去，离开后不能再穿回。

P / Esc 暂停，R 重新开始。离开页面会自动暂停。十关逐关解锁；存档只在当前浏览器，清理浏览器数据会移除进度。
