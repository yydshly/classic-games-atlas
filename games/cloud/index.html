CLOUD SEAM / 巡航手册

看的是机体，躲的是核心。

  1. 移动，自动射击。

    方向键 / WASD 移动，或让鼠标在画布内带领机体；手机一指拖动。中央金色小点是判定核心，装饰机翼不计入受弹范围。机体会按正常速度跟随，不会瞬间传送。

  2. 先看虚线，再避弹道。

    铜色长弹直射，青色菱形锁定预告时的位置，紫色三角以扇形散开。虚线表示发射前预告。敌机从远端进入，靠近机体或飞到低空后不再生成近距离弹幕。普通敌机离场不扣生命，也不给击退分。

  3. 两次风幕，三点机体。

    每关两次风幕，空格 / K 或按钮发动，立即清除敌弹并短暂保护；激活期间不能重复消耗。手机可以一指拖动、另一指发动风幕。受伤后短暂无敌并闪烁。拾取 ↑ 升级最多 III 级，+ 修复最多三点。

清完编队并击落末段精英即胜利。机体耗尽时失败；同刻击落精英也不能抵消致命伤。P / Esc 暂停全部战斗与计时，R 重开。刷新从当前关重新整备，保留解锁和最高分。拖动画布不会滚动页面。
