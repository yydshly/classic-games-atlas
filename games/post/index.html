BEND & LETTER / 驾驶手册

把车头，指向下一封信。

  1. 油门与方向盘，一起用。

    W / ↑ 加速，S / ↓ 刹车，A D / 左右相对车头转向。不是屏幕方向平移；停车时方向盘不会原地旋转，刹车不倒车。触屏可同时按住油门与方向。三秒倒计时结束后才开表，提前按油门不会偷跑。

  2. 进弯之前，先留一点余地。

    松油会自然减速，急弯前刹车、弯中转向、对准出口再加速。道路外是慢速路肩，偏离外边界会自动安全复位；本轮无对手、碰撞淘汰或倒计时道具。

  3. 闸门是顺序，终点是闭环。

    按道路箭头正向通过亮起的下一闸门。必须完成本圈所有顺序闸门再过格纹终点；逆向穿越、漏门或在终点来回摆动不会刷圈。目标为界面注明的圈数与总时限，余时为零即失败；最后圈完成后只结算一次。

  4. 路线走偏，也能重新接上。

    B / 安全复位回到最近已通过的闸门前方，车头沿路、车速归零，加时三秒并短暂锁输入。路线严重偏离也按相同规则处理；不会跳过下一个闸门。重开会清空本次计时和圈数，最佳记录独立保留。

P / Esc 暂停；页面失焦自动暂停并清除按住输入。每圈记录与全程最佳、解锁、本次进度只存在本机。刷新按安全复位恢复：回最近闸门，额外加三秒并先暂停；不信任外部坐标。当前圈计时不重置。损坏当前局拒绝，合法最佳与解锁独立保留。
