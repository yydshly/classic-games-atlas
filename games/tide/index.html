TIDAL THREAD / 潮汐手册

给下一颗，留一段回声。

  1. 旋转潮灯，把同色接起来。

    鼠标移动后点画布；触屏点画布，或拖动瞄准后松手。三颗以上相邻同色才消除，单颗也可先接成一对。每色有独立符号，不必只靠颜色。左右键转向、Enter/空格发射，滑杆与3°按钮可微调。

  2. 看清下一颗，再决定是否交换。

    X / 换珠只交换当前与下一颗，不生成新色；只抽取场上仍有用途的颜色。发射珠在飞行、珠链在衔接或短暂装填时，下一发和换珠会锁住。按住空格不会连发，暂停后的旧手势也不会补发。

  3. 断口会靠拢，连锁要等实际接上。

    清掉中间一段，前段会回接。接上后又凑到三颗，会继续消除并增加连锁；隔着断口或不同色不会隔空算相邻。瞄准虚线停在第一颗珠或礁屏；礁屏只挡发射珠，弯道上的珠始终沿连续路径行进。

  4. 少量能力，留给需要的时刻。

    第4关起有两次缓潮：五秒推进降到40%；第7关起有一次回汐：整链后退约四颗珠距，近入口会限制距离。按1/2或大按钮，只在准备好发射时使用；次数不补回，缓潮不叠加。

清空全部场上珠才赢，包含自己插入的珠。触线优先于同一步的末珠清除，不能以最后一击抵消失败。所有关基础推进同速。P/Esc暂停，R重来，失焦/切页自动暂停。刷新按正式引擎重放普通操作记录，并暂停恢复飞行、断口、弹仓与能力。存档只在本浏览器；损坏当前局拒绝。五分钟观察上限。潮分只按原珠消除及连锁奖励，扣除发射、用时和能力，胜利另奖1000；新插入珠不刷分。
