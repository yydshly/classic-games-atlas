# 雾港查单 · 三班航务推理原型

这是一款原创的货单核对短篇，不计入现有 45 款目录作品。玩家在虚构雾港对照船单、港务底册和不断变化的航路规则，为每艘船指出一条证据并决定放行或暂扣。船名、港湾、文件版式、美术、规则和事件均为本项目原创，无现实通关或法律建议。

## 经典启发与差异

[《Papers, Please》开发者官方说明](https://papersplea.se/presskit/)描述了逐人核验文件、利用简陋查验工具作通行决定的循环；[开发者官网](https://papersplea.se/)列出设计与叙事奖项。我们借鉴“规则变动让同一份证据在不同时间具有不同意义”的可玩价值，但不借用原作的国家、人物、移民、图章、故事、画面或音乐。本作把对象改成虚构货船和航路，三班固定案例，不是商业原作的完整复刻。它会不会让陌生玩家愿意重复核单仍需真人验证。

## 核心循环与三班差异

每班先读规则板。船单给出航证有效期、航路、货类、封签、蓝签和载重；底册给出登记封签和载重上限。选“无矛盾”才能放行，暂扣则须点出一条真实问题。判定一份耗 1 分钟；做错会计入误判并公开实际理由。若封签污损，快检耗 1 分钟且次数有限；索拓本耗 2 分钟，不耗快检。东汐关闭以点击判定前显示的分钟为准，因此检查方式会改变后续船的可放行状态。

- 第一班教航证日期、封签与北礁禁航，无污损；5 份船单，8 分钟内至少判对 4 份，误判不超 1。
- 第二班加入光石蓝签、东汐第 5 分钟关闭与一份污损封签；快检和索拓本都能过关，但后者可能错过东汐开放窗口。
- 第三班再加载重规则和第二份污损封签。有限快检可用于不同案例；慢速保守查验与承担可见风险的快路线有不同时间与放行记录。

操作为鼠标或触控点按；键盘 Tab／Enter 可用所有按钮，1～6 选证据，R／H 决定，I 快检，C 索拓本，P 暂停。失焦自动暂停，刷新后须明确继续。失败可重试当前班，已解锁班次及旧成绩保持。使用独立存档键 `classic-games-atlas:fog-harbor-ledger:v1`，不读取或写入其他游戏存档。旧版页面与目录均保留。
