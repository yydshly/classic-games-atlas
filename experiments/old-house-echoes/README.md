# 旧馆余声 · 雨檐救援

七个相连房间的原创生存探索首段，`echoes-slice-1`。**仅本地候选，未部署，不计入45款登记作品。** 不是完整《Resident Evil》复刻，七室不是后续上限。没有使用原作人物、建筑、地图、故事、美术、音效或代码。

从仓库根目录运行 `python3 -m http.server 4174 --bind 127.0.0.1`，打开 `/experiments/old-house-echoes/`。首页近期入口 → `/play/#independent` → 本作 → 返回大厅；原45款、99版本与7个旧实验地址继续保留。

## 救援目标与操作

救援者林芜寻找巡馆员阿遥：在阅览室拿馆钥，检查铭牌、在东门使用；把档案室熔芯与温室绝缘线组合，在档案室北电柜使用；去前室用敷包照料阿遥；回门厅南座使用撤离信标完成。体力归零失败，可回到值班室最近记录点重试；没有记录则回进馆时。

- 方向键 / WASD：按屏幕方向移动。Shift：举枪停步，方向调整朝向。空格：射击。E：近处调查、拾取、过门。
- B 背包、M 地图、P 暂停。菜单暂停敌人与时间。物品按钮可以检查、使用、选择两件组合。
- 触控方向盘＋按住举枪＋射击，调查独立按钮。多指、取消、失去指针捕获、键盘释放及失焦均处理；继续后需重新按方向。

## 决策与空间

门厅 ⇄ 肖像回廊 ⇄ 阅览室 ⇄ 档案室 ⇄ 撤离前室；门厅 ⇄ 温室 ⇄ 阅览室是较长替代路线；门厅 ⇄ 值班室，温室南侧开内闩后可双向通值班室。每次门前主动 E，固定全室斜视镜头，不会自动瞬移。碰撞按地板坐标；长桌、花台与壁龛实际影响路线。

六格包括枪、弹盒、治疗和任务物。开始枪内4发，弹盒5发。巡馆偶需4发准确命中才停下；角度错会浪费，举枪不能逃跑。巡馆偶追向最后可见位置，推击前摇0.65秒、收势1.4秒；可以侧移脱开，也可完全走温室。清理永久保留，方便较慢的返程。没有血腥表现。

药叶＋净布＝敷包（两格变一格）；熔芯＋线＝修复熔芯；弹盒＋枪＝装填（满4，空盒收起）。两个敷包是两格、分别消耗。药叶自己用恢复25，敷包自己用恢复60；阿遥也需要一包，若先给自己用掉，就得回值班室取备用药布。满包不能拾取，物品留在原处。不能远程寄存、丢物或复制，钥匙用过仍占格。箱内备用药布和已寄存物不会凭空再生。枪存进柜里仍保留弹仓，但无法在外使用。

阿遥获救后以简化同行表现跟随，移动从3.15降至2.25；没有独立寻路、碰撞或受伤系统，不称完整护送AI。回程若没清廊，仍有巡馆偶，可重新躲避或走温室。

## 续档与测试

独立键 `classic-games-atlas:old-house-echoes:rescue:v1`，只保存本作现场与记录点。暂停、过门、后台/离页和每4秒自动保存；加载先暂停。记录点还原当时资源而非免费补给。重试、新旅程均确认；结束页取消重试返回结果。存储失败会显示提示；损坏或结构不合法的旧档不覆盖，临时玩不会改原字节。没有联网、统计、账户或第三方运行时依赖，声音默认关，为本地振荡器短提示。

```sh
node tests/old-house-echoes.test.mjs
python3 scripts/test-old-house-browser.py
node scripts/build-play-index.mjs
node scripts/audit-play-entry-links.mjs --check
```

浏览器脚本需要现有 Python Playwright 与 `/usr/bin/chromium`，以及根目录4174静态服务。正常输入路线脚本是有限的人工路点，不做无界搜索。完成回放只用方向、举枪/射击、E、背包按钮和铁柜按钮；读取序列化 telemetry 观察位置，不修改引擎或胜负。场景单元测试中的坐标夹具与正常通关证据分开。截图及JSON只放被忽略的 `.local/old-house-qa/`，不加入提交、不上传。

## 来源事实与本作简化

[Capcom 原出版 PC 手册公开镜像](https://retrogamer.biz/wp-content/uploads/2016/06/Resident-Evil-Manual.pdf)（第三方托管的原出版物，2026-10-26读取）：印刷页7–8说明举枪、方向与攻击分离；页11–13说明耗材存档、状态界面、使用/装备、检查、组合、地图/文件、有限携带与储物箱。该手册的角色携带量有差别。本作采用六格、单人、无消耗续档与一个储物点，是简化，不将其描述成原版完整功能。

[GOG 授权原版发行介绍](https://www.gog.com/en/game/resident_evil)（2026-10-26读取）所保留原版介绍强调洋馆空间、光影和变化镜头。本作只取固定视角的空间判断，不复用画面；每室固定一镜、屏幕方向移动，无坦克控制、三维物品旋转、双主角、复杂武器、推箱、原版剧情/谜题、耗材存档或完整原版规模。后续西翼/庭院档案/地下撤离尚未制作，应以新的决策而非堆房间推进。

当前证据与限制见 [本地开发记录](../../docs/old-house-echoes-qa/README.md)。辅助输入回放不等于陌生玩家趣味验收；390 Chromium模拟不等于真机触控。未上传截图，未公开提交或部署。
