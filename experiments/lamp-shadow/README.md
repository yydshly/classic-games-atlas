# 灯影潜行（本地五段原型）

Konami 对《Metal Gear》系列的[官方介绍](https://www.konami.com/games/eu/en/topics/19257/)称其核心转向避开敌人并潜入目标区域，初代于 1987 年发行。本作只借鉴“观察巡逻、避开视线、完成潜入目标”这一机制方向；港区档案员、五段地图、巡卫灯束、画面和文字均原创，没有战斗、道具清单或原作故事。它是简化短篇，真人趣味与真机触控尚未验收。

## 玩家闭环

取齐蓝色档案，抵达绿色北门。墙格阻挡通行与灯束；巡卫沿可见路线往返，被连续照见约 0.7 秒便失败。方向键 / WASD 或触控方向键走动，Q 消耗本段一次或两次声响，使巡卫停步约 2 秒，但灯束不消失。P 暂停，R 打开重试确认；切页失焦自动暂停，刷新从当前段继续。已完成段落可单独重玩，不改其他实验和正式作品的存档。

五段分别聚焦单巡线墙角、上门短险 / 下门绕行、交叉巡线、两翼档案回访、终局近路巡线 / 南墙绕行。阶段数量是原型范围，不代表该玩法最终上限。早期静态路径检查、有限浏览器键盘路线及窄屏触控路线只能证明操作可完成，不能替代陌生人首玩或乐趣判断。
