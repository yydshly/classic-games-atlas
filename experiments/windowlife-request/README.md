# 栖窗日常 · 先听你说，还是先写完

**独立、未发布候选。** 复用第二日小屋，探索一次具体的相处安排；不增加目录作品、天数、家具、关系数值或道德评分。原三日页面与存档完全保留。本候选未依据任何尚未读取的外部参考视频创作。

作者设定的下午尾声：禾禾的手记还剩半页，阿沐的速写还差最后几笔。这不是读取、继承或伪造玩家的原三日进度。按开始后只有一次请求，时间会明确暂停，给玩家决定的余地。

- **现在一起**：暂存未完手记，实际走到长座共同作画；纸上留下两种笔色，再实际走回书桌接着写。
- **我先写完**：两人各自完成；禾禾带着完成的手记走到长座，与阿沐交换成品。
- **先各忙各的／不回应**：各自完成作品，正常结束，没有情绪扣分、社交硬目标或期限惩罚。
- 取消共同安排保留实际完成的笔迹与未完工作，不把部分共作标成“共同完成”。取消分享后禾禾带回手记，释放家具占用。
- 完成后主动“收起今天”。没有排名、时长成绩、奖励、下一日或更优结局评级。

这是有限的场景状态机，不把原日常的完整排程界面复制进来；已完成一次选择后仍可暂停、取消共同安排或重试，但不追加自由绘画、关系树等系统。

## 保存与原版隔离

仅使用 `classic-atlas.windowlife.request-scene.v1`。不读取、不迁移、不写 `classic-atlas.windowlife.v1`。保存合法指令与逻辑步数，恢复时确定性重放：位置、纸面进度、占用、取消状态和选择均重建，活动恢复先暂停。损坏或读取失败时保留原字节并停止覆盖；写失败可临时继续，后续安全重试。

模型以 0.1 秒固定步推进；寻路不穿墙或家具，画面只读模型坐标。页面切出或长前台间断暂停，回来需手动继续。画布中的两侧作品近看来自同一份作品状态，不是额外作品或奖励。
