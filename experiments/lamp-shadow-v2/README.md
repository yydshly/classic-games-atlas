# 灯影潜行 · 暗格与声响（独立进阶原型）

本作沿用原创夜港档案员的避敌潜入目标，参考 [Konami 对 Metal Gear 的官方介绍](https://www.konami.com/games/eu/en/topics/19257/)所述“避开敌人、潜入目标区域”的核心。人物、地点、五段地图、暗格与局部声响规则均为原创；这不是原作的完整复刻，也不是已上线原版的替换。

## 核心判断

取齐蓝色档案，再到北门。金色灯锥照到普通地格会累积暴露，约 0.7 秒后失败；标“暗”的地格可走且能避开灯束，若与巡卫同格仍危险。每段的一至两次声响只影响四格内的巡卫，让其停约 1.8 秒并把灯束转向发声点。远处没有巡卫时不扣次数；声响扩散约半秒，连点不会重复扣次。暗格等转身可省声响；在暗格附近诱引可抢短路，但要避开转向后的灯锥。

方向键／WASD 和触控方向键移动，Q 或声响按钮诱引，P 暂停，R 请求重试。打开重试确认会暂停计时；取消后继续，确认只重置本段。失焦自动暂停、刷新续本段，已完成段落可以重玩。本版用 `lamp-shadow-v2` 独立存档，原 `lamp-shadow-v1` 存档和页面不改。

五段分别练暗格等灯、上下双门、交叉听距、双档案回访、终局近路与南墙绕行。阶段数仅是当前短篇范围，不是最终上限。模型测试可证明规则与拓扑，浏览器合法输入可证明有限路线可走；真人首次理解、乐趣和实体手机仍待评估。
