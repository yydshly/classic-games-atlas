# 边郡来信 · 五役试玩首段

原创回合策略短篇，参照图鉴中《三国志》系列的命令额度、内政、补给与地形行军判断。具体核读依据是[光荣特库摩《三国志14》官方手册的内政页](https://www.koeitecmoamerica.com/manual/rtk14wpk/en/4200.html)和[主界面／回合命令页](https://www.koeitecmoamerica.com/manual/rtk14wpk/en/3300.html)。本站不使用原作人物、地图、素材或规则数据，也不称完整复刻。

## 目标与取舍

玩家是边郡传信官。五役分别要求保粮仓、夺烽台、驿骑探两路、同时守住北望与远哨、送出末封信并守住补给线；第五役不是最终数量上限。每回合仅有两或三条命令，谷卫战力强但入山及过浅滩更耗粮，驿骑省粮且承担探报任务。路线控制会影响断线行军加价。行军、筹粮和驻防共用命令，所有敌军意图提前公开，按该地守力总和与敌力比较结算。两队每回合消耗两粮；缺粮会减少次回合命令，若末回合缺粮则失败。松驿失守立刻失败，目标在期限回合同时满足才胜利。第二役的谷卫岚隘线比驿骑浅渡线少两道命令并较早稳住烽台，却多耗一粮；两条都能正常完成。第四役期末北望、远哨同时受袭，单队先后走两点会失去离开的据点。

首屏说明目标、操作与胜败。点击队伍及相邻地，使用行动按钮；键盘可用数字1/2、方向键、Enter、M/F/G/Z/E/Esc。未结算命令可撤销，刷新续档仍保留本回合最多三步撤销历史；结束回合后不可撤销。刷新载入先暂停。重试仅重开本役，解锁记录保留；存档只写 `atlas.border-letters.v1`，不读取或写入其他游戏存档。
