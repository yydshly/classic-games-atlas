# 边郡来信 · 八役已上线试玩

原创回合策略短篇，参照图鉴中《三国志》系列的命令额度、内政、补给与地形行军判断。具体核读依据是[光荣特库摩《三国志14》官方手册的内政页](https://www.koeitecmoamerica.com/manual/rtk14wpk/en/4200.html)和[主界面／回合命令页](https://www.koeitecmoamerica.com/manual/rtk14wpk/en/3300.html)。本站不使用原作人物、地图、素材或规则数据，也不称完整复刻。

## 目标与取舍

玩家是边郡传信官。前五役分别要求保粮仓、夺烽台、驿骑探两路、同时守住北望与远哨、送出末封信并守住补给线；第五役不是最终数量上限。每回合仅有两或三条命令，谷卫战力强但入山及过浅滩更耗粮，驿骑省粮且承担探报任务。路线控制会影响断线行军加价。行军、筹粮和驻防共用命令，所有敌军意图提前公开，按该地守力总和与敌力比较结算。两队每回合消耗两粮；缺粮会减少次回合命令，若末回合缺粮则失败。松驿失守立刻失败，目标在期限回合同时满足才胜利。第二役的谷卫岚隘线比驿骑浅渡线少两道命令并较早稳住烽台，却多耗一粮；两条都能正常完成。第四役期末北望、远哨同时受袭，单队先后走两点会失去离开的据点。

第六至八役已加入线上试玩，但新役的真人体验仍待验；前五役地图、参数和结算规则未改。第六役要求驿骑到过烽台传令、远哨与北望；玩家可守仓维持连通补给，或弃仓让驿骑提前通过，断线后每次行军额外耗一粮；两条正常输入路线分别用 5 次行军／6 粮和 4 次行军／7 粮完成。第七役是公开的连续换防：驿骑先行、让烽台暂失再由谷卫夺回，或谷卫逐点守住、驿骑跟进；前者早到远哨且需一次驻防，后者多走一段并多筹一次粮但不丢烽台。第八役让强卫守北望、驿骑折返松驿，或卫回驿、驿骑在北望连续三回合驻防；前者行军耗粮 12、筹粮三次、驻防一次，后者耗粮 9、筹粮两次、驻防三次。第六至八役均沿用原地图、军粮、驻防、公开敌意图与独立存档，不加新兵种或隐藏数值。第六役把原有断线费用在界面拆明，北线直接绕过烽台的旧版捷径已被可见目标挡住；旧版完赛记录按当时目标保留。

首屏说明目标、操作与胜败。点击队伍及相邻地，使用行动按钮；键盘可用数字1/2、方向键、Enter、M/F/G/Z/E/C/Esc。未结算命令可撤销，刷新续档仍保留本回合最多三步撤销历史；结束回合后不可撤销。刷新载入先暂停。重试仅重开本役，解锁记录保留；存档只写 `atlas.border-letters.v1`，不读取或写入其他游戏存档。

第六役的目标修正不会追改旧版进行中存档：缺少目标版本标记的第六役继续按原有远哨／北望条件结算，页面明确说明；新开或确认重试才启用烽台传令目标。临近第四回合的旧档可照旧筹粮完赛，载入页面本身不写旧档。旧版已完成记录与第七役解锁也保留。

旧版五役完成存档的 `unlocked` 曾封顶为 4。新版仅凭有效的第五役胜利记录在内存中解锁第六役；页面载入不改写旧存档。第五役仍在进行、记录损坏或未达成者不会提前解锁。第六、七役结算成功后按原方式开放下一役，重试仍只重开当前战役。

线上反馈修复：一次“结算回合”仅结算当前回合。若仍有下回合，进入持久化的“待查看结算”状态，所有命令及再次结算均锁住；单独点“继续部署”或按 C 仅解除状态，不额外推进时间。暂停刷新会同时保留结算与暂停状态。旧存档缺少该字段时按未待查看读取。此门闩针对鼠标双击、触控连点和按键重复，位置分开的继续按钮不能被原结算坐标再次命中；快捷键的重复 keydown 不会触发新动作。修复前已被双击推进的记录无法可靠辨认意图，因此不会自动回滚或改写旧记录。
