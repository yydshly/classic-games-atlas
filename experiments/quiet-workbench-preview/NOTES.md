# 轻轻回窝 · Quiet 独立体验候选

同一款《别吵醒修理师》的单场景体验切片，仍是小机器人自己回充电窝，没有搬运系统。本轮只在独立本地分支改变既有预览路径；未改 main、正式实验或目录入口，未发布。

刚修好的机器人从维修托盘出发，沿较宽的工具区或较窄的软垫边回窝。方向键 / WASD 滚动，Shift 制动，P / Esc 暂停。完整说明在“操作说明”中；明确开始后才推进物理。

- 球壳读取真实物理旋转，铜色修补片和接缝随壳滚动；面罩自稳，制动低头、真实撞击缩眼。
- 木台、金属工具盒、套筒/扳手/螺丝刀、缝边软垫与维修标签形成同一工作场景。所有实际工具体仍按原尺寸显示，含两件练习体。桌外茶杯、眼镜、台灯和修理师不构成新支撑。
- 修理师呼吸，真实碰撞和累计噪声驱动眉、头、手；惊醒照旧立即判负，表现动作不会延迟判定。
- 充电窝是低矮的台面内嵌轮廓。到窝过快时亮双竖线，铜触点保持未接通；只有物理 `charged` 才接通灯和触点，面罩点头后安定。没有磁吸、自动刹车或新增等待。
- 失败保留现场与真实落点小叉，结果条在画布外，一键回维修盘。暂停冻结物理和表现，重试清除旧反应。
