# 雾港查单 · 五班航务调度原型

独立实验，原三班《雾港查单》的文件和存档不变。五班由日期、航路、封签、蓝签、载重递进，第四、五班再给当前两艘候查船单选择先后；临时泊位和总潮窗会改变正确放行的船与优先分。正确核完当班且不超时即过班，优先分仅用来比较通关记录，不是隐藏门槛。

每次只显示当前两艘候查船单。选择一艘后可在未复核封签前改选；复核后须先判定本船。判定需明确选择证据并耗一分钟，污损封签可花一次快检与一分钟，或花两分钟索取拓本。第 2 分钟起关闭意味着当前分钟为 2 时已经不能放行该泊位，规则在页面开局说明。失败仅重试当前班，暂停刷新保留当前选船和证据。五班版用独立 v2 存档。

参考 [《Papers, Please》开发者官方说明](https://papersplea.se/presskit/)中核对文书并决定通行的核心循环。船只、港湾、泊位、货单、人物和画面均原创；排序与港务优先分是本作缩减后的额外决策，不宣称逐项复刻原作。自动化路线证明机制可完成，并不证明真人初见理解或长期重玩意愿。
