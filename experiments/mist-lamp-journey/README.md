# 雾灯远行 · 三区探索原型

这是独立的原创小队 RPG 三段短篇原型，可从统一实验入口进入，不计入正式作品计数。人物、山口、档案馆、观测站、地图、画面和数值均为原创。参考 [Square Enix 对初代《Final Fantasy》的官方介绍](https://www.jp.square-enix.com/pcgamehub/title/ff_pixelremaster/ff1/index.html)所确认的职业选择与远行体验。本作的三人编制、公开敌意图、有限营地、应急布棚和镜面守机都是自主简化规则，不是商业原作完整复刻，也不把重制版新增便利功能误称为原版机制。

## 玩家目标与空间决策

带岚（结阵防护）、遥（耗法力疗愈）、丘（耗法力破甲）连续穿过三区，重启观测站主灯。战斗中三名存活队员依次行动，敌方按提前展示的目标和基础伤害反击。普通攻击不消耗法力，死亡可只重试当前区。

1. **风墙山口**：上路 22 步，有较强哨兵，保口粮；下路 26 步，有较弱游影，渡道首次耗 1 口粮，桥后才可取得一次性饮剂。尽头守机必须清除。
2. **淹水档案馆**：上路封障让丘花 2 法力永久拆除；法力不足可走下路。下路需清敌，胜后取得一次性药包。两路到图册出口汇合。
3. **雾灯观测站**：中路直达主灯。北侧死巷需 1 口粮开舱门，才可取饮剂；南侧死巷需清敌才可取药包。主灯每轮公开攻击对象与镜面状态；镜面闭合时普通攻击减 2，丘的破甲不受影响。

生命、法力、物品和已清敌/已开障碍跨区保留，进入下一区不自动补满。营地休整花 1 口粮，每人最多恢复 4 生命和 2 法力；口粮归零时，后两区入口各有**一次**应急布棚，把生命提到至少 8、法力提到至少 2（不超过职业上限），不免费无限恢复。可从本区入口返回前一区；回访不会重发已经取得的补给。重试当前区回到该区进入时的资源快照，保留此前区域结局。

## 操作与存档

方向键 / WASD、手机方向按钮移动；E / 互动按钮用于营地休整或档案馆封障。战斗里 1 / 2 / 3 或按钮选择攻击、防守、职业技能；4 / 5 使用药包、饮剂，先选目标。P 暂停。刷新先暂停续档，取消重试不写入。保存键为 `classic-games-atlas:mist-lamp-journey:v2`，不读取任何已上线游戏的档案；首段旧本地候选的 `classic-games-atlas:mist-lamp-pass:v1` 只读迁移，原键不被删除或覆盖。
