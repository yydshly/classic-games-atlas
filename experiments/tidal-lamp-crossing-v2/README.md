# 潮桥送灯 · 六关进阶横断原型

原创港区灯邮以九列短步，把灯送往北岸中央。车道看移动间隙，水面踩浮梁并随其横移；车撞、落水或超时失败，重试只重开本关。已完成关卡可重玩且保留最佳记录，安全岸可停步观察；暂停与刷新不推进关卡时钟。

参考经 Konami 授权发行的 [《FROGGER》官方发行介绍](https://www.arcadearchives.com/en/title/aca-099/) 所述限时穿越车流与河道。我们推断“先看危险节奏，再用短步作空间选择”是其吸引力之一，保留这一判断；灯邮、港区、车辆、浮梁、地图、故事和画面均原创，不使用原作素材，不称完整复刻。

六关按判断方式递进：

1. 清晨车潮：车流与安全岛，练习停步观察。
2. 浮梁渡口：水面必须落在浮梁上，浮梁会横移。
3. 双闸归灯：中岸封栏挡住中央，两侧都可绕行。
4. 错峰双车道：两组逆向车流之间有安全岸；连续抢过或分段等候各有时间与风险代价。
5. 中岸双门：下段连续水面没有安全岸；跟随浮梁并短步对准左侧二、三列或右侧五、六列，在中岸再观察北段。
6. 两岸分路：左侧以车流为主、右侧以浮梁为主，中岸可换边；同一目标有不同的时机判断。

方向键 / WASD 或屏幕方向键可按住连续短步，松开即停；P 暂停，R 打开重试确认。失焦自动暂停。进阶版存档 `classic-games-atlas:tidal-lamp-crossing:v2`，原三关版 `classic-games-atlas:tidal-lamp-crossing:v1` 的文件、入口和存档均保持不变；不自动导入原版记录，进阶版从第一关独立开始。

本原型尚需真人首玩和实体手机体验判断车流可读性、节奏与重玩价值。规则路线与自动浏览器操作只证明有限可完成性，不能代替真人验收。运行 `node --test experiments/tidal-lamp-crossing-v2/engine.test.mjs` 验证规则与存档；另有 Chromium 输入、布局和恢复回归脚本。地图、角色与画面均由本项目代码自绘。
