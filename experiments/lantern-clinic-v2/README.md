# 灯下候诊 · 五班进阶原型

独立于三班原版的原创五班经营短篇。两版入口、存档分别保留；本版不计入现有 45 款目录作品，真人和实体手机体验待验。

## 经典启发与原创边界

[Electronic Arts 对初代《Theme Hospital》的官方介绍](https://www.ea.com/games/theme/theme-hospital)指出，有限资源下设计、维护并管理医院，使房间、员工和来者流动互相牵动。本作只借这一经营循环：四个线性房位、两种虚构灯光故障、一间可选读谱室、最多两名护理员。人物、场景、病症、规则和页面均原创；不含原作素材，也不是现实医疗建议。

## 五班目标与新增决策

每班须在可见时限内处理足额来者，离开数不超过上限。房间越远路程越长。第二班起，模糊线索可送读谱室确认，也可直接分流承担误送风险；第三班起标明“长诊”的来者累计占用护理员两个有效分钟，调离会暂停处理而不清除进度。第四班有两波到达，间隙可换岗；第五班把辨光与长诊叠在一起。各班开场说明目标与波次，来者卡片说明期限和处理长度。

胜利之外有两种独立重玩目标：零误送、零离开取得“清晰章”；在班次明示的分钟数内完成取得“迅捷章”。两个标记可以分次取得，不以一条高风险快路线覆盖此前的谨慎纪录。例：第二班读谱路线约 11 分钟、0 误送，增员快路线约 8 分钟、1 误送；末班读谱约 16 分钟、0 误送，增员快路线约 15 分钟、2 误送。数值来自确定性规则模拟，是策略可行性证据，不等于真人认为有趣。

鼠标或触控点按，键盘 Tab / Enter 可操作所有按钮；N 推进一分钟，P 暂停。失败可重试本班，刷新先暂停，已取得标记与已解锁班次保留。存档键为 `classic-games-atlas:lantern-clinic:v2`，原版 `:v1` 不读取也不改写。

## 本地检查

从仓库根目录运行 `node --test experiments/lantern-clinic-v2/engine.test.mjs`。检查五班胜负、不同资源路线、长诊中途换岗、暂停刷新、重试与两个独立标记。独立浏览器的正常输入证据与局限记录在私有 `.local/`，不进入发布候选。
