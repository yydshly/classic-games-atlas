# 三席擂台 · 潮门三场（体验原型）

这是与已公开单场原型并存的原创三场短战役，通过独立 `/play` 实验入口与单场并列，不计入 45 款目录作品。复用项目自写的角色画法，战役引擎与存档独立，不修改 `experiments/three-seats-arena/` 的规则或记录。三人接力、排阵和胜者余血留场参考 [SNK 官方 KOF 系列介绍](https://www.snk-corp.co.jp/us/games/kof-portal/about/)；人物、场景、敌方打法和简化规则为本作原创，并非原作完整复刻。

| 场次 | 公开对手顺序 | 可见打法与决定 |
| --- | --- | --- |
| 门廊探步 | 汐 → 芦 → 砾 | 对手追近到轻击距离，先蓄重击再快击。玩家选长距牵制或提前守住追压；不靠看见 0.12 秒轻击才反应。 |
| 长袖影线 | 芦 → 砾 → 汐 | 到重击距离即蓄力。玩家可以停在线外、预先防守，随后趁收招接近。 |
| 潮门守擂 | 砾 → 汐 → 芦 | 接近后先举守再蓄重击，换席重新从举守开始。玩家等守势结束、保余血应付后两席，并决定己方顺序。 |

三个场次使用相同的拳手血量、伤害、距离、前摇和收招；敌方只读当前距离及已经出现的动作，没有隐藏克制倍率、倒计时或未来输入读取。每场开赛时全队满血；场内胜者带余血，场间不暗扣资源。完成一场解锁下一场，可选择已解锁场次；失败重试只重置当前场，取消不动记录。三场过关后显示每场排阵、余血和用时。独立存档键：`classic-atlas.three-seats.campaign.v1`，刷新后暂停；公开单场键 `classic-atlas.three-seats.slice1.v1` 从不读写。

运行：从仓库根目录启动静态服务器，访问 `/experiments/three-seats-campaign/`。模型契约测试：`node experiments/three-seats-campaign/engine.test.mjs`。本地浏览器证据在忽略的 `.local/three-seats-campaign/` 下：最终版本以正常时钟键盘连续通关三场，分别用时约 34、30、45 秒；390 原生触控第一场约 34 秒、第二场约 37 秒、第三场约 50 秒。第二场结算后刷新保持存档字节再进入第三场；暂停刷新、重试取消、三场回顾及原单场存档隔离均已检查。触控测试脚本曾误把 CDP `touchEnd` 的参数当作剩余手指，造成防守键假粘住；改正测试输入后两场均可完成，游戏代码无相关修改。真人可读性、实体手机和重玩意愿仍未验证。画面沿用矢量原型，不宣称最终美术品质。
