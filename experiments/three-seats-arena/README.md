# 三席擂台：单场实验

本目录是独立的原创三对三接力格斗原型，不计入 45 款正式目录。以静态服务器打开 `index.html` 即可游玩一场完整比赛；统一 `/play` 实验入口的发布状态以该索引为准。人物、场景和画面均为本项目原创；它采用了三人组队、赛前排序、胜者余血留场的经典循环，不是任何商业作品的完整复刻。

设计参照 [SNK 官方 KOF 系列介绍](https://www.snk-corp.co.jp/us/games/kof-portal/about/)对三人组队、败者换人和胜者留场的说明，以及 [KOF '98 UM 官方系统说明](https://www.snk-corp.co.jp/zh/games/arcade/KOF98UM/system/index.html)对赛前选择出场顺序的说明。本作只实现一个原创短场、轻重击与防守，未复用原作角色、动作、美术或代码。

赛前可调整汐、芦、砾的顺序，对方可选潮线阵（芦 → 汐 → 砾）或疾潮阵（汐 → 砾 → 芦）。两阵使用同一批拳手与规则，只改变顺序，没有隐藏伤害倍率。方向键或 A/D 移动，J 轻击，K 重击，按住 L 防守，P 暂停；手机用画面下方的方向键和三枚动作键。攻击有前摇、有效距离和收招，防守减伤但不能同时攻击。先击倒对方三席获胜，己方三席退场则失败。比赛自动保存到独立键 `classic-atlas.three-seats.slice1.v1`；刷新后暂停，重试或重排需确认。原先只有潮线阵的有效记录仍可读取。

运行规则测试：

```sh
node experiments/three-seats-arena/engine.test.mjs
```

当前只验证一场接力和两套敌方出场顺序。有限模型操作显示不同顺序有代价，但正常浏览器动作尚未证明不存在跨两阵都占优的己方排序；真人第一次上手、动作手感与反复游玩价值也未定稿。不要将它计入现有游戏数量或在实际发布前标为已上线。
