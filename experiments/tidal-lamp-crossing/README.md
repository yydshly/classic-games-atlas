# 潮桥送灯 · 三关实时横断原型

玩家是原创港区的灯邮，沿九列地图短步移动，把灯送到北岸中央。车道需要看移动间隙；水道必须踩浮梁，站上后会随浮梁横移。被车撞、落水或超时则失败，可重试当前关；已完成关卡记录保留。安全岛可停步观察，暂停和刷新不推进时钟。

参考经 Konami 授权发行的 [《FROGGER》官方发行介绍](https://www.arcadearchives.com/en/title/aca-099/)：原作在限时下穿越车流与河道。我们推断其短步与移动危险交错带来“看准空隙再行动”的吸引力；这里保留该操作判断，改为原创灯邮、货车、浮桥、港口和三张地图，不使用原作角色、音画、地图或故事，也不声称完整复刻。

三关递进：清晨车潮练习车道与安全岛；浮梁渡口要求落在移动平台并被其带行；双闸归灯由封栏迫使绕行，两侧均能通行。没有隐藏生命或无限重刷奖励。方向键/WASD 或屏幕方向键按住连续短步，P 暂停，R 打开重试确认；失焦自动暂停。独立存档键 `classic-games-atlas:tidal-lamp-crossing:v1`，不访问其他游戏数据。

本原型尚需真人首玩和实体手机体验来判断车流可读性、节奏及重玩价值。模型路线和自动浏览器操作仅证明有限可完成性，不能代替上述验收。运行 `node --test experiments/tidal-lamp-crossing/engine.test.mjs` 验证规则与存档。地图、角色和画面均由本项目代码自绘。
