# 箱跃货栈 · 单人七关试玩

状态：`crate-courier-seven-fourth-cue-1` 为七关公开试玩版本，第四至七关作为阶段内容纳入现有网页入口；原有前三关与旧第六、第七关进行中存档保留。实体手机与玩家初见体验未验，线上体验验收中。

玩家是递送员阿禾，从雨后货栈出发，举箱、投箱、借箱垫脚、跨水道，前往各站亮灯出口。被巡逻机碰撞三次或落水失败；只重试本关。安全落地的箱子须到落点捡回；箱子损坏或落水才会在原补给点延时重现。第三关已到站的旧存档可直接进入第四关；旧第六关进行中或完赛的存档保持原四箱／四巡逻／高架终点地图，新进入第六关才用短关；旧第六关完赛可进入新版第七关。已经在旧第七关进行中或完赛的存档继续使用旧地图，重试也不会悄悄更换地图。旧关记录保持，存档仍使用同一个本游戏专属 key。

## 参考与改编边界

`data/games.json` 中 `chip-dale` 对应初代《松鼠大战》。[Capcom 官方合集介绍](https://news.capcomusa.com/lets/browse/90s-kids-rejoice-the-disney-afternoon-collection-revisits-ducktales-rescue-rangers-and-more-retro-classics-on-april-18)说明其平台动作、双人合作及投箱特色；[原版手册公开扫描](https://www.thegameisafootarcade.com/wp-content/uploads/2017/02/Chip-n-Dale-Rescue-Rangers-Game-Manual.pdf)的检索文本说明 A 跳、B 举物/投掷及向上投掷。本环境早前直接取得该 PDF 被云代理以 403 拒绝，未重试。本站采用原创角色、场景、故事、地图、Canvas 美术与固定抛物线。未做原作双人合作、向上投掷、Boss、藏箱或声音，不称完整复刻。

前五关的地图、敌人与物理规则未变。第四关「错层接力」把末箱带过最后水沟，再轻放垫脚登高架。第五关「斜桥调度」保留清路、窄架绕行和省投掷但会受伤的选择。新版第六关「晨光终递」缩为左岸一箱、一道水沟、右岸一台巡逻与地面交货：箱子须被实际带过水沟才能在右岸投中，预测虚线落在敌前就应继续靠近；熟练玩家也可不投而跳过。末段不再重复第四关的垫箱登高，投失后箱子落地可捡，损坏／落水仍从左岸补给点恢复。旧第六关完整地图继续供旧存档使用。新版第七关「折返分拣」保留轻放箱子挡巡逻、借箱上架的上层路线；上层货架落脚更宽，远离巡逻但需连续换层。下层清路路线以两次瞄准投箱避敌并跨水道，流程更直接。地面交接终点取代重复的末箱登架。场内地板金带标示提前轻放挡机的位置，上下路线有不同的站内线色与文字。模型路线分别为上层 0 投中、4 跳、1 轻放，下层 2 投中、2 跳、0 轻放，都可无伤；不以强制掉血造差异。本作七关是阶段内容，不是以后关卡数量上限。

首屏说明角色、目标、操作、胜败；移动 ←→/A D，跳空格/K，举箱或投箱 J/E，↓+J 轻放，P 暂停，R 重试。每跳需要松开再按。触屏方向、跳、举投和轻放按钮在 390 宽度可点。暂停、失焦和切后台清除按键；刷新现场先暂停。损坏或未知版本的原档保留原字节，只有用户明确确认才替换。其他作品的存档键不读取或修改。
