# 灯塔拍点（本地五段节奏原型）

参考 [Nintendo 对《Rhythm Paradise Megamix》的官方介绍](https://www.nintendo.com/en-gb/News/2016/October/In-shops-and-on-Nintendo-eShop-now-Rhythm-Paradise-Megamix-1149098.html)：按键或触屏跟随音乐节拍。官方资料支持的是易懂的节拍输入与多种场景；“简单操作能让人反复练准”是本项目的设计推断，并非销量或玩家评价事实。本作灯塔传信、双轨、五组谱、图形、音色均原创，不复制原作人物、乐曲或关卡，也不宣称完整复刻。

五组依次要求均匀左鼓、左右轮答、等待空拍与半拍、按住一拍再松开、综合应答。命中线到达时允许前后 0.20 秒窗口；左鼓用 A/←、右铃用 L/→，手机按两个大键。长按若被系统触控取消会重置该音符供重新对拍，不会悄悄留下按键或扣失误。P 暂停、R 打开重试确认；失焦自动暂停。当前段成绩与失误在刷新后保留，正在按住的音符恢复为待按并略微回退。每段显示命中、长按、错误三项；达标解锁下一段，失败重试仅清本段。最后一段给出明确终局，不显示不存在的下一段。

提示音由 Web Audio 正弦振荡器在本地合成，不请求声音文件；可静音并看轨道。音频设备与浏览器延迟可能影响节奏体验，尚未做真人校准；当前判定沿页面动画时间轴，不能保证真实设备音画同步精度。五段是首个阶段，不是最终内容上限。独立存档键 `classic-atlas.lighthouse-beats.v1`，不读写现有任何游戏档。

验收边界：纯规则测试覆盖五段逻辑、错键/空拍、长按与续档；隔离 Chromium 用正常墙钟键盘及原生触控走完五段，另查失败刷新、重试取消、暂停续档和触控取消。自动按预知谱面操作证明可完成，不等于陌生玩家的节奏乐趣、美术品质、音频延迟或实体手机验收。
