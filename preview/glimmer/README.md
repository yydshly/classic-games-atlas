# 砾光行者 / Glimmerstride

三庭有终点的原创二维即时战斗与拾取构筑小品。参考原72条清单《暗黑破坏神Ⅱ》的战斗、掉落、装备取舍方向；人物、地图、美术与代码原创，不是官方复刻。没有职业树、随机刷装、交易经济或在线联机。

1. 页岩前庭：近处遗匣在快刃/重锤间选择升级，清除两名守卫后走向石门。
2. 岔脉回廊：右侧通路可直接清理离开；可选侧室多两名守卫，换来苔纹护符或星髓坠。
3. 灯核石庭：清除守卫，面对半血转阶段的守望者。二阶段交替圆震与三束矿火；击退后获得砾光印记，仍需到石门完成旅程。

基础挥击朝4格内可见的近敌瞄准，伤害只作用于真实距离、扇区与视线内敌人；没有移动即自动攻击。晶环消耗晶能和冷却；闪步短暂无敌，治疗药每段一份。敌人先蓄势预警，没有接触即扣血。玩家和敌人都不能穿墙。

两装备槽。旅行短棍起步；快刃出手快，重锤单次伤害/范围更大。苔纹护符偏生命、机动、闪步与治疗；星髓坠偏晶能和晶环。比较界面使用同一deriveStats真实数值。遗匣只选一件替换对应槽位，也可保留当前装备封存遗匣，不会重复拾取；首关检查遗匣即完成该目标，无选特定武器的钥匙限制。

三段之间恢复生命/晶能并带上装备。本段重试回到本段入场装备和初始资源，保留前段完成回顾；不允许靠重试累加战利品。已完成段可重走，回顾保存首次完成结果，后续入场装备记录不反复刷写。

独立存档键 classic-atlas.glimmer.v1。活动刷新先暂停，恢复人物、敌人、冷却、弹体、遗匣与时间；选择装备保持choosing停时，终态保持终态。坏档/读失败保全原字节停止覆盖；写失败保留旧有效档并明确提示，后续成功写入恢复正常。不读写任何旧作存档。

WASD/方向键移动，J挥击、K晶环、Space闪步、E交互、H补给、P暂停。原生Tab/Enter按钮操作，开始后焦点进入画布；触控方向/行动可同时按住，取消/移出释放/失焦会清理输入。切后台暂停，返回需明确继续。无强制拖拽或鼠标精确瞄准。

模型固定1/30秒，渲染不修改规则。无外部依赖、字体、服务、凭据、账户、后端、追踪或音频。
