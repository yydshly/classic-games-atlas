      01 / 读懂环线

      每园有十二段固定轨道，地形、高度与弯道不变。点击画面或轨道索引选段，查看坡度、弯道与已有模块。每段只能安装一种模块。

      02 / 在预算内配置

      03 / 先派空车

      空车试跑不计入载客班次，也不产生营收。诊断会给出停滞、速度或转弯问题所在的轨道。修改任何模块都会清除旧报告，必须重新试车。

      04 / 安全与达标

      05 / 有限班次的经营

      06 / 随时停下来

      暂停会停止列车和计时。离开窗口、打开手册或公园列表也会暂停；关闭弹窗后仍保持暂停，按“继续”才恢复。刷新后，未结束的当前局会恢复方案，保存中的试车或载客会暂停等待。已结束的局只保留通关记录与解锁；没有可恢复的当前局时，进入最新已解锁公园。

      速度与受力是游戏简化模拟，不能用于真实设施设计或安全认证。

      快捷键：P / Esc 暂停或继续，T 试车，O 开放，D 返回设计，R 重试，H 手册。输入框和弹窗内不触发全局快捷键。
