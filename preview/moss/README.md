# 苔灯归途 / MOSS PARADE

三关原创群体路径规划小品，使用原创芽帽灯灵、林地美术、地形和代码。参考本轮明确指定的 Lemmings 式自主群体救援机制，不是官方复刻。该参考不在原72条图鉴中；只新增第43款原创作品与参考说明，不扩充或冒称已覆盖原图鉴。

## 三段归途

1. **溪口一桥**：5人、目标4。一次搭桥，配合后方驻守保护施工；整桥完工后免费放行，让队伍过溪。
2. **两岸回廊**：6人、目标5。向右开土走短路，或让队伍折返向左搭桥走长路，两端安全台阶通往共同出口。深落差不可直接当捷径。
3. **苔灯归途**：7人、目标6。开土与架桥组合；可后方挡队保护施工，或领队驻守先让全队回旋再放行修桥。不是同一图换背景或只增加人数。

所有灯灵自主行走，碰墙转向。驻守消耗一次指令，阻挡两侧同伴使其转向；放行免费但不返还指令。搭桥跨前方1–3格缺口且对岸需有锚点；开土只挖前方1–3格连续软土墙，不挖地板与硬石。每格施工0.7秒，施工者站定，其他人仍走；整段完成才一起开放，不是瞬间修路。松土、石、桥、险地和施工预览各有对应画面。

超过2.2格的坠落或险地会失散。**救回人数达标且全员已经归队或失散才结算**；留下挡员会拖到超时失败，必须记得放行。三关活动上限70/85/90秒，暂停不计时。熟练辅助策略时间不是真人预计用时或难度承诺。

## 操作与连续进度

先从名册或地图选人，再选工作并确认。无需精细拖拽。暂停时也可下令，但时间与施工不走，这是本作有意的原创辅助规则。画布获焦时，左右键切换灯灵，1/2/3/4选择驻守/桥/开土/放行，Enter确认，P或空格暂停/继续。原生Tab/Enter操作按钮及返回链接；390 CSS下名册和工具保持大按钮。触摸取消不触发确认，不使用长按重复施令。

三关依次推进，每关重置人物与工具。当前关重试需确认，只重置本关，前关成果保留；关间说明下关目标，结局可查看三关回顾和返回大厅。查看场景后可重新打开结果。新旅程也需确认，清本作当前三关进度与回顾；没有跨旅程最佳纪录，不影响其他游戏。

独立存档键 `classic-atlas.moss.v1`。约每秒、施令、暂停、关间与终态保存；活动刷新先暂停，关间和终态保留。恢复人物、方向、地形、工具、施工与倒计时。写失败准确提示刷新风险，旧有效字节不删除，后续写入成功清警告；坏档/读取失败保全原字节停止覆盖。没有在线账户、服务、凭据、追踪、外部字体、依赖或音频。
