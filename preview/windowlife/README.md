# 栖窗日常 / Windowlife

有终点的三关原创生活安排小品。机制方向参考原经典清单《模拟人生》系列；人物、代码、美术与房间均为原创，不是官方复刻或开放沙盒。

第一日独自完成做饭、用餐、洗漱与手记；第二日两位住户轮流使用设施并共同聊天；第三日灶台18–32秒维护，40–100秒可开始共享晚餐，双方还需完成手记。具体目标、需求门槛和时限在页面显示。第二、三日各有两种模型合法安排，见 scripts/fixtures/windowlife-schedules.json；并非要求唯一解。

- 2住户、4需求、5设施，每人3项队列（包括当前行动）；人物寻路可互相经过，不能穿墙或家具。
- 共同活动原子排入双方队列；双方在队头就绪才能一起开始。等待不半占设施，取消双方释放；用餐开始时扣食物，不退款、不重复扣除。
- 准备阶段只可在预设位置调整书桌与双人座，无强制拖拽。开始后不可移动。
- 达到目标即完成当天；时限或饱腹/精力耗尽则失败。重试只重开当前日，保留前日完成回顾与陈设选择；可选择已开启的天数重新安排。
- 独立存档键 classic-atlas.windowlife.v1。活动刷新暂停恢复行动、设施锁、需求、队列及剩余时间；ready/won/lost也恢复。重玩不重复新增完成记录，回顾保留首次完成结果。
- 写失败提示临时进度风险、保留旧有效字节，后续操作再试；坏档或读取拒绝停止覆盖，仍可临时游玩。不写任何旧作存档。
- 键盘Tab/Enter全操作，非交互区1/2选人、P暂停；单点触控，无连续按压控制。切后台/失焦暂停，返回需明确继续。

模型为0.1秒固定步，渲染不修改模型。引擎/三关数据、画面、控制器与存储分离；无运行时外部依赖、账户、后端、音频、追踪或网络调用。

验证：node scripts/test_windowlife.mjs；node scripts/test_windowlife_storage.mjs。普通UI、触控模拟与故障夹具的分项证据见[公开报告](../../docs/windowlife-qa/)。已知排程辅助完成不证明真人自由安排的趣味、真实手机性能或审美验收。
