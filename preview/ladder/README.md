# 梯港拾星 · LADDERLIGHT

原创三座梯港的攀行、临时挖坑与诱敌收集小品。参考本轮指定的 Lode Runner 式机制；人物、美术、关卡和本作巡卫规则原创，不是官方复刻。Lode Runner 不在原72条图鉴中，本轮保留原图鉴，只增加一款独立原创作品。

## 三关决策

| 梯港 | 要想清楚的事 | 有限证据 |
|---|---|---|
| 修梯小港 | 埋在软砖中的灯芯需要先斜挖，落洞后立即向右借梯退出；上层与悬绳决定后续顺序。 | 两种收集顺序模型可解；取灯后留洞底会被回填困住。 |
| 双梯货栈 | 长侧梯绕行，还是挖开上层直落悬绳？先取哪层灯芯，决定与巡卫同层的窗口。 | 长梯方案0洞；直落方案2洞、实际困卫。普通UI采用直落顺序。 |
| 回环灯塔 | 左先行与右先行经过不同梯口；双巡卫下用侧梯/中央回环和临时洞安排取灯后的退路。 | 左右两种顺序均可解且实际困卫。普通UI先沿中央梯直下被捕，再重试左先行路线完成。 |

每关集齐全部灯芯后回到亮起的归灯门。关间先看新目标再开始；失利可确认重试当前关，前关成果保留。完成后可以重读航记；新旅程会重置本作进度和回顾，必须确认，可以取消。本作没有另设最佳纪录。

## 操作与规则

- 方向键 / WASD 移动，Q / E 挖左下 / 右下，P或空格开始/暂停/继续；画布获焦时Enter也可开始/暂停。按钮和链接保留原生键盘行为。
- 手机尺寸使用可按住的四向按钮和挖掘按钮，不需要拖拽。松手、取消、失焦或切后台清除输入；不会自动继续。
- 不可跳跃。梯可以上下走，悬绳可横行，向下可松开悬绳。软砖可挖、硬钢不可挖；洞只开在脚边斜下方。
- 临时洞5.5秒后复原。巡卫落洞后暂时无害，回填时回原岗并显示0.8秒整备；起步有0.6秒预警。同层巡卫直追，跨层沿可达梯索追逐。三关基础速度一致，没有强制等待门槛。
- 被非陷洞巡卫碰到、被回填砖困住或余时用尽，本次关卡失利。下落本身不扣血；没有额外战斗或随机掉落。

## 验证与质量级别

[实际UI、截图与模型证据](../../docs/ladder-qa/)分别记录。模型三关×两顺序×50/100/200ms共18次胜利，以及回填、被捕和恢复边界；200ms按20ms子步完整累计。普通UI使用原生键盘和只读当前状态路线建议完成三关，正常暂停用于一次开放洞刷新检查。第三关直下被捕后重试；实际完成档刷新与390CSS触控模拟通过。结算关闭后的可见焦点问题已在发布前修正并用实际完成档回归。

熟练辅助路线结算约4.94 / 8.06 / 8.74秒，37 / 60 / 66步。它们证明一条很短的完整玩法循环，不证明真人无辅助的乐趣、难度或长期深度。地图小且确定性强，暂列原创三关首版候选；真手机触控/性能和人工审美未验收。
