# 汀光织界 · INLET WEAVER

原创三湾闭合路径圈地小品，经典机制启发，不是官方复刻。原43项、旧版本与原72条图鉴不变。人物、海图、SVG封面及绘制均为本项目原创代码，无原作素材。

- 第一湾：目标50%，学习沿岸移动、开线和闭合。
- 第二湾：目标60%，汀口与浮岛提供分段落点，可选长线或借位路线。
- 第三湾：目标65%，双潮影与中央浮岛组合；所有敌人的所在分区都保留，同速而非加速堆难度。

方向键/WASD，或按住方向按钮；空格/X准备织线，P/Esc暂停或继续，R请求当前湾重试。Tab/Enter操作按钮，游戏快捷键只在非交互区处理。触控无需拖拽，移出/取消/暂停释放方向。

从汀地开线，回到汀地才闭合。以所有水域潮影为种子做连通检查，只填不含潮影的分区（含新线）；百分比分母只含最初可织水域，不含初始岸/岛。开放线不能取消；回踩第一格退回原岸也算回踩，不能白退。针碰潮影、潮影碰线、自交损一灯回起点，已织区域保留。外岸巡游者可伤灯，短青环只挡岸巡，不能免除回踩/潮影伤害。三灯用尽或超时失败。

独立键 `classic-atlas.inlet.v1` 保存当前网格、开放线、时间、敌人和三湾航记。活动局刷新先暂停，按键不恢复；ready/失利/关间/结局保持。重试需确认，只重置当前湾；新旅程需确认，重置本作三湾及航记，没有另存最佳纪录。写入失败提示风险并保留旧有效字节，之后成功可恢复；坏档保全且阻止覆盖，无读取权限时不写。没有联网、账户、外部依赖或音频。

参考：[Nintendo 官方 Arcade Archives QIX 产品介绍](https://www.nintendo.com/us/store/products/arcade-archives-qix-switch/)，本轮核读画线圈区与避敌机制。Qix/Xonix方向是本轮明确新增参考，不在原72条中，未把未读资料说成已核验。目标百分比、网格敌人规则、原创海图和暂停为本作设计，不逐项还原原作。
